# SABES 디자인 규칙

기존 [Instrument console 결정](../ui_redesign/decisions.md)·[단계 계획](../ui_redesign/plan.md) 위에 적용하는 광학 테이블 마감 규칙. 앱 전체 재설계나 별도 테마 신설 범위 아님. [광학 테이블 계획](optical_table_ui_plan.md)의 좌표·물리 분리 유지.

## 사용자 직접 요구 · 2026-10-22

- 기존 console의 글꼴·색·간격·컴포넌트 재사용.
- 광학 테이블은 의도적으로 정돈된 전문적 도식으로 표현.
- 소자마다 반복되는 `(lumped)` 제거. 불완전한 소자 모델은 이름 옆 `*`로 표시.
- 사용자용 범례에서 선 굵기 설명 제거.

이전 광학 테이블 계획의 `(lumped)` 반복 표기·선 굵기 설명 요구는 위 최신 요청으로 대체.

### 상단 요약 · 사용자 채택, 2026-10-22

- 상단은 잡음 수준(`Noise level [dB]`)·`Gain G_s / G_c`·`Detector clearance` 세 카드.
- `G_s`는 probe/seed gain. 기존 `Pump gain` 명칭 제거. 잡음 수준은 계산 NF의 dB 값으로 설명.
- 모델 상태는 제목 옆 작은 배지. NF 선형값·algebraic detection floor·RIN 진단은 Detection, 잔류 carrier : seed는 Power budget에 배치.

## ⟦AI⟧ 구현 기준 · 제안

아래 수치·배치·검증 항목은 위 요구를 구현하기 위한 작업 기준. 별도 사용자 결정으로 승격하지 않음.

### 기존 시각 언어

색·글꼴 출처는 [gabes_ui/theme.py](../../gabes_ui/theme.py), 광선 식별색은 [sabes/layout/render.py](../../sabes/layout/render.py). iframe도 기존 토큰·IBM Plex Sans/Mono 전달받아 사용. 제목·소자명은 Sans, 수치·단위는 기존 숫자 포맷. 간격·모서리·버튼·탭은 공유 console 규칙 우선.

| 역할 | 유지 기준 |
|---|---|
| 바탕·경계·본문 | 기존 중립 쿨 그레이·흰 surface·ink/muted 토큰 |
| 선택·포커스 | 기존 accent 계열. 광선 식별색과 분리 |
| common / pump | 주황 `#E8873A` |
| seed / probe | 빨강 `#D9534F`; seed의 기존 점선 구분 유지 |
| conjugate | 파랑 `#3B82F6` |
| reference | 연주황 `#F0A868`; 기존 점선 구분 유지 |

본문 대비를 낮춰 비활성 상태 표현하지 않음. 비활성·선택·부분 모델은 색 하나만으로 구분하지 않음. 광택·입체 그림자·그라데이션·만화식 하드웨어 효과 추가하지 않음. 재질 표현보다 광학 기능·연결·선택 상태 우선.

### 도식의 품질

- 같은 소자는 같은 glyph·선 두께·비례 사용. PBS의 대각선, mirror 반사면, lens, waveplate, iris, cell, detector 식별 가능. 부품별 임의 아이콘 혼용 금지.
- 광선은 소자 중심·입출력 anchor에 연결. 진행 순서와 분기 명확히 유지. 불필요한 꺾임·짧은 되돌이·의도 없는 교차 제거. 대체 SQL 광로와 FWM 연결은 기존 물리·구성 의미 보존.
- 라벨과 glyph에 여백 확보. 글자끼리, 글자와 소자, 글자와 광선 겹침 금지. 긴 기종명은 상세보기로 이동; 이름 줄임이 필요하면 일관된 약어와 전체 이름 접근 수단 제공.
- 테이블 경계·SVG viewBox 안에 소자·라벨·선택 표시 전부 포함. 임시 음수 margin이나 글꼴 축소로 잘림 숨기지 않음.
- 주광로→소자→라벨→보조 grid 순으로 읽히도록 계층 구성. Grid는 정렬 보조 수준. 광선을 가리는 과도한 패널·채움·중복 캡션 제거.
- `display` 좌표는 schematic. 깔끔하게 재배치해도 `path_m`·기준면·실측값 변경 금지. 화면상 직각·간격·그리드를 실험대 실측이나 배율로 제시하지 않음. 선 굵기를 실제 빔 직경으로 사용하지 않음.

### 모델 표시·범례

`*` = **소자 상세 모델 미완**. 손실·기하·이상적 분기 일부는 이미 계산될 수 있음. 표시 판정은 `node.lumped or not node.modelled`; 계산 경로 변경 없는 presentation 규칙. 기종 미상·물리 계산 전무·클릭 불가를 뜻하는 표식으로 혼용하지 않음. 이름 없는 steering mirror에는 단독 `*` 라벨 생성하지 않음.

화면 범례는 광선 식별과 `* 상세 모델 미구성` 한 번만 표시. `(lumped)`·동일 제한문구를 소자마다 반복하지 않음. 개별 생략 특성·출처·기종 미상은 소자 상세나 장치 정보에서 한 번 설명. 클릭 가능 여부는 조절값·정보 접근 기능으로 판단; `*`와 독립.

사용자 범례에 선 굵기·로그 스케일·구현 수식 설명 추가하지 않음. 필요한 구현 계약은 코드·개발 문서에 유지.

### 선택·확대·좁은 화면

선택 상태와 keyboard focus-visible은 glyph 경계를 따라 명확히 표시. 라벨·광선을 가리지 않으며 hover 없이도 선택 소자 식별 가능. 기존 popup·입력 컴포넌트 재사용. 터치 목표는 충분히 확보하되 인접 소자 hit area가 의미 없이 겹치지 않게 조정.

맞춤 보기와 확대 보기 모두 지원하는 경우, fit 상태는 전체 광로 파악용, 확대 상태는 소자명·선택·편집용. 390px 화면에서 전체 테이블을 축소한 뒤 작은 글자로 고정하지 않음. 확대·이동 또는 상세 접근으로 읽을 수 있어야 함. 확대 후에도 선·라벨 anchor·클릭 좌표 정합 유지.
