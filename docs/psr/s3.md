# PSR Maxwell 열평균과 계산 효율

사용자 요청. PSR 개선 계획의 S3 구현. [단계별 계획](model_review_2026-11-02.md) · [S2 단일 속도 RF 모델](s2.md)

## ⟦AI⟧ 사용법과 범위

**Polarization squeezing → Calculation → Rb87 D1 thermal RF squeezing** 선택. 기존 단일 속도 모드 유지. **Analysis frequency**에서 25개 양의 RF의 최소·최대 잡음과 최소 위상, **Quadrature phase**에서 선택 RF의 두 직교 quadrature 확인. 0 dB는 검출면 shot noise.

순수 ⁸⁷Rb D1, B=0, 밝은 x 선형 펌프, 독립적인 1차원 Maxwell 속도군. 같은 온도로 축방향 속도 폭과 순수 동위원소 증기 밀도를 정함. Python API에서는 밀도 별도 지정 가능. 단일 속도·편광각·기존 excess-noise 입력은 thermal 모드에 적용하지 않으며, 결과 JSON의 적용 입력에서 제외함.

셀 내 펌프 강도는 균일하게 유지. 평균 흡수로 계산한 |αL|≤0.3 화면 적용 경계 유지. 속도 변경 충돌·공간 모드·분석기 대역 적분은 포함하지 않음. optical sideband들이 같은 광학 파수를 갖는 S2 근사 유지. S4의 길이 방향 펌프 고갈·편광 변화는 후속 범위. 이번 수치 수렴은 열증기 실험과의 정량 일치를 뜻하지 않음.

## ⟦AI⟧ 평균 순서와 재사용

각 속도 v에서 S1의 포화 full-OBE 정상상태와 S2의 복소 응답·Langevin 잡음을 계산. 총 밀도를 사용한 국소 행렬을 아래와 같이 평균함.

```text
K̄(f)  = Σv wv K(v,f)
D̄⁾(f) = Σv wv D⁾(v,f)
D̄⁼(f) = Σv wv D⁼(v,f)
χ̄pump = Σv wv χpump(v)
β̄ = k Re(χ̄pump)/2
Kco = K̄ − i β̄ diag(1,1,−1,−1)
```

잡음도 선형 가중치 wv 사용. 서로 독립적인 원자군의 잡음이며 wv²를 사용하지 않음. 평균한 K와 두 ordered noise를 한 번 전파. 각 속도군의 gain·dB·출력 covariance를 평균하지 않음. Maxwell 평균 밀도행렬을 단일 원자의 정상상태로 간주하지 않음. 반환하는 평균 펌프는 별도 model ID와 평균 χ·population·진단값만 가지며, 가상의 Liouvillian이나 ρ는 없음.

기존 [공유 velocity_quadrature](../../gabes/magneto_multilevel.py)의 공명 중심 composite Gauss–Legendre 적분 재사용. 선택적인 cutoff·RF 공명 기준점만 추가. 기본 호출 결과는 기존 Rb87 D1 및 Rb85 D2 사례와 배열 단위 bit-identical 확인. [열평균 backend](../../gabes/psr_thermal.py)는 기존 원자 상태, S2 drift·noise, 공유 전파 및 homodyne 함수를 호출함.

이 평균 순서는 [Lezama 등, PRA 77, 013806, Sec. II.A, Eqs. (21)–(29)](https://arxiv.org/abs/0710.0609)의 속도분포 처리와 연결됨. [DB 근거 레코드](../../references/psr_experiments/papers/lezama_2008_pra.json)에 원문 위치 보관.

## ⟦AI⟧ 수렴 검사

공명과 자연선폭 주변의 기존 분할점에 RF 범위 양끝의 측파대 기준점을 추가. 모든 RF의 복소 drift, reservoir별 D⁾·D⁼, 평균 편광을 비교하며 구간당 적분 차수를 2씩 증가시킴. 최종 두 차수와 6σ→7σ cutoff 비교를 보관함. 각 kernel 성분의 허용 차이는 `1e-6 m⁻¹ + rtol × max(|old|, |new|)`.

| Thermal integration | 시작 / 최대 구간 차수 | rtol | 전체 속도군 평가 상한 |
|---|---:|---:|---:|
| Quick | 2 / 6 | 0.02 | 1,800 |
| Balanced | 4 / 10 | 0.005 | 3,000 |
| Fine | 6 / 14 | 0.001 | 6,000 |

현재 셀 길이에서 **source covariance와 최소·최대 분산 및 dB**도 검사. 분산 절대 허용량 10⁻⁵ SQL, 상대 허용량 rtol. dB 차이 허용량 max(0.001, rtol) dB. Python 검출 효율을 지정하면 source와 detector 두 면을 검사. UI는 검출 손실로 수치 오차가 가려지지 않도록 source 검사를 통과해야 표시함.

6σ 밖의 Maxwell 확률 약 1.97×10⁻⁹, 7σ 밖 약 2.56×10⁻¹². 작은 꼬리 확률만으로 관측량 오차를 보증하지 않음. 실제 cutoff 비교는 분포 범위와 적분 격자를 함께 바꾸는 경험적 수렴 검사. 엄밀한 오차 상한은 아님. 두 차수·cutoff·출력 검사가 실패하거나 평가 예산을 소진하면 UI에서 잡음 곡선을 보류하고 원인 표시. Fine에서도 실패하면 운전점별 추가 수치 검토 필요.

## ⟦AI⟧ 최적화와 캐시

S2의 직접 계산은 기본값 `method="direct"`로 보존. thermal 모드는 검증된 `method="optimized"` 사용.

- 실제 선언된 reset jump가 replacement 연산자 집합인 경우, 동일한 commutator Gram을 대수적으로 수축. 다른 jump 집합은 직접 계산으로 복귀.
- ±RF의 정확한 Nambu 공액 관계 재사용. DC와 짝 없는 RF도 직접 처리.
- 한 속도군의 원자 배열만 유지. 전체 속도군의 255×255 확산 행렬 또는 정상상태를 쌓지 않음.
- 캐시에 평균한 작은 광학 행렬과 수렴 이력 보관. 셀 길이 변경은 전파·출력 수렴만 다시 계산. QE·셀 뒤 손실·화면 전환은 검출 처리만 변경. 펌프·온도·reset·RF·적분 정확도 변경은 thermal 적분 재계산.

## ⟦AI⟧ 수치 검증과 비용

검증점은 Δ=400 MHz, I=12.5 mW/cm², T=70°C, n=10¹⁶ m⁻³, reset=10⁵ s⁻¹, f=±400 kHz, L=25 mm, η=0.9025. 밀도는 API에서 별도 지정했으므로 같은 온도의 UI 기본 밀도와 구별해야 함.

| 항목 | 결과 |
|---|---:|
| 검출 최소 / 최대 잡음 | +0.02500043 / +0.14211240 dB |
| adaptive 대 고정 order-20 최소 / 최대 차이 | 1.14×10⁻⁶ / 1.14×10⁻⁵ dB |
| 같은 검증점의 6σ→7σ 최대 잡음 차이 | 약 6.03×10⁻¹⁰ dB |
| 단일 속도 직접 / 최적화 kernel 상대 차이 | ≤1.63×10⁻¹⁵ |
| adaptive 속도군 평가 수 | 1,900 |
| adaptive 시간 / traced peak allocation | 37.12 s / 12.88 MB |
| 고정 order-20 시간 / traced peak allocation | 20.76 s / 19.47 MB |

기준 적분은 cutoff 7σ의 고정 order-20이며, 원자 kernel 최적화는 별도로 직접 계산과 대조. 독립 리뷰에서는 기존 공명 격자의 직접 계산 order-20과도 비교했고 최대 차이 1.14×10⁻⁵ dB 확인. adaptive는 수렴 검증을 위한 여러 적분을 수행하므로 한 번의 고정 차수 계산보다 느릴 수 있음. 메모리는 tracemalloc이 추적한 Python/NumPy 할당량이며 프로세스 RSS가 아님.

UI 기본 운전점의 25개 양의 RF 전체 계산도 수렴. 790개 속도군 평가, 첫 적분 약 64.1 s, 보관 kernel 이력 192,000 bytes. 선택 RF 1.2 MHz에서 최소 −8.72844×10⁻⁵ dB, 최대 +1.20091×10⁻⁴ dB. 시간은 이 환경의 측정값이며 강한 구동·공명·Fine 선택에서는 몇 분까지 늘어날 수 있음.

## ⟦AI⟧ Python과 내보내기

```python
from gabes.psr_thermal import solve_psr_thermal, thermal_convergence
from gabes.psr_spectrum import psr_uniform_transfer
from gabes.psr_homodyne import psr_homodyne_readout

thermal = solve_psr_thermal(
    400., [-4e5, 4e5], intensity_mw_cm2=12.5, temp_c=70.,
    ground_relaxation_hz=1e5, density_m3=1e16)
audit = thermal_convergence(thermal, .025, detection_efficiency=.9025)
if not audit["passed"]:
    raise ValueError(audit["status"])
transfer = psr_uniform_transfer(thermal["local"], thermal["pump_state"], .025)
noise = psr_homodyne_readout(transfer, detection_efficiency=.9025)
```

`reference=True`는 지정 차수의 한 번 적분이며 수렴 상태는 미평가로 남김. UI JSON은 `velocity_quadrature`, `thermal_convergence`, `thermal_performance`에 차수·cutoff 이력, 검사 결과, 전체 평가 수, 시간과 배열 크기를 저장. 최종 평균 K·D⁾·D⁼ 및 전파·검출 covariance도 기존 RF 형식으로 저장. `params`는 실제 적용 입력, `saved_control_state`는 다른 모드의 보관 입력까지 포함.

검증 테스트는 [thermal backend](../../tests/test_psr_thermal.py), [RF kernel](../../tests/test_psr_spectrum.py), [thermal UI·export·cache](../../tests/test_psr_thermal_scheme.py)에 추가. 기존 PSR·quantum 전파/검출·공유 magneto quadrature 호출자도 관련 회귀 대상으로 검증함.
