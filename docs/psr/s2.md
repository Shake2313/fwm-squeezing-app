## ⟦AI⟧ 사용법과 계산 범위

**Polarization squeezing (PSR) → Calculation → Rb87 D1 RF squeezing** 선택. **Pump detuning**은 원자 전이 중심에 대한 광학 detuning, **Analysis frequency**는 검출 RF. 두 주파수 모두 UI 단위는 MHz. 광학 구동이 정하는 정상상태에서 검출 RF에 따른 응답과 잡음을 계산함.

- **Analysis frequency** 화면은 선택한 f₀의 0.1배부터 10배까지 로그 간격의 25점에서 최소·최대 잡음과 최소 잡음 위상을 표시. 각 점에 대해 ±f를 직접 계산. f₀는 가운데 표본.
- **Quadrature phase** 화면은 f₀에서 θ와 θ+90°의 Stokes 잡음을 표시. 0 dB는 검출면 shot noise. 두 분산이 같은 경우 주축 위상은 미정.
- 원자는 순수 ⁸⁷Rb D1, B=0, 한 축 방향 속도. 밝은 x 선형 carrier와 y 입력 vacuum을 가정. 결과는 각 분석 주파수에서의 좁은 대역 PSD. 실제 분석기 filter의 대역 적분·전자잡음·Doppler 평균·공간 모드 중첩은 별도 확장 범위.

셀 안의 local pump intensity를 고정하고 평균 굴절 위상을 전파. UI 적용 범위는 S1의 국소 흡수계수로 계산한 |αL|≤0.3. 기존 균일 펌프 근사의 engineering screen을 S2 표시 경계로 사용. 경계 밖에서는 αL과 조정할 조건을 표시. 입력 광세기 또는 외부 효율이 0이면 검출 carrier가 없어 Stokes 판독이 unavailable. 충분히 밝은 carrier라는 선형화 가정은 빔 면적과 검출 대역을 알고 있을 때 별도로 검토할 사항.

### 원자에서 장 스펙트럼까지

S1의 구동 정상상태 ρ, Liouvillian L, signed dipole 및 동일한 방출·열적 replacement jump를 사용. 편광·측파대 순서는

\[
b(f)=(a_x(+f),a_y(+f),a_x^\dagger(-f),a_y^\dagger(-f))^T,\qquad
J=\mathrm{diag}(1,1,-1,-1).
\]

1. 전체 16준위 밀도행렬에서 trace 방향을 분리하고, 255개 traceless 원자 좌표에서 \((-i2\pi f-L)^{-1}\)의 네 광학 출력 행을 구함. 이들 행과 구동 commutator로 복소 응답 K(f)를 계산. f=0은 정적 Jacobian 비교에 사용.
2. 같은 출력 행과 각 jump의 commutator를 수축해 두 순서의 장 잡음 \(D^>(f), D^<(f)\)를 계산. 자연방출·transit reset별로 합산. 각 jump마다 255×255 diffusion matrix를 보관하지 않고 네 광학 출력으로 먼저 투영. 공통 평면파 면적 A에서 원자 선밀도 nA와 photon-flux 결합 제곱 g²∝1/A의 곱은 \(n d_0^2 k/(2\epsilon_0\hbar)\). 고정 intensity의 정규화 스펙트럼에서 A는 상쇄됨. [원자 응답과 잡음 계산](../../gabes/psr_spectrum.py)
3. 국소 출력은 고정 envelope 좌표의 K. 평균 carrier의 국소 위상을 따라가는 좌표에서 전파할 때 \(K_{\rm co}=K-i\beta J\), \(\beta=k\,\mathrm{Re}(\chi_{\rm pump})/2\). 이 drift와 각 ordered noise를 공유 constant-segment solver로 길이 L에 걸쳐 전파. 국소 및 출력 commutator와 잡음의 Hermiticity·양의 준정부호를 확인. 고정 pump 가정과 선형화의 배경은 Lezama 등의 Sec. II, Eqs. (5)–(20) 참조. [전파 코드](../../gabes/quantum/traveling.py) · [Lezama 원문](https://arxiv.org/pdf/0710.0609)
4. 출력 carrier 기준 위상 θ에서 homodyne 광전류는 \(e^{-i\theta}a_y(+f)+e^{i\theta}a_y^\dagger(-f)\)에 비례. 두 측파대의 서로 다른 점유수와 복소 pair correlation을 유지. 셀 뒤 광학 투과율과 detector QE의 곱 η를 한 번 적용해 \(S_{\rm det}=1-\eta+\eta S_{\rm cell}\)로 계산. 두 측파대 canonical covariance의 진공은 I/2, 위상별 PSD의 SQL은 1. 표시값은 \(10\log_{10}S_{\rm det}\). 검출 공분산에서 최소 분산을 float64 정밀도로 분리할 수 없으면 해당 계산에 수치 오류를 표시. [Homodyne 계산](../../gabes/psr_homodyne.py)

### Python 사용 예

```python
import numpy as np
from gabes.psr_full_obe import solve_psr_pump
from gabes.psr_spectrum import psr_local_generator, psr_uniform_transfer
from gabes.psr_homodyne import psr_homodyne_readout

pump = solve_psr_pump(400., intensity_mw_cm2=12.5, ground_relaxation_hz=1e5,
                      density_m3=1e16, velocity_m_s=0., jones_xy=(1., 0.))
f_hz = np.array([1e5, 4e5, 1e6])
local = psr_local_generator(pump, np.r_[-f_hz[::-1], f_hz])
transfer = psr_uniform_transfer(local, pump, length_m=.025)
noise = psr_homodyne_readout(transfer, detection_efficiency=.9025)
print(noise["frequencies_hz"], noise["minimum_db"], noise["maximum_db"])
```

Python 전파 함수는 지정한 균일 매질의 수학적 전파를 계산. 실험 조건에 사용할 때에는 호출자가 \(|\alpha L|\)와 pump-depletion 근사를 평가. 위 예에서 400 kHz의 검출 잡음은 최소 +0.0890 dB, 최대 +0.4849 dB, 최소 위상 28.42°. 구동 조건에 따라 위상 의존 잡음이 있어도 두 quadrature 모두 SQL 위에 있을 수 있음.

다른 계산 예로 UI에서 Δ=+350 MHz, I=100 mW/cm², 70°C, 75 mm, v=0, reset=1000 s⁻¹, f₀=0.157 MHz, η=0.9025를 지정하면 αL≈0.0207이며 검출 최소 −7.45 dB, 최대 +12.69 dB. 이 숫자는 단일 속도·균일 펌프 모형의 결과. 열증기 실험의 절대 dB 비교에는 속도분포와 측정 조건이 추가로 필요함.

- 구동된 400 MHz detuning 사례에서 DC drift를 S1의 독립적인 x·y 실수/허수 평균장 섭동과 대조. 최대 상대 차이 3.8×10⁻¹⁰. −400 kHz, DC, +400 kHz에서 두 ordered noise를 원래 Liouvillian의 독립 2시각 QRT 계산과 비교. 최대 상대 차이 1.9×10⁻¹⁴. carrier 위상 전파는 실험실 좌표의 z 적분으로 대조. [원자·전파 회귀](../../tests/test_psr_spectrum.py)
- 수동 흡수와 길이 0에서 진공 0 dB, 이상적 shear의 해석값, 서로 다른 복소 측파대 transmission, LO 위상, downstream loss 1회 적용, 대칭 RF pair 검사, 수치적으로 미분해된 최소 분산을 확인. [검출 회귀](../../tests/test_psr_homodyne.py)
