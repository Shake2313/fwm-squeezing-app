# PSR 측정 규약과 ⁸⁷Rb D1 단일 속도 정상상태

2026-11-03 사용자 요청. S0 측정·편광 규약, S1 광학 포화를 포함한 단일 속도 full-OBE 정상상태 구현 및 기존 약한 여기 PSR 모형과 비교.

## ⟦AI⟧ 계산과 검증

GABES에서 **Polarization squeezing (PSR) → Calculation → Rb87 D1 steady state**를 선택. 셀 내부 한 지점의 intensity, laser detuning, 입사 편광, 축 방향 원자 속도를 지정하면 각 Zeeman 준위의 인구, 총 여기 인구와 국소 흡수계수를 확인할 수 있음. **More → Atomic populations and solver checks**에서 국소 편광 회전율과 밀도행렬 진단 확인. Export JSON의 `raw.rho`는 바닥 8개, 여기 8개 순서의 복소 밀도행렬. `params`는 이 계산에 적용한 입력, `saved_control_state`는 다른 모드에 보관된 입력까지 포함한 UI 상태.

### S0 측정·편광 규약

| 양 | 계산·비교 규약 |
|---|---|
| 광학 detuning | 위쪽 바닥 F=2의 선세기 가중 전이 중심 기준, laser가 청색이면 양수. +z가 빛의 진행 방향. 단일 속도 원자의 `Δ_atom[MHz] = Δ_lab[MHz] − ν₀[Hz] v_z/(c·10⁶)` |
| 구동 | 국소 광주기 평균 intensity[mW/cm²], 정규화된 복소 Jones 벡터 (Ex,Ey). 온도는 별도 밀도 입력이 없을 때 순수 ⁸⁷Rb 증기 밀도를 결정. Gaussian 국소 power와 intensity의 1/e² 반경이 함께 주어지면 I₀=2P/(πw²). 폭 정의가 없으면 환산값은 미보고 |
| 편광 | E±=(Ex∓iEy)/√2, S₃=2 Im(Ex*Ey). ψ는 방위각, ε는 타원율각. `jones_from_angles(ψ, ε)`는 두 각을 rad 단위로 독립 지정. 선형 x 편광에서 각각 δEy=δψ, δEy=iδε. 기존 QWP는 작은 β에서 ψ≈β, ε≈−β. 순수 원편광에서는 방위각 좌표가 특이하므로 각 변화율은 미정, 흡수는 정의됨 |
| 측정 주파수·대역 | 광학 Δ와 별도로 분석 중심 f[Hz], Ω=2πf[rad/s]. Fourier 역변환 부호는 exp(−iΩt). RF 측정 중심, 분석 필터 폭, RBW, VBW를 개별 필드로 유지. S1의 관측량은 정상상태 평균장 |
| 잡음·기준면 | 기존 조건부 squeeze 모드의 밝은 carrier와 직교 vacuum, canonical vacuum I/2, export된 정규화 공분산 2V 및 SQL=I. 검출 위상 θ는 도, 직교 trace는 θ+90°. 그래프 dB=10 log₁₀(variance/SQL). 직접 측정·전자잡음 차감·손실 역보정·셀 출구를 분리 |

규약은 `measurement_conventions()`로 export. `benchmark_case(paper, experiment_id)`는 한 논문의 한 사례를 골라 원문 locator, 값의 종류·불확도, beam 정의, seed, 장치 그룹, 판본·주석과 측정 기준면을 유지. 예를 들어 Ries Fig.4의 직접 측정 0.85 dB 감소는 검출면 −0.85 dB, 보정한 1.23 dB 감소는 추론한 셀 출구 −1.23 dB. 5 MHz 분석 주파수만 Ω로 변환하며, 해당 논문의 광학 detuning 원점은 흡수 최대점으로 보존. [규약 코드](../../gabes/psr_conventions.py) · [Ries 원문 기록](../../references/psr_experiments/papers/ries_2003_pra.json)

### S1 원자 모형

순수 ⁸⁷Rb의 5S₁/₂와 5P₁/₂ 각각 F=1,2의 모든 m을 유지. B=0에서 균일한 단색 고전장을 가정. 회전파 근사 아래 바닥 및 여기 hyperfine coherence, optical coherence와 인구를 동시에 풀어 포화·광펌핑을 포함함. Maxwell 적분이나 길이 방향 전파를 적용하기 전의 **단일 속도·국소 응답**. [구현](../../gabes/psr_full_obe.py)

1. 공유 `level_structure`의 에너지·자연선폭 Γ·signed dipole Cq와 기존 PSR의 detuning 중심을 재사용. H/ℏ의 결합 블록은 −(Ω₀/2) Σq E_q Cq†. Ω₀=d₀E_peak/ℏ, E_peak=√(2I/(ε₀c)). Hamiltonian은 rad/s, replacement rate r은 s⁻¹.
2. 방출 jump는 최종 바닥 F와 q로 구분한 √Γ P_F Cq. 같은 jump 안의 m·여기 F 경로는 coherent하게 합산. Σ J†J=ΓP_e. Transit은 r(ρ_th Trρ−ρ)로, 유입 상태 ρ_th는 바닥 8개 준위의 균일 혼합. 방출과 replacement jump의 이름·종류·출처를 별도로 유지. [Reservoir API](../../gabes/quantum/reservoirs.py)
3. 256개 밀도행렬 성분에 대해 공유 `steady_state_from_liouvillian`으로 Lρ=0, Trρ=1을 풀고 원래 방정식의 residual·Hermiticity·최소 고윳값 검사. 계산된 ρ_eg에서 복소 유도 편광, carrier 감수율, α=−d ln S₀/dz와 각 변화율을 구함. 구동 0에서는 원자 상태가 ρ_th이고 χ는 무한소 probe 극한. [공유 선형대수](../../gabes/core.py)

저장소 루트에서 실행할 수 있는 단일 점 예시.

```python
from gabes.psr_conventions import jones_from_angles
from gabes.psr_full_obe import solve_psr_pump

state = solve_psr_pump(
    350.0, intensity_mw_cm2=0.01, velocity_m_s=0.0,
    ground_relaxation_hz=1000.0, density_m3=1e15,
    jones_xy=jones_from_angles(azimuth_rad=0.0, ellipticity_rad=0.0),
)
print(state["excited_fraction"], state["alpha_per_m"], state["diagnostics"])
```

Python API는 정상상태 ρ, H/ℏ, Liouvillian과 명시적 reservoir도 반환. 고전 응답에 대한 S1 결과는 준위 인구와 평균 편광으로 표시. 이 상태를 이용한 유한주파수 Langevin 잡음 계산과 homodyne 검출은 [S2 구현](s2.md) 참조.

### 약한 여기 비교

같은 밀도 10¹⁵ m⁻³, v_z=0, r=1000 s⁻¹, B=0에서 양쪽 계산의 optical detuning과 dipole/Rabi 규약을 일치시킴. 기존 `compute_psr_response`는 Doppler off, QWP h=0.05°의 half-step. full-OBE는 ψ=0을 고정하고 ε=±0.025°에서 dψ/dz를 구해 rad 기준으로 중심 차분. 상대 차이의 분모는 기존 계산의 절댓값. [재현 테스트](../../tests/test_psr_full_obe.py)

| I [mW/cm²] | Δ [MHz] | 기존 g [m⁻¹] | full-OBE g [m⁻¹] | g 상대 차이 | α 상대 차이 |
|---:|---:|---:|---:|---:|---:|
| 0.0001 | −600 | 5.65674×10⁻⁶ | 5.65788×10⁻⁶ | 0.02009% | 0.00553% |
| 0.0001 | +350 | −2.00582×10⁻⁴ | −2.00608×10⁻⁴ | 0.01310% | 0.00550% |
| 0.01 | −600 | 5.85015×10⁻⁴ | 5.85128×10⁻⁴ | 0.01934% | 0.00548% |
| 0.01 | +350 | −0.0202108 | −0.0202131 | 0.01136% | 0.00494% |

네 지점에서 χ±의 실수·허수부, 회전 부호와 흡수를 별도로 검사. full-OBE는 서로 다른 바닥 F 사이의 coherence를 유지하고, 전체 상태를 교체하는 reset은 optical coherence에도 r의 감쇠를 추가. 기존 모형은 바닥 F 블록을 secular하게 분리하고 광학 분모에 Γ/2를 사용. 위 수치는 이 근사 차이를 포함한 제한된 운전점 비교임.

추가 검증으로 원자 정상상태의 전력 수지 α I = nℏω₀(Γ+r)Trρ_ee를 독립 계산. Δ=400 MHz, I=12.5 mW/cm², r=10⁵ s⁻¹, n=10¹⁵ m⁻³에서 양변 모두 18.71632 W/m³. 포화의 수치 극한은 고립된 D1 모형의 강한 선형 구동으로 검사. Δ=407.24 MHz에서 I를 10⁷에서 10⁹ mW/cm²로 높이면 여기 인구가 0.2605에서 0.4955로 1/2에 접근. 이 강도는 수학적 극한 검사용이며, 실험 파워 비교에는 실제 beam 정의와 D1 근사의 유효 범위가 필요함.
