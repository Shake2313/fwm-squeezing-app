# PSR 펌프·편광·잡음의 길이 방향 전파

## ⟦AI⟧ 사용법

**Calculation → Rb87 D1 propagated RF squeezing** 선택.

- **Pump intensity**는 셀 입구 세기. **Pump azimuth**, **Pump ellipticity angle**로 입구 Jones 편광 지정.
- **Velocity distribution**에서 단일 속도 또는 Maxwell 열평균 선택. 기본은 단일 속도. 열평균은 구간마다 속도 적분을 반복하므로 계산 시간이 늘어남.
- **Analysis frequency / Quadrature phase**는 실제 출력 편광에 직교하는 모드의 잡음을 표시. 기준은 출력 carrier, 0 dB는 shot noise.
- **Pump propagation** 그림에서 I(z), 편광 방위각 ψ(z), 타원율각 ε(z) 확인. 원편광의 방위각은 미정으로 처리.
- **Length integration**은 셀 분할 수렴 설정. thermal 선택 시 **Thermal integration**도 적용.

기존 단일 속도·열평균 균일 펌프 모드 유지. 기존 모드의 |αL|≤0.3 경계도 유지. 새 전파 모드는 세기 변화를 직접 계산하므로 이 균일 펌프 경계를 사용하지 않음. 원자 상태·양자 잡음·수치 정밀도·분할 수렴 검사는 그대로 적용.

## ⟦AI⟧ 평균장과 잡음 계산

[전파 backend](../../gabes/psr_propagation.py)는 펌프를 `E(z)=exp(i phi) E0(I) u`로 표현. u는 복소 단위 Jones 벡터. 계산 좌표 q=√I·u의 단위는 √(mW/cm²). 전기장 세기 변환은 공통 `beam.field_amplitude` 재사용.

기존 full-OBE 또는 Maxwell 평균의 복소 편극 P로 Maxwell 평균장 미분을 구함.

```text
F(q) = sqrt(I) · i k P(q) / [2 epsilon0 E0(I)]
beta = Im(q† F) / (q†q)
dq/dz = F − i beta q
dphi/dz = beta
```

공통 위상을 별도로 적분해 빠른 굴절 위상 때문에 길이 격자가 불필요하게 촘촘해지는 문제를 줄임. 세기와 두 Jones 성분은 모두 갱신. B=0의 정확한 선형 입력에서는 대칭성 때문에 편광 방향이 유지될 수 있음. 일반 타원 입력에서는 회전과 타원율 변화가 발생함.

각 구간은 explicit midpoint 방식으로 계산. 시작점의 원자 응답으로 중간점 펌프를 예측하고, 그 **중간점 펌프로 포화 원자 상태·복소 K·D^>·D^<를 다시 계산**. 공통 위상 좌표의 drift는 K−iβJ, J=diag(1,1,−1,−1). 기존 `psr_uniform_transfer`의 명시적인 위상률 인수와 공유 `constant_segment`를 사용.

구간을 통과하며 앞에서 발생한 잡음도 이후 구간의 전달 행렬로 전파함.

```text
T_total = T_segment T_previous
N_total = T_segment N_previous T_segment† + N_segment
```

두 잡음 순서에 동일하게 적용하는 기존 [compose_segments](../../gabes/quantum/traveling.py) 재사용. 원자 reservoir가 제공하는 흡수·자연방출·reset 잡음에 별도의 셀 투과 손실 vacuum을 다시 더하지 않음. 외부 광학 손실과 detector QE는 셀 뒤에서 한 번 적용.

열평균은 각 중간점의 Jones 편광·세기로 S3를 재호출. 평균 P·K·D를 먼저 계산한 후 해당 구간을 전파. 구간마다 같은 P·K·D를 고정해서 쓰지 않음.

## ⟦AI⟧ 출력 편광과 위상

새 [출력 homodyne adapter](../../gabes/psr_homodyne.py)는 실제 출력 Jones carrier와 그 직교 편광으로 전체 4-port 전달 행렬·두 ordered noise를 회전한 뒤 기존 homodyne 계산을 호출. 두 입력 편광의 요동은 coherent-state vacuum.

출력 Jones와 전달 행렬은 동일한 공통 위상 좌표를 사용. 이미 분리한 φ를 검출에 다시 더하지 않음. carrier와 광학 출력에 같은 전역 위상을 주면 전체 위상 스캔이 불변임을 실제 구동 원자에서 검증.

Jones 좌표의 위상은 x 성분을 기준으로 정함. |uₓ|≤10⁻¹²에서만 y 성분으로 전환. 이 좌표 선택은 export의 `output_polarization`에 기록. 길이 수렴의 covariance 비교는 공통 실험실 analyzer로 맞춰 좌표 선택의 차이를 물리적 오차로 오인하지 않음.

## ⟦AI⟧ 길이·속도 수렴과 실패 처리

| Length integration | 시작 / 최대 구간 수 | 상대 허용량 | 원자 평가 상한 |
|---|---:|---:|---:|
| Quick | 1 / 8 | 0.02 | 12,000 |
| Balanced | 2 / 32 | 0.005 | 30,000 |
| Fine | 4 / 64 | 0.001 | 80,000 |

분할 수를 두 배씩 늘리고 출력 복소 펌프·세기·편광 projector·누적 위상, 전체 전달 행렬과 양쪽 잡음, 출력 covariance 및 최소·최대 잡음을 비교. 잡음 dB 허용 차이는 max(0.001, rtol) dB. 상대 비교의 절대 바닥값과 실제 최대 오차는 `propagation_convergence`에 연결되는 계산 코드와 검사 결과로 확인 가능.

한 구간에서 펌프가 지나치게 변하면 더 세분화. 최대 구간 수, 원자 평가 예산, 국소 원자·잡음·정밀도 검사에 걸리면 잡음 곡선과 출력 세기 판독은 unavailable. 마지막 계산 경로는 수렴되지 않은 진단용 profile로 명시.

열평균은 각 국소 kernel·cutoff 수렴에 더해, 마지막 적분 차수 및 cutoff의 대체 kernel들을 같은 펌프 경로로 끝까지 전파하는 검사를 수행. 이를 통해 작은 국소 잡음 적분 오차가 셀 전체에서 커지는 경우를 검출. 추가 원자 계산 없이 공유 구간 전파 사용.

이 대체 경로 검사는 **후보 평균 펌프 경로를 고정한 상태의 속도 적분 오차 추정**. 서로 다른 속도 격자로 비선형 평균 펌프 경로 전체를 다시 푼 엄밀한 전역 오차 상한은 아님. 길이·속도 수렴 모두 경험적인 차수 비교이며, 검증 조건 밖에서 물리적 근사의 유효성을 보증하지 않음.

## ⟦AI⟧ Python API와 모델 범위

```python
from gabes.psr_conventions import jones_from_angles
from gabes.psr_propagation import solve_psr_propagation
from gabes.psr_homodyne import psr_output_homodyne_readout

result = solve_psr_propagation(
    400., [-4e5, 4e5], .025, intensity_mw_cm2=12.5,
    jones_xy=jones_from_angles(.31, .17), density_m3=1e17,
    ground_relaxation_hz=1e5, velocity_model="single")
if not result["convergence"]["passed"]:
    raise ValueError(result["convergence"]["status"])
noise = psr_output_homodyne_readout(
    result["transfer"], result["output_jones_xy"], detection_efficiency=.9025)
```

`velocity_model="thermal"`과 `thermal_options`로 S3 적분 설정 적용. `freeze_pump=True`는 균일 펌프 기준 검사 전용. 실제 고갈 계산에서는 기본 False 유지.

범위는 순수 ⁸⁷Rb D1, B=0, 1차원 평면파, 균일한 온도·밀도·reset, 각 위치의 **국소 정상상태 원자**. 원자가 펌프 기울기를 따라 움직이며 운반하는 내부상태 기억, 속도 변경 충돌, 횡방향 빔·공간 모드, 측정 대역 및 입력 기술잡음은 포함하지 않음. 출력 carrier가 충분히 밝다는 선형화 가정도 유지.

UI JSON은 실제 적용 입력과 보관 입력을 구분하고, 펌프 profile, 구간별 α·β·Jones·여기분율·원자 상태 검사, 길이 수렴, 속도 잡음 검사, 최종 T·N과 검출 covariance를 저장. 세기·편광·길이·RF 변경은 해당 경로를 재계산. 검출 효율과 RF/위상 화면 전환은 저장된 전파 결과 재사용.
