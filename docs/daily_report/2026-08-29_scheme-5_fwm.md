# GABES 일일 스킴 물리 검토 — Scheme 5: FWM

- 날짜: 2026-08-29 (Asia/Seoul)
- 선택식: `n = (29 mod 5) + 1 = 5`
- 선택 스킴: `FWMScheme`, key `fwm`, **Four-wave mixing (Gain diagnostic / Biphoton)**
- 관점: warm-vapor double-Λ FWM, balanced intensity-difference 검출, 원자 biphoton 실험을 수행하는 연구자

## 요약 판단

Scheme 5는 **실제 물리를 계산하는 유용한 반정량 실험 설계 도구**다. Seeded 경로는
⁸⁵Rb D1 hyperfine double-Λ, 충돌·thermal transit reset, Doppler 평균, finite-seed
Floquet OBE, Maxwell–Bloch 전파와 위상정합을 포함한다. Biphoton 경로는 cascade/diamond
topology, velocity-class coherent sum, Autler–Townes denominator, vector phase matching,
timing convolution과 detector/background ledger를 포함한다
(`gabes/schemes/fwm.py:1-13`, `52-114`, `1182-1570`, `2406-2848`).

그러나 실험 reference로서의 신뢰 범위는 명확히 제한해야 한다.

1. **Seeded FWM**은 detuning, 온도, 세기, 셀 길이, 교차각의 민감도와 후보 동작점
   탐색에는 유용하다. 기본점의 full-scan Floquet gate는 `CONVERGED`지만,
   `G_s=406.9205`, photon-flux gap `−2.3796`, commutator defect `3.4591`이며 독립
   audit의 `G_s=403.5355`도 문헌 약 15.5보다 2503.5% 크다. 같은 reduced model 안의
   수치 수렴은 절대 이득이나 물리적 squeezing 검증이 아니다.
2. **Biphoton**은 파형 ordering, collection geometry, jitter/filter/window trade-off의
   정성·반정량 설계에 유용하다. 하지만 절대 pair rate는 reference-anchored이고,
   검출폭 일치는 입력 timing response를 재사용하며, coincidence gate도 현재 잘못
   적용된다. 절대 brightness, `g²`, CAR, ns 폭의 독립 예측으로 인용하면 안 된다.
3. 2026-08-28에 추가된 열·초과잡음 보고서는 동일조건 SQL, EOM/laser/electronics,
   near-2-MHz feature를 구분하는 실험 진단 자료로 가치가 높다. 다만 스스로 밝히듯
   microscopic Langevin diffusion과 detector transfer가 없어 squeezing spectrum은
   계산하지 않는다
   (`docs/fwm_thermal_excess_noise_report/README.md:1-32`,
   `docs/fwm_thermal_excess_noise_report/scripts/generate_analysis.py:10`, `878-885`).

가장 큰 개선 효과는 새 고차원 원자 모델보다 **이미 제안된 trust boundary, detector
후처리, 캐시 분리와 문서 정합성**을 닫는 데서 나온다. 이들 대부분은 atomic solve를
늘리지 않고 물리를 보존하거나, 잘못된 후처리만 바로잡는다.

## 4. Seeded ⁸⁵Rb FWM의 물리적 가치와 한계

### 유용한 실제 물리

- ⁸⁵Rb D1의 F=2,3 ↔ F'=2,3 전이에 `sqrt(3 C_F²)`를 drive/readout에 사용하고,
  trace-normalized state가 manifold population을 한 번만 공급한다. 외부 구조 계수는
  `1/[2(2I+1)]=1/12`다 (`gabes/schemes/fwm.py:38-85`).
- collision broadening, ground-Raman dephasing, trace-preserving thermal transit reset과
  pure-⁸⁵Rb vapor density가 온도별 atom model에 들어간다
  (`gabes/schemes/fwm.py:2314-2381`).
- finite-order Floquet density matrix를 velocity class와 scan 전체에서 풀고 N_F=3과
  N_F=2의 complex response, transfer, gain, phase, optimum을 비교한다
  (`gabes/schemes/fwm.py:269-455`, `2052-2133`, `2539-2669`).
- bare frequency-specific wavevector와 vacuum/geometric mismatch를 쓰는 Option-A
  Maxwell 전파, segment/overlap, post-hoc Manley–Rowe cap을 분리한다
  (`gabes/schemes/fwm.py:2174-2309`, `2567-2685`).

이 구성은 상대적인 knob sensitivity, 공명 branch, feature 위치, 수치 truncation과
propagation convention을 점검하는 데 충분히 물리적이다.

### 오늘 기본점 재계산

조건: Δ=+0.9 GHz, δ=−8 MHz, 121 °C, L=12.5 mm, pump=600 mW,
wanted seed=8 µW, angle=0.32°, post-cell loss=5.5%, QE=92%, Fast 181점,
297 velocity classes.

| 항목 | 값 |
|---|---:|
| 새 Python process 첫 compute | 3.638 s |
| 같은 process warm compute | 2.484 s |
| `G_s` / `G_c` | 406.920464 / 409.231143 |
| gain-referred diagnostic | −8.654249 dB |
| small-signal photon-flux gap | −2.379569 |
| 동작점 commutator defect | 3.459118 |
| scan 최대 commutator defect | 75.297592 |
| Floquet gate | `CONVERGED` |
| validation level | `MEAN_FIELD_DIAGNOSTIC` |

`operating_point()`는 표시 δ를 scan point 사이에서 보간한다
(`gabes/schemes/fwm.py:2851-2917`). 따라서 가장 가까운 격자점 값을 읽는 대신 위 보간값을
사용했다. 독립 analytic audit는 `G_s=403.535497`, `G_c=405.853591`, gap
`−2.311543`을 고정하고 문헌 약 15.5 대비 2503.5% 차이를 기록한다
(`tests/test_fwm_docs_consistency.py:72-86`,
`analysis/squeezing/analytic_reconstruction/generated/convergence_audit.md:318-330`).

### 실험 reference로서의 한계

- `CONVERGED`는 같은 reduced model의 Floquet truncation 수렴이다. absolute gain,
  manifold completeness, covariance나 experiment agreement를 증명하지 않는다.
- transfer가 canonical Bogoliubov map이 아니고 microscopic distributed diffusion이 없다.
  그래서 `physical_squeezing_dB=None`, `S_dB`는 compatibility alias다
  (`gabes/schemes/fwm.py:2752-2763`).
- 0.74 residual, mode/polarization/Zeeman penalties, transit floor와 pump-scatter coefficient는
  독립 calibration/uncertainty가 없다 (`gabes/schemes/fwm.py:543-568`, `3039-3092`).
- production은 1-D velocity average다. 2-D reference의 121 °C, 0.32° Raman rms
  1.380 MHz는 수렴했지만 opt-in audit일 뿐이다
  (`docs/checklist.json:762-786`, `README.md:246-257`).

따라서 seeded mode는 **동작점 후보와 민감도 reference**로는 적합하지만 **절대 이득,
IDS squeezing 크기·대역폭, SQL 상하의 reference**로는 부적합하다.

## 5. Generic SFWM / biphoton의 물리적 가치와 한계

Predictive 경로는 Ω_c² Autler–Townes term, velocity-class coherent sum, natural decay,
velocity-grid 자동 세분화, vector phase match, optional OD reshaping을 포함한다
(`gabes/schemes/fwm.py:1251-1414`, `1416-1567`). 오늘 ⁸⁷Rb telecom 기본값은 다음과 같다.

| 항목 | 값 |
|---|---:|
| source compute | 0.0770 s |
| headless observables | 0.398 ms |
| intrinsic source FWHM | 0.172600 ns |
| detected FWHM (0.55 ns timing response) | 0.496522 ns |
| velocity step / status | 0.541239 m/s / converged |
| anchored raw pair rate | 380.000 cps |
| 300-MHz scalar throughput 뒤 rate | 124.622727 cps |
| `g²` peak / CAR | 308.710 / 307.710 |

물리적으로 유용한 것은 파형 형태·wavelength ordering·phase-match geometry와 detector
trade-off다. 절대값에는 다음 한계가 있다.

- pair rate는 pump, sqrt(coupling scale), vector phase match, sqrt(density ratio)에만
  직접 비례하며 OD/cell length는 absolute rate를 정하지 않는다
  (`gabes/schemes/fwm.py:1462-1472`).
- filter는 transfer function이 아니라 `min(1, BW_filter/BW_source)` scalar다
  (`gabes/observables.py:310-315`).
- “Predictive/first-principles”라는 aggregate label이 waveform, anchored rate, detector
  convolution의 서로 다른 evidence level을 가린다
  (`gabes/schemes/fwm.py:2963-2975`, `3745-3756`, `3969-3982`).

### 확인된 coincidence-window 오류

`biphoton_stats()`는 accidental에 window를 곱하지만 true coincidence는 window와 무관하게
둔다 (`gabes/observables.py:322-340`). 같은 waveform에서:

| window | true coincidence | CAR |
|---:|---:|---:|
| 0.05 ns | 1.246227 cps | 6154.202 |
| 1.00 ns | 1.246227 cps | 307.710 |

즉 window→0에서 true count가 줄지 않고 CAR가 발산한다. 현재 테스트는 background와
window를 함께 바꿔 CAR가 감소하는지만 검사한다
(`tests/test_fwm_generic.py:128-140`). detected delay PDF를 gate 정의에 맞게 적분해 true
coincidence에 곱하고, peak/bin `g²`와 gate-integrated CAR를 분리해야 한다. 비용은 이미
계산한 481-point 파형의 O(Nτ) 적분뿐이며 source physics와 atomic solve는 보존된다.

## 6. 기존 개선 제안의 비용과 물리 보존성

| 기존 제안 | 상태 | 계산 비용 | 물리 보존성 / 판단 |
|---|---|---|---|
| Biphoton observable별 provenance/trust | ready P1 | O(1) metadata | waveform, anchored rate, detector convolution을 분리할 뿐 수치를 바꾸지 않는다. 즉시 적용 가치가 높다. |
| Seeded source/detection trust·cache 분리 | ready P1 | O(1)–O(n_scan) 후처리 | raw transfer/gain과 capped/display 값을 분리하면 source physics가 보존된다. |
| Exact unequal-loss covariance | ready P1 | O(n_scan) 2-arm algebra | atomic solve 추가 없음. 출력은 바뀌지만 현재 ad-hoc covariance의 물리 오류를 고치는 변화다. Full covariance가 없으면 unavailable이어야 한다. |
| Option-A/loss ledger와 segment convergence | ready P1 | 2×2 propagation O(n_scan·n_seg) | OBE보다 싸다. 32/64 segment 비교는 opt-in/offline이면 기본 overhead가 거의 없다. Microscopic noise를 대신하지 않는다. |
| Coupling/normalization provenance | ready P1 | ledger O(1); parameter endpoint는 추가 solve | one-use ledger와 unknown status는 무료다. γ_transit endpoint 재계산은 offline sensitivity가 적절하다. |
| Coincidence gate integration | 이전 Scheme 5 보고서, 미구현 | O(Nτ)=O(481) | source solve를 그대로 두고 detector gate만 바로잡는다. |
| 실제 filter transfer | 이전 Scheme 5 보고서, 미구현 | O(Nτ log Nτ) | FFT filter/IFFT 후처리. scalar throughput보다 실험적으로 유용하며 원자 물리를 보존한다. |
| Microscopic Langevin | parked research | Ω_SA×velocity×segment covariance 전파 | 물리적 squeezing에는 필요하지만 negligible-overhead가 아니다. 현재 trust gate를 먼저 닫아야 한다. |
| 24-level Zeeman Floquet | parked research | density-vector 16→576; dense 기준 계산 급증 | 단순 dense 산술은 상태벡터 비 36의 세제곱 규모까지 커질 수 있다. polarization/B holdout data 없이는 비용 대비 식별력이 낮다. |
| Held-out biphoton/squeezing validation | blocked_external | 데이터 취득·calibration 비용 지배 | 같은 자료를 fit과 validation에 재사용하지 않는 predeclared split이 필요하다. 코드만으로 해결할 수 없다. |

낮은 비용으로 물리를 보존할 수 있는 항목은 provenance/status, source/detection cache 분리,
coincidence gate, filter transfer다. Exact covariance는 싸지만 **잘못된 현재 동작을 보존하면
안 되는 physics correction**이다. Langevin/Zeeman은 연구 프로젝트이므로 “거의 무료 개선”에
넣으면 안 된다.

## 7. 순수 코드 최적화 후보

### 7.1 `loss_pct`와 `qe_pct`를 atomic cache key에서 분리

현재 두 `ParamSpec`은 `recompute=False`가 없어 전체 N_F=3/N_F=2 solve를 다시 돌린다
(`gabes/schemes/fwm.py:3039-3049`, `3394-3396`). 하지만 두 값은 검출 η와 gain-referred
후처리에만 필요하다.

- loss 0% compute: 2.1084 s
- loss 35% compute: 2.1026 s
- 두 결과의 `G_s`, `G_c`, `T_field_small_signal`: bitwise identical
- 같은 gain array의 η remap: median 14.70 µs

따라서 source/detection result를 분리하면 약 143,000배 싼 반응이 가능하다. 기존 수식과
array를 그대로 사용하고 Fast/Balanced/Ultra, 여러 η의 exact-equivalence test를 추가하면
behavior-preserving이다. checklist의 gain-only trust boundary acceptance criterion에도 이미
이 분리가 명시돼 있다 (`docs/checklist.json:646-678`).

### 7.2 Biphoton 1-D angle trace vectorization

figure 경로는 181개 angle을 Python loop로 `phase_mismatch_vector()`에 전달한다
(`gabes/schemes/fwm.py:3659-3671`). 이미 vectorized
`phase_mismatch_vector_grid()`가 있다 (`gabes/schemes/fwm.py:901-926`).

- loop: 0.5392 ms
- vectorized: 0.0600 ms
- speedup: 8.99×
- phase-matching weight 최대 절대차: `3.48e-19`

절대 절감은 작지만 완전히 behavior-preserving인 정리다.

### 7.3 Cs 반대 channel raw-result bounded cache

Cs validation table은 매 observables 호출에서 선택하지 않은 channel source를 다시 푼다
(`gabes/schemes/fwm.py:3920-3937`). 반복 headless 호출 median은 28.14 ms였다.
`_solver_from_topology_key()`는 solver 객체만 cache하고 source result는 cache하지 않는다
(`gabes/schemes/fwm.py:1571-1576`). detector-only knob와 source key를 분리한 뒤 immutable
source result를 bounded cache하면 파형과 출력 값을 바꾸지 않고 이 비용을 없앨 수 있다.

## 8. 문서·테스트·예제의 experimental-reference 적합성

### 강점

### 남은 reference 위험

1. **오래된 FWM 그림.** `docs/Userguide/userguide_assets/fwm.png`는 G_s≈12,
   η=0.855, “Intensity-difference squeezing”을 표시한다. 현재 plot은 G_s≈407과
   “Gain-referred noise diagnostic”이다 (`gabes/schemes/fwm.py:3439-3458`). 현재 figure로
   교체하는 비용은 offline solve 1회, 앱 overhead 0이다.
2. **Biphoton aggregate claim.** README/UI의 Predictive/first-principles 표현은
   waveform prediction과 anchored rate/detector convolution을 충분히 분리하지 않는다
   (`README.md:198-222`). 기존 `biphoton-source-trust-boundary`를 적용해야 한다.
3. **Stale nonclassicality test.** `tests/test_coincidence.py:35-48`은 production `G_s>1`에
   ideal TMSV 공식을 적용해 nonclassical/Cauchy–Schwarz violation을 단언한다. 현재
   noncanonical transfer와 missing covariance에서는 ideal fixture로만 허용해야 하며,
   production path는 unavailable을 요구해야 한다.
4. **Low-pump body의 과도한 결론.** 파일 맨 위 claim gate는 좋아졌지만 결론의 “squeezing
   수준이 아니다”는 문구는 physical prediction처럼 읽힌다. measured-gain-in ideal-law
   conditional statement로 좁혀야 한다.
5. **Thermal report 재생성 테스트 부재.** generator는 hash와 convergence를 잘 기록하지만
   현재 `tests/`에는 이 report의 schema/claim gate/재생성 smoke test가 없다. 전체 expensive
   generation 대신 JSON schema와 quick deterministic slice만 검사하면 낮은 CI 비용으로
   provenance drift를 막을 수 있다.

## 10. 실험 연구자용 최종 권고

현재 Scheme 5를 다음 용도로 사용하면 가치가 높다.

- seeded: branch/detuning/온도/intensity/length/geometry 민감도, 후보 동작점,
  Floquet와 propagation convention 점검
- biphoton: waveform ordering, vector phase matching, jitter/filter/gate 설계의 방향성
- 새 thermal report: near-2-MHz feature, coherent contamination, 동일조건 SQL,
  EOM/laser/electronics/atomic 후보를 분리하는 측정 순서

다음 용도로는 사용하지 말아야 한다.

- 기본 `G_s`나 dB 곡선을 장치의 절대 gain/IDS squeezing 예측으로 인용
- `CONVERGED` 또는 내부 invariant를 experiment validation으로 해석
- Predictive biphoton rate/`g²`/CAR/detected width를 독립적인 논문 재현으로 인용
- `G_s>1`만으로 nonclassicality 또는 Cauchy–Schwarz violation을 주장
- 현재 frequency-response plot을 microscopic squeezing spectrum으로 해석

우선순위는 다음이 적절하다.

1. loss/QE cache 분리, coincidence gate 적분, stale FWM 그림과 low-pump 결론 문구 수정
2. biphoton observable별 provenance와 seeded gain-only trust boundary 완결
3. exact unequal-loss covariance와 Option-A/loss ledger 마무리
4. raw held-out 데이터와 detector transfer/동일조건 SQL 확보 후에만 microscopic
   Langevin 및 Zeeman reference를 활성화

1–2단계는 atomic solve를 거의 늘리지 않으면서 실험 reference의 가장 큰 오해와 대기시간을
동시에 줄인다.
