# GABES 일일 스킴 물리 검토 — Scheme 5: FWM

- 날짜: 2026-08-04 (Asia/Seoul)
- 선택식: `n = (4 mod 5) + 1 = 5`
- 선택 스킴: `FWMScheme`, `name="fwm"`, **Four-wave mixing (Squeezing / Biphoton)**
- 관점: warm-vapor FWM·세기차 스퀴징·원자 biphoton 실험을 수행하는 연구자

## 요약 판단

Scheme 5는 두 성격이 다른 물리 도구를 한 UI에 묶는다.

1. **Seeded ⁸⁵Rb D1 double-Λ FWM**은 실제 hyperfine line strength와 branching,
   온도 의존 밀도·충돌 완화, Doppler 평균, 3-mode Floquet 응답,
   Maxwell–Bloch 전파와 위상 부정합을 연결한다. detuning·온도·셀 길이·광파워·교차각의
   경향과 실험 동작점을 찾는 데 유용한 **반정량 reference**다. 그러나 Sim et al. 기준으로
   맞춘 residual `0.74`, 현상론적 Ultra 잡음, 고정 `N_F=1`, 미포함 교차각 2광자 Doppler,
   full quantum-Langevin/Zeeman 부재 때문에 절대 스퀴징 계측 기준은 아니다.
2. **Generic SFWM biphoton**은 velocity-class coherent waveform, vector phase matching,
   검출 효율·dark count·timing response·CAR를 함께 보는 좋은 source-design 도구다. 다만
   absolute pair rate는 여전히 reference anchor이고, filter와 coincidence-window 처리는
   완전한 계수 히스토그램 모델이 아니다. 절대 brightness·`g²`·시간폭을 논문 재현값으로
   인용해서는 안 된다.

오늘 가장 중요한 새 판단은 다음 두 가지다.

- 기본 교차각 `0.32°`가 만드는 잔류 2광자 Doppler 표준편차는 약
  `1.36–1.38 MHz`로, 현재 기본점의 ground-coherence relaxation
  `γ_gg/2π = 0.103 MHz`보다 약 13배 크다. 각도는 현재 전파 위상정합에만 들어가고 원자
  Raman detuning 분포에는 들어가지 않는다.
- biphoton `coincidence_window_ns`는 accidental에만 곱해지고 true coincidence에는
  반영되지 않는다. 따라서 작은 window에서 CAR이 인위적으로 `1/W`로 발산한다. 기본
  `1 ns`에서는 계산된 포획률이 98.7%라 기존 기본값은 거의 보존되지만, 허용 범위 전체는
  실험 설계 reference로 안전하지 않다.

## 3. 현재 구현된 실제 물리와 실험적 가치

### 3.1 Seeded ⁸⁵Rb D1 double-Λ

구현의 실질적인 장점은 다음과 같다.

- `F=2,3 ↔ F'=2,3`의 D1 `3 C_F²`를 drive와 polarization readout에 적용하고
  (`gabes/schemes/fwm.py:26-61`, `1085-1147`), decay branching도 같은 hyperfine
  strength로 정규화한다 (`gabes/atoms.py:101-139`; `tests/test_regression.py:164-182`).
- pure-⁸⁵Rb CRC 밀도와 density-dependent optical self-broadening·ground Raman
  relaxation을 매 온도마다 dissipator에 반영한다 (`gabes/schemes/fwm.py:1427-1448`,
  `1523-1531`).
- 각 two-photon detuning과 optical Doppler class에서 두 개의 probe/conjugate reference
  solve로 `χ_ss, χ_cs, χ_sc, χ_cc`를 구하고 Doppler 평균한다
  (`gabes/schemes/fwm.py:1150-1225`, `1533-1557`).
- 두 Raman branch를 서로 다른 mode pair로 취급하고 합산을 금지한다
  (`gabes/schemes/fwm.py:1451-1467`; `tests/test_regression.py:141-161`).
- susceptibility를 2×2 Maxwell–Bloch 전달행렬로 전파해 seed/conjugate gain을 구한다
  (`gabes/observables.py:17-84`). 고온 runaway에는 Manley–Rowe energy cap을 적용한다
  (`gabes/observables.py:87-115`).
- Fast는 vacuum phase mismatch, Balanced는 refractive/segmented propagation, Ultra는
  64-segment dynamic pump budget·Gaussian overlap·arm-resolved absorption·pump-scatter
  noise를 더한다 (`gabes/schemes/fwm.py:1573-1688`, `1762-1779`).

따라서 실험자가 detuning·온도·cell·power·angle 경향을 훑고 대략적인 동작점을 잡는 데는
실제 가치가 있다. 그러나 다음은 reference 경계다.

- macroscopic coupling은 first-principles `p_F/[2(2I+1)]` 위에 Sim et al. residual
  `0.74`를 곱한다 (`gabes/schemes/fwm.py:43-88`, `1501-1515`).
- Ultra pump-scatter `κ=0.1`은 독립 측정으로 검증된 값이 아니다
  (`gabes/schemes/fwm.py:128-137`, `1656-1688`).
- 24-level Zeeman은 CG-sum diagnostic이며 main solve가 아니다
  (`gabes/schemes/fwm.py:1606-1625`).
- `S_dB`는 classical gain에서 구성한 이상적/현상론적 noise readout이며 full
  Langevin source noise가 아니다 (`gabes/observables.py:256-387`).
- Fast/Balanced/Ultra는 단순 수치해상도 tier가 아니다. Ultra는 noise physics 자체도 바꾼다.

### 3.2 Generic SFWM / biphoton

지원 topology는 ⁸⁷Rb 780/1529-nm telecom cascade, ¹³³Cs 852/917 또는 852/795-nm
BTW cascade, 검증되지 않은 generic diamond template이다
(`gabes/schemes/fwm.py:492-639`).

Predictive 경로는 다음 실제 물리를 포함한다.

- `Ω_c²` Autler–Townes term이 든 two-photon denominator, Maxwell velocity-class
  coherent sum, natural-linewidth decay (`gabes/schemes/fwm.py:758-804`)
- source resonance를 측정하고 waveform FWHM이 3% 이내로 안정될 때까지 velocity grid를
  반으로 줄이는 수렴 제어 (`gabes/schemes/fwm.py:842-921`)
- calibrated longitudinal mismatch와 absolute transverse mismatch를 결합한
  vector `sinc²(|Δk|L/2)` (`gabes/schemes/fwm.py:307-359`, `936-958`)
- intrinsic/source 폭과 timing-response-broadened detected 폭의 분리,
  detector efficiency·dark count·accidental·CAR·heralding 계산
  (`gabes/observables.py:174-253`; `gabes/schemes/fwm.py:2320-2557`)

반면 absolute pair-rate 식은 `pump × sqrt(coupling scale) × phase match ×
sqrt(N/N_ref)`이며, waveform에 OD가 들어가도 cell length/OD는 표시 rate에 직접 들어가지
않는다 (`gabes/schemes/fwm.py:969-979`). 그러므로 geometry와 channel ordering은 유용하지만
absolute brightness는 독립 예측이 아니다.

### Seeded 기본점

공통 조건은 OPD `+0.9 GHz`, TPD `-8 MHz`, `121 °C`, `12.5 mm`, pump `600 mW`,
seed `8 µW`, external loss `5.5%`다.

| fidelity | wall time | `G_s` | `G_c` | squeezing | velocity classes |
|---|---:|---:|---:|---:|---:|
| Fast | 2.502 s (JIT 포함) | 5.586105 | 4.637712 | -6.836490 dB | 297 |
| Balanced | 0.872 s (warm) | 13.896793 | 12.992370 | -8.039521 dB | 591 |
| Ultra | 3.525 s (warm) | 13.828895 | 12.924426 | -7.081927 dB | 1573 |

Fast가 gain을 크게 덜 잡고, Balanced와 Ultra gain은 약 0.5% 이내지만 squeezing은 약
0.96 dB 다르다. 후자는 수렴 오차라기보다 Ultra arm-loss/pump-scatter noise 차이다.

| 항목 | 값 |

## 5. 중요 발견과 저비용 물리 개선

### 5.1 P0 trust boundary — 교차각 2광자 Doppler가 원자 응답에 빠져 있다

현재 `seeded_angle_deg` 도움말은 angle이 phase mismatch를 정한다고 명시하고
(`gabes/schemes/fwm.py:1867-1872`), 실제로도 `compute_spectrum()`의 전파 Δk에 전달된다
(`gabes/schemes/fwm.py:1573-1605`, `2191`). 그러나 atomic susceptibility 쪽
`delta_axis`는 lab probe frequency만으로 정해지고 (`gabes/schemes/fwm.py:1547-1549`),
velocity shift는 optical excited-state detuning에만 들어간다 (`gabes/atoms.py:101-139`,
`gabes/core.py:124-175`). 즉 교차각이 만드는 `Δk_2γ·v` Raman 분포는 없다.

저장소의 기존 수렴 감사도 이 사실을 명시한다.

- production `floquet_solve`/kernel은 `N_F=1`이고 two-photon detuning을 velocity와 분리하지
  못한다 (`analysis/squeezing/analytic_reconstruction/generated/convergence_audit.md:161-169`).
- 그 감사의 기본 교차각 추정은 omitted one-sigma angular width `1.361 MHz`다
  (`.../convergence_audit.md:166-168`).
- 오늘 현재 상수로 다시 계산하면 `σ_2γ ≈ 1.380 MHz`, 반면
  `γ_gg/2π = 102.9 kHz`다.

실험적으로 이것은 작은 보정이 아니다. 좁은 Raman feature, optimal TPD, gain gap과 squeezing
위치를 바꿀 수 있다.

권고는 두 단계다.

1. **즉시/무부하:** `σ_2γ`와 `σ_2γ/γ_gg`를 derived table에 표시하고, angle>0에서
   “atomic angular Doppler not included” 상태를 hero 근처에 둔다. 추가 solve가 없다.
2. **저비용 correction:** lab beat `Ω_beat`는 고정한 채 atomic Raman detuning만 이동하도록
   API를 분리한다. 기본 작은 각도에서는 transverse velocity가 pump-axis velocity와 독립이므로,
   현재 Doppler-averaged `χ(δ)`를 `σ_2γ` Gaussian으로 convolution하는 reference correction은
   `O(n_δ log n_δ)`이며 행렬 solve를 늘리지 않는다. 작은-grid 2-D velocity quadrature와 비교해
   이 근사가 유효한 각도 범위를 테스트해야 한다. 완전한 non-collinear 2-D velocity solve는 더
   무겁고 기본 경로로 켤 필요가 없다.

### 5.2 P1 — coincidence window가 true coincidence를 자르지 않는다

`biphoton_stats()`는

- `coincidence = pair_rate × η_s × η_i`로 두고 (`gabes/observables.py:211-215`),
- accidental에만 `coincidence_window_ns`를 곱한다 (`gabes/observables.py:216-230`).

따라서 window를 줄여도 true coincidence가 전혀 줄지 않는다. 기존 테스트는 background와
window를 동시에 바꾸고 CAR가 감소하는지만 검사해 이 문제를 잡지 못한다
(`tests/test_fwm_generic.py:127-139`).

오늘 telecom 기본 waveform을 현재 timing response로 smooth한 뒤, start–stop 양의 지연축
`[0,W]`에 들어오는 정규화된 area를 보수적으로 적분했다.

| window `W` | 현재 true coincidence | 현재 CAR | 계산된 gate 포획률 | gate 반영 CAR |
|---:|---:|---:|---:|---:|
| 0.05 ns | 1.24623 cps | 6154.20 | 0.0851 | 523.91 |
| 0.10 ns | 1.24623 cps | 3077.10 | 0.1762 | 542.10 |
| 0.50 ns | 1.24623 cps | 615.42 | 0.7987 | 491.54 |
| 1.00 ns | 1.24623 cps | 307.71 | 0.9872 | 303.78 |
| 12.0 ns | 1.24623 cps | 25.64 | 1.0000 | 25.64 |

정확한 구현은 acquisition convention을 먼저 명시해야 한다.

- gate-integrated CAR이면 detected delay PDF를 정규화하고 선언된 one-sided 또는 symmetric
  window의 적분확률 `P_gate(W)`를 true coincidence에 곱한다.
- histogram-bin `g²_peak`이면 bin width/IRF 정규화를 gate-integrated CAR와 분리한다.

두 경우 모두 이미 계산한 481점 waveform을 쓰는 `O(N_τ)` 후처리다. source solve는 재사용되고
기본 `1 ns` 결과도 약 1.3%만 변하므로, 물리를 살리면서 overhead는 사실상 무시할 만하다.
테스트는 `W→0`에서 true coincidence가 0으로 가고 CAR/`g²`가 비물리적으로 발산하지 않는지,
큰 W에서 현재 full-pair limit를 회복하는지를 따로 고정해야 한다.

### 5.3 기존 Floquet 수렴 감사가 보여 주는 외삽 경계

production solver는 3-mode, 즉 `N_F=1`로 고정된다 (`gabes/core.py:124-175`;
`gabes/kernels.py:170-273`). 기존 analysis 감사의 결과는 균일하지 않다.

- Sim literature point에서는 `N_F=1→2`가 `G_s=5.60950→5.61434`,
  `G_c=4.66125→4.66816`으로 0.1% 미만이며 `N_F=2,3`은 일치한다
  (`.../convergence_audit.md:68-80`). 기본점은 현 truncation이 충분하다.
- 다른 공통점 `Δ=-1.5 GHz, T=110 °C, δ=-280 MHz`에서는 `N_F=1→2`가
  `G_s` 16.8%, `G_c` 13.0%를 바꾸고, `N_F=2,3`은 수렴한다
  (`.../convergence_audit.md:18-41`).
- 같은 reference script의 runtime은 `N_F=1/2/3 = 3.10/6.73/9.32 s`로 약
  `1×/2.17×/3.01×`였다 (`.../convergence_audit.json:33-103`).

따라서 N_F=2를 기본으로 켜는 것은 “무부하 개선”이 아니다. 기본 Sim preset은 N_F=1을 유지하되,
외삽 scan에 no-cost provenance/status를 붙이고, 별도 slow convergence view에서 N_F=2를 비교하는
편이 적절하다.

## 6. 순수 코드 최적화

### 6.1 최우선 — `loss_pct`를 heavy solve cache key에서 분리

`loss_pct`는 현재 기본 `recompute=True`다 (`gabes/schemes/fwm.py:1873-1875`;
`gabes/schemes/base.py:44-56`). 그러나 solve에서 loss는 `η=QE(1-loss)`만 만들고
(`gabes/schemes/fwm.py:1515`), `χ`, Doppler average, `G_s`, `G_c` 뒤의 noise 식에만 들어간다
(`gabes/schemes/fwm.py:1542-1690`).

07-29 검토는 loss `0/35%`에서 gain 배열이 bitwise 동일하고, loss-only noise remap이
`0.0284 ms` median임을 확인했다. Ultra tolerance 예제도 raw gain/arm OD를 재사용해 analytic
loss remap을 수행한다 (`analysis/squeezing/scan_squeezing_v6_tolerance.py:146-164`).

권고:

1. `loss_pct`를 `recompute=False`로 바꾼다.
2. raw gain, `segment_absorption_od`, `hardened_noise` arm-OD arrays를 사용해 observables에서
   현재와 동일한 `S_dB`를 다시 계산한다.
3. Fast/Balanced/Ultra와 여러 loss 값에서 기존 결과와 bitwise 또는 tight-tolerance 동등성을
   테스트한다.

이는 물리·격자·gain을 바꾸지 않는 behavior-preserving cache/postprocess 분리다.

### 6.2 보조 최적화

1. **Cs 반대 channel raw solve cache.** validation table은 선택하지 않은 channel을 observables
   호출마다 다시 푼다 (`gabes/schemes/fwm.py:2633-2650`). source-physics key bounded cache와
   detector-only 재계산을 분리하면 물리 불변이다. 07-24 측정에서는 headless 28.16 ms 중 반대
   channel solve가 27.33 ms였다.
2. **1-D angle trace vectorization.** figure 경로의 181-angle Python loop
   (`gabes/schemes/fwm.py:2372-2384`)를 이미 있는 `phase_mismatch_vector_grid()`
   (`gabes/schemes/fwm.py:408-433`)의 1×N 사용으로 바꿀 수 있다. 기존 측정은
   `0.537→0.058 ms`, max difference `1.76e-18`이었다.
3. **현재 fused kernel 유지.** `chi_matrix_table()`의 Numba fused path와 NumPy reference를
   테스트로 계속 고정한다 (`gabes/schemes/fwm.py:1150-1225`; `tests/test_kernels.py`).
   N_F 확대와 현재 N_F=1 최적화를 한 구현으로 섞지 않는 편이 안전하다.

## 7. 문서·테스트·예제의 reference 적합성

### 강점

- frozen seeded baseline이 기존 FWM 경로의 drift를 막는다
  (`tests/test_regression.py:21-50`).
- branch convention, D1 hyperfine strength, factorized residual, loss/noise 단조성,
  phase matching, wrong-side suppression, timing jitter, Cs width ordering, lazy phase map을 각각
  테스트한다 (`tests/test_regression.py:67-196`; `tests/test_fwm_generic.py:60-615`).
- README와 app info는 anchored rate, approximate width, full Langevin 부재를 숨기지 않는다
  (`README.md:179-204`; `gabes/schemes/fwm.py:2106-2163`).
- `scan_squeezing_v6_tolerance.py`는 loss를 재풀이 없이 remap하는 좋은 실험 허용오차 예제고,
  `analytic_reconstruction/convergence_audit.py`는 N_F와 velocity cutoff의 신뢰 경계를 수치로
  분리한다.

### 남은 문서·예제 위험

- User Guide의 FWM 그림 설명은 gain 약 12, IDS 약 -8 dB라고 쓰지만 현재 기본 Fast readout은
  `5.586/-6.836 dB`다 (`docs/Userguide/GABES_User_Guide_v2.html:622-632`). fidelity와 생성
  provenance를 그림에 고정해야 한다.
- `bench_numba_fwm.py`는 app-fast를 `121,dv=5`, app-fine을 `301,dv=2`라고 부르지만 현재
  Fast/Balanced는 `181,dv=4`와 `301,dv=2`다
  (`analysis/squeezing/bench_numba_fwm.py:7-34`; `gabes/schemes/fwm.py:1762-1779`).
- archived CLI는 표시 밀도에 natural-abundance `atoms.rb85_density`를 쓰지만 backend는
  pure-85 `hyperfine.number_density`를 쓴다 (`archive/fwm_obe.py:28,69`;
  `gabes/schemes/fwm.py:1523-1526`).
- seeded 분석 예제는 풍부하지만, biphoton의 window/filter/rate convention을 실측
  histogram과 비교하는 독립 batch example은 없다. 현재 가장 가까운 예는 unit test와 app table이다.
- `FWM_physics.tex:1524-1548`은 filter가 throughput-only임은 밝히지만 true coincidence의
  window 포획률이 생략됐다는 설명은 없다.

코드는 주석·검증·한계 표기가 좋은 **계산 구현 reference**다. 그러나 실험 reference로는 각
숫자의 분류가 필요하다: `measured / paper theory / anchored / predicted / diagnostic`. 이 분류가
없는 figure·preset·`g²` hero는 실제 데이터와의 비교에서 오해를 만들 수 있다.

## 8. 우선순위 권고

1. **P0 — 교차각 2광자 Doppler trust status와 저비용 convolution reference path.** 먼저
   `σ_2γ/γ_gg` 경고를 무부하로 추가하고, 이후 lab beat와 atomic detuning을 분리한다.
2. **P0 — paper-specific preset/provenance.** 온도·cell·detuning·optical power·backend Rabi·
   linewidth·fidelity·delay convention을 하나의 preset/표에 묶고 값의 출처 분류를 표시한다.
3. **P1 — coincidence gate 포획률과 `CAR_gate`/histogram `g²_peak` 분리.** 481점 후처리만으로
   기본값을 거의 보존하면서 전체 window 범위를 물리적으로 만든다.
4. **P1 — waveform norm 기반 상대 brightness.** fixed-domain reference norm으로 cell/OD/drive
   sweep의 상대 발생률을 연결하되 기존 `ψ` factor를 이중 계산하지 않는다.
5. **P1 — 실제 filter transfer option과 temporal-resolution/delay status.** source solve를
   재사용하므로 overhead는 작다.
6. **P1 성능 — `loss_pct` postprocess 분리.** 가장 큰 behavior-preserving UI speedup이다.
7. **별도 slow validation — N_F=2와 full 2-D velocity reference.** 기본 interactive 경로가
   아니라 외삽점 검증용으로 둔다.
8. **GROUP C — quantum Langevin / full Zeeman Floquet.** absolute noise·polarization metrology에는
   필요하지만 negligible-overhead 개선으로 분류하지 않는다.

## 최종 결론

Seeded FWM은 GABES에서 가장 실제 실험에 가까운 경로 중 하나다. warm-vapor double-Λ의
동작점과 parameter trend를 보는 반정량 reference로 충분히 유용하다. 그러나 residual anchor,
현상론적 Ultra noise, 고정 Floquet truncation, angular Raman Doppler 부재와 full Langevin/Zeeman
부재 때문에 절대 squeezing metrology 기준으로 쓰면 안 된다.

Biphoton 모드는 phase matching·velocity-class interference·detector trade-off를 묶는 좋은 설계
도구지만, absolute rate와 `g²`는 여전히 anchor와 acquisition convention에 민감하다. 특히 오늘
확인한 coincidence-window 처리 때문에 작은 gate를 최적화하는 실험 판단에는 현재 값을 그대로
사용하면 안 된다.

가장 비용 대비 효과가 큰 다음 작업은 고차원 원자 모델이 아니다. **angular-Doppler trust
status/저비용 convolution, coincidence gate 적분, paper provenance, waveform-normalized 상대 rate,
filter transfer, loss cache 분리**다. 이들은 대부분 기존 배열의 후처리 또는 scalar bookkeeping이라
현재 물리를 보존하면서 실험 reference 신뢰도를 크게 높일 수 있다.
