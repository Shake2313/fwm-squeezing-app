# GABES 일일 스킴 물리 검토 — Scheme 5: FWM

- 날짜: 2026-08-24 (Asia/Seoul)
- 선택식: n = (24 mod 5) + 1 = 5
- 선택 스킴: FWMScheme, name=fwm, **Four-wave mixing (Gain diagnostic / Biphoton)**
- 관점: warm-vapor double-Λ FWM, intensity-difference 검출, 원자 biphoton 실험을 수행하는 연구자

## 요약 판단

현재 Scheme 5는 지난 2026-08-04 검토 때보다 물리적 신뢰 경계가 크게 좋아졌다.
production seeded 경로는 이제 N_F=3 유한-seed Floquet 응답을 계산하고 전체 표시 스캔에서
N_F=2와 복소 응답, 전달행렬, 이득, 위상, 최적점까지 비교한다. 별도 느린 기준 경로로
pump-only 정상상태/무한소 Nambu 응답과 2차원 비공선 Raman-Doppler 평균도 추가됐다
(gabes/schemes/fwm.py:1-13, 253-269, 2539-2551, 2626-2669).

실험 참고자료로서의 결론은 두 모드에 따라 다르다.

1. **Seeded ⁸⁵Rb D1 double-Λ**는 온도, detuning, pump intensity, cell length,
   교차각, transit reset에 대한 민감도와 동작점 탐색에는 유용한 실제 물리 모델이다.
   그러나 현재 기본점의 G_s=406.92, G_c=409.23은 문헌의 약 15 수준과 크게 다르고,
   canonical photon-flux gap=-2.380, 동작점 commutator defect=3.459이다. 따라서
   정량 이득, squeezing 크기, squeezing bandwidth의 실험 reference로 사용하면 안 된다.
   코드가 이를 MEAN_FIELD_DIAGNOSTIC / QUANTITATIVE_GAIN_UNSUPPORTED /
   PHYSICAL_SQUEEZING_UNAVAILABLE로 막는 것은 올바르다
   (gabes/schemes/fwm.py:3428-3489).
2. **Generic SFWM biphoton**은 velocity-class coherent sum, Autler-Townes denominator,
   vector phase matching, timing response와 detector/background trade-off를 한곳에서 보는
   유용한 source-design 도구다. 그러나 Predictive라는 묶음 이름과
   first-principles라는 설명은 현재 증거보다 강하다. 파형은 reduced-model prediction이지만
   absolute pair rate, reference OD와 longitudinal offset은 보정값이며 검출폭 일치는 같은
   timing response를 재사용한다. 절대 brightness, g², CAR, ns 폭을 독립적인 논문 재현으로
   인용해서는 안 된다.

가장 우선할 일은 새 고차원 물리를 즉시 더하는 것이 아니라, 이미 checklist에 있는
신뢰 경계와 검출 후처리를 닫는 것이다. 대부분 원자 OBE를 다시 풀 필요가 없어 물리를
보존하면서 거의 무시할 만한 overhead로 구현할 수 있다.

## 3. 2026-08-04 이후 반영된 중요한 개선

### 3.1 전체 스캔 Floquet 수렴 게이트

현재 기본은 N_F=3이며 N_F=2를 같은 181점 스캔 전체에서 함께 계산한다.
응답 성분, canonical transfer, gain, wrapped phase, optimum shift가 모두 기준을
통과해야 CONVERGED다(gabes/schemes/fwm.py:269-455, 2539-2551, 2640-2669).
오늘 기본점은 CONVERGED였고 최대 transfer 차 1.95e-7,
gain 상대차 5.25e-8 이하, 최대 위상차 1.22e-5 deg였다.

이 검사는 계산비용이 0은 아니다. N_F=3 외에 N_F=2 전 스캔을 추가하므로 현재 Fast
warm solve가 약 2.26 s다. 그러나 이것은 reference 신뢰를 위해 정당한 비용이며,
단일점 또는 N_F=1 결과를 수렴으로 오인하지 않게 한다. 과거 제안은 완료 상태다
(docs/checklist.json:691-721; tests/test_fwm_floquet.py:97-208).

### 3.2 pump-only 무한소 응답과 2-D Raman-Doppler 기준 경로

별도 기준 함수는 pump 정상상태를 trace-one null solve로 구하고, trace-zero two-column
Nambu response를 계산한다(gabes/schemes/fwm.py:1585-2003).
또 다른 기준 경로는 lab beat와 spectrum-analyser frequency를 고정한 채
독립 v_z, v_x Maxwell 평균을 수행한다. production에 몰래 대체하지 않고
minus branch만 지원하며 plus branch는 gauge parity 실패로 unsupported다
(gabes/schemes/fwm.py:157-200, 1789-1972;
tests/test_fwm_pump_response.py:18-282;
tests/test_fwm_angular_doppler.py:67-156).

기본 0.32 deg의 Raman-Doppler rms는 1.38017 MHz이고, order 24/32/40의
2-D 기준 계산은 0.508/0.932/1.526 s였다. 고정 δ=-8 MHz에서 1-D 대 2-D G_s 차는
0.1187%지만, 기준 feature 위치는 약 +35.95 MHz로 이동한다
(analysis/squeezing/analytic_reconstruction/generated/convergence_audit.md:133-172).
즉 nominal point의 gain은 비교적 안정해도 detuning 최적화에는 여전히 별도 기준 확인이
필요하다. opt-in 경로이므로 기본 runtime overhead는 0이다.

### 3.3 정상화, transit reset, Option-A와 claim gate

- trace-normalized rho_ss가 ground-manifold population을 이미 한 번 포함하므로 외부 p_F를
  다시 곱하지 않고 1/[2(2I+1)]=1/12만 남겼다
  (gabes/schemes/fwm.py:52-85).
- transit은 coherence-only floor가 아니라
  gamma_t(rho_th Tr rho-rho)의 trace-preserving thermal replacement로 구현됐다
  (gabes/schemes/fwm.py:2314-2381).
- nonlegacy 전파는 bare frequency-specific k와 vacuum/geometric mismatch만 사용하고
  Re chi는 diagonal Maxwell drift에 한 번만 둔다
  (gabes/schemes/fwm.py:2174-2199, 2567-2584).
- physical_squeezing_dB는 None이고 S_dB는 compatibility alias일 뿐이다
  (gabes/schemes/fwm.py:2752-2763).

이 변화들은 실험 reference의 정직성을 크게 높였다. 다만 corrected normalization 뒤
기본 absolute gain이 문헌과 맞지 않는다는 사실을 숨기지 않는 것이 중요하다.

## 4. 현재 seeded FWM 물리의 실험적 가치와 한계

### 실제로 유용한 물리

- ⁸⁵Rb D1의 F=2,3 ↔ F'=2,3 네 전이에 sqrt(3 C_F²)를 drive와 polarization
  readout에 사용하고 branching을 같은 hyperfine 구조와 일관되게 둔다
  (gabes/schemes/fwm.py:35-65; gabes/atoms.py).
- pure-⁸⁵Rb vapor density, density-dependent optical self broadening,
  ground-collision dephasing와 thermal transit reset을 온도별 atom model에 반영한다
  (gabes/schemes/fwm.py:2347-2381, 2501-2509).
- 각 probe detuning, optical velocity class에서 finite-order Floquet density matrix를
  풀고 네 susceptibility를 Doppler 평균한다
  (gabes/schemes/fwm.py:2052-2133, 2511-2551).
- 서로 다른 두 Raman branch를 한 susceptibility에 더하지 않으며, Maxwell 2x2
  전파, phase mismatch, segment/overlap, Manley-Rowe energy cap을 분리한다
  (gabes/schemes/fwm.py:2384-2400, 2567-2685).

따라서 detuning/temperature/pump-intensity/cell-length sensitivity, feature 위치,
상대적인 실험 knob 우선순위를 찾는 데는 유용하다. low-pump와 variable-audit 예제도
absolute gain이 예측이 아님을 명시하고, 측정 gain 또는 로그 민감도처럼 절대 scale이
약분되는 양만 사용하려 한다
(analysis/squeezing/low_pump_power/README.md:20-42;
analysis/squeezing/variable_audit/README.md:37-47).

### 오늘 기본점 재계산

조건은 Δ=+0.9 GHz, δ=-8 MHz, 121 °C, L=12.5 mm, pump=600 mW,
wanted seed=8 µW, angle=0.32 deg, post-cell loss=5.5%, QE=92%,
Fast 181점, 297 velocity classes다.

| 항목 | 오늘 값 |
|---|---:|
| 첫 실행(JIT 포함) | 6.170 s |
| warm solve | 2.25-2.26 s |
| G_s | 406.920464 |
| G_c | 409.231143 |
| gain-referred diagnostic | -8.654249 dB |
| canonical photon-flux gap | -2.379569 |
| 동작점 commutator defect | 3.459118 |
| 전체 스캔 최대 commutator defect | 75.2976 |
| Floquet gate | CONVERGED |
| validation level | MEAN_FIELD_DIAGNOSTIC |

독립 analytic audit의 더 촘촘한 고정점도 G_s=403.535와 문헌 약 15.5의
2503.5% 차이를 기록한다
(analysis/squeezing/analytic_reconstruction/generated/convergence_audit.md:68-90,
245-263, 320).

중요한 해석은 “수치적으로 수렴했으므로 물리적으로 맞다”가 아니다.
N_F gate는 같은 reduced model의 truncation 수렴만 증명한다. 현재 transfer는 canonical
Bogoliubov map이 아니며, 미시적 diffusion/covariance도 없다. -8.65 dB는 G_s와 G_c의
차를 넣은 algebraic score이고 실험 IDS squeezing이 아니다
(gabes/observables.py:367-404).

## 5. 현재 biphoton 물리의 실험적 가치와 한계

지원 topology는 ⁸⁷Rb 780/1529-nm telecom cascade, ¹³³Cs 852/917 및
852/795-nm BTW cascade, 검증되지 않은 generic diamond template다
(gabes/schemes/fwm.py:985-1133).

Predictive 경로는 다음의 유용한 실제 물리를 포함한다.

- Ω_c² Autler-Townes term이 든 two-photon denominator
- Maxwell velocity-class coherent amplitude sum과 natural decay
- velocity-space resonance를 측정한 뒤 waveform FWHM이 안정될 때까지 격자 자동 세분화
- longitudinal calibrated offset과 absolute transverse mismatch를 합친 vector sinc²
- intrinsic source width와 detector timing-response-broadened width의 분리

관련 코드는 gabes/schemes/fwm.py:1182-1414, 1416-1567이고,
detector readout은 gabes/observables.py:285-364다.

오늘 ⁸⁷Rb telecom 기본값은 다음과 같았다.

| 항목 | 값 |
|---|---:|
| source compute | 0.091 s |
| intrinsic source FWHM | 0.1726 ns |
| detected FWHM, 0.55 ns timing response | 0.4965 ns |
| waveform bandwidth | 914.761 MHz |
| anchored raw pair rate | 380.000 cps |
| 300 MHz scalar throughput 후 표시 rate | 124.623 cps |
| predictive g² peak | 308.71 |
| CAR | 307.71 |
| velocity step / status | 0.54124 m/s / converged |

하지만 pair rate 법칙은 pump, sqrt(coupling scale), vector phase match,
sqrt(N/N_ref)만 사용하며 cell length/OD를 직접 rate에 넣지 않는다
(gabes/schemes/fwm.py:1462-1472). filter도 실제 transfer function이 아니라
min(1, filter bandwidth/source bandwidth) scalar다
(gabes/observables.py:310-315). 검출폭 0.4965 ns와 측정 0.56(4) ns의 근접성은
같은 0.55 ns timing response를 사용한 결과라 독립 검증이 아니다.

따라서 geometry, channel ordering, waveform/filter/jitter의 방향성은 유용하지만,
absolute rate/g²/CAR/width metrology에는 부적합하다.

### 낮은 비용으로 아직 남은 검출 오류: coincidence window

biphoton_stats는 true coincidence를 pair_rate eta_s eta_i로 두고 window와 무관하게
유지하지만, accidental에만 window를 곱한다
(gabes/observables.py:322-340). 오늘 기본 waveform에서:

| window | true coincidence | CAR |
|---:|---:|---:|
| 0.05 ns | 1.24623 cps | 6154.20 |
| 1.00 ns | 1.24623 cps | 307.71 |

W→0에서도 true count가 줄지 않아 CAR가 1/W로 발산한다. 기존 테스트는 background와
window를 동시에 늘인 뒤 CAR 감소만 검사해 이 문제를 잡지 못한다
(tests/test_fwm_generic.py:128-140). detected delay PDF의 선언된 one-sided/symmetric
gate area를 true coincidence에 곱하고, histogram-bin g²와 gate-integrated CAR를
분리해야 한다. 원자 solve 추가는 없다.

## 7. 순수 코드 최적화

### 7.1 최우선: loss_pct와 qe_pct를 heavy cache key에서 제거

ParamSpec의 recompute 기본은 True다(gabes/schemes/base.py:44-56).
현재 loss_pct와 qe_pct는 recompute=False를 지정하지 않아 매 변화마다 전체 N_F=3/N_F=2
atomic solve를 다시 수행한다(gabes/schemes/fwm.py:3039-3049). 그러나 둘은
eta=QE(1-loss)를 만들고 gain-referred 검출 후처리에만 사용된다
(gabes/schemes/fwm.py:2460, 2693-2719, 2732-2733).

오늘 loss 0%와 35%를 각각 다시 계산한 결과:

- warm runtime: 2.261 s / 2.253 s
- G_s, G_c, T_field_small_signal: 모두 bitwise identical
- 같은 gain에서 eta만 바꾸는 remap: median 0.0155 ms

즉 검출 knob 하나의 응답을 약 145,000배 싸게 만들 수 있다. raw source에 gain,
hardened pump-scatter scalar와 필요한 arm diagnostics가 이미 있으므로 loss_pct와 qe_pct를
navigate-only로 바꾸고 observables에서 정확히 같은 식을 재평가하면 동작을 보존할 수 있다.
Fast/Balanced/Ultra, 여러 eta에서 기존 배열과 동등성 테스트를 추가해야 한다.

### 7.2 Biphoton 1-D angle trace vectorization

figure 경로는 181개 idler angle에서 phase_mismatch_vector를 Python loop로 호출한다
(gabes/schemes/fwm.py:3659-3671). 이미 phase_mismatch_vector_grid가 있다
(gabes/schemes/fwm.py:901-926).

오늘 같은 181점 계산은 0.597 ms → 0.111 ms, 5.38x였고
phase-matching weight 최대 차는 3.48e-19였다. 절대 절감은 작지만 완전한
behavior-preserving 정리다.

### 7.3 Cs 반대 channel source-result cache

Cs validation table은 선택하지 않은 917/795 channel을 observables 호출마다 다시 푼다
(gabes/schemes/fwm.py:3920-3937). 같은 raw와 params를 두 번 headless rendering해도
각각 32.4/32.8 ms가 걸렸다. _solver_from_topology_key는 solver 객체만 cache하고 raw
source result는 cache하지 않는다(gabes/schemes/fwm.py:1570-1576).

detector-only knob와 source key를 분리하고 반대 channel raw를 bounded cache에 넣으면
파형과 수치를 그대로 보존한다. 특히 navigate-only detector knob를 움직일 때 이 중복 solve를
막을 수 있다.

## 8. 문서, 테스트, 예제의 experimental-reference 적합성

### 강점

- README와 User Guide 본문은 physical squeezing unavailable, production 1-D,
  2-D slow reference, N_F scan gate를 명시한다
  (README.md:227-271; docs/Userguide/GABES_User_Guide_v2.html:633-660, 834-841).
- validation 테스트는 physical_squeezing=None과 claim gate를 고정한다
  (tests/test_fwm_validation.py:54-149).
- Floquet direct/block/kernel parity, Option-A propagation, passive Beer-Lambert,
  pump state, pole/residue, angular grid/cutoff를 독립적으로 테스트한다.
- analytic audit는 archived dressed-k 계산과 corrected Option-A 결과를 분리하고,
  internal invariant가 experimental validation이 아님을 명시한다
  (analysis/squeezing/analytic_reconstruction/generated/convergence_audit.md:1-7,
  322-331).
- low-pump/variable audit는 측정 gain과 model sensitivity를 구분해 읽도록 경고한다.

### 남은 reference 위험

1. **User Guide 그림이 오래됐다.**
   docs/Userguide/userguide_assets/fwm.png는 2026-06-08 자산으로,
   G_s 약 12와 Intensity-difference squeezing 축을 그리며 eta=0.855를 표시한다.
   현재 기본은 G_s 약 407이고 plot 축은 Gain-referred noise diagnostic이다
   (gabes/schemes/fwm.py:3439-3458). 본문은 수정됐지만 그림이 반대 메시지를 준다.
   현재 figure를 한 번 생성해 asset을 교체하는 것은 한 번의 offline solve뿐이고
   앱 runtime overhead는 0이다.
2. **Predictive/first-principles 표현이 아직 집계형이다.**
   UI schema와 status는 waveform, rate, detector convolution을 분리하지 않은 채
   Predictive를 쓴다(gabes/schemes/fwm.py:2963-2975, 3745-3756, 3969-3982).
   checklist의 biphoton-source-trust-boundary를 그대로 적용해야 한다.
3. **legacy coincidence 테스트가 production gain만으로 nonclassicality를 승인한다.**
   tests/test_coincidence.py:35-48은 G_s>1인 production spectrum에 ideal TMSV 공식을
   적용해 Cauchy-Schwarz violation을 단언한다. 현재 transfer가 noncanonical이고
   covariance가 없으므로 이 테스트는 ideal fixture로만 제한하거나 canonical gate 실패 시
   unavailable을 요구해야 한다. 이는 새 물리 제안이 아니라 기존 gain-only trust P1의
   테스트 마무리다.
4. **일부 예제는 의도적으로 legacy fidelity를 사용한다.**
   low_pump_power 분석은 P/w² 불변성과 측정 gain 전파를 위해 이를 명시하지만,
   독자가 generated 수치를 current production absolute prediction으로 재사용하지 않도록
   보고서 헤더에 compatibility/diagnostic 표기를 계속 유지해야 한다.

## 10. 실험 연구자용 최종 권고

현재 Scheme 5를 다음 범위에서 사용하면 가치가 높다.

- seeded: detuning/temperature/intensity/geometry 민감도, 후보 동작점,
  reduced-model 수렴과 propagation convention 점검
- biphoton: 파형 ordering, phase-matching geometry, jitter/filter/gate trade-off의
  정성·반정량 설계

다음 용도로는 사용하지 말아야 한다.

- seeded absolute gain이나 dB 값을 장치 성능 예측으로 인용
- gain-referred diagnostic을 IDS squeezing 또는 squeezing spectrum으로 인용
- Predictive biphoton rate/g²/detected width를 독립적인 논문 재현으로 인용
- G_s>1만으로 nonclassicality 또는 Cauchy-Schwarz violation을 주장

우선순위는 다음이 적절하다.

1. loss/QE cache 분리, coincidence gate integration, stale FWM 그림 교체
2. biphoton observable별 provenance와 seeded gain-only trust boundary 완결
3. exact unequal-loss covariance와 loss ledger 정리
4. 외부 held-out 데이터 확보 뒤에만 Langevin/Zeeman 연구 경로 활성화

이 순서는 1-2단계에서 원자 solve를 거의 늘리지 않으면서 실험 reference로서 가장 큰
오해 가능성을 제거한다.
