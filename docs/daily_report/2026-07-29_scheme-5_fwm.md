# GABES 일일 스킴 물리 검토 — Scheme 5: FWM

- 날짜: 2026-07-29 (Asia/Seoul)
- 선택식: `n = (29 mod 5) + 1 = 5`
- 선택 스킴: `FWMScheme`, `name="fwm"`, **Four-wave mixing (Squeezing / Biphoton)**
- 관점: warm-vapor FWM, intensity-difference squeezing, atomic biphoton 실험의 설계·해석 레퍼런스

## 요약 판단

Scheme 5는 두 신뢰 수준을 한 UI에 담는다.

1. **Seeded ⁸⁵Rb D1 double-Λ**는 실제 hyperfine CG strength, spontaneous branching,
   Doppler average, density-dependent dephasing, truncated Floquet response,
   Maxwell–Bloch propagation, phase mismatch와 검출 손실을 연결한다. 따라서 detuning,
   온도, 출력, 셀 길이와 각도에 따른 **실험 동작점·경향을 보는 반정량 reference**로
   유용하다. 그러나 `0.74` residual calibration, phenomenological Ultra noise,
   lumped Zeeman 구조와 full quantum-Langevin 부재 때문에 absolute squeezing
   metrology reference는 아니다.
2. **Generic SFWM biphoton**은 velocity-class coherent waveform, vector phase matching,
   detector/background/CAR를 한 번에 탐색하는 좋은 source-design 도구다. 다만 absolute
   pair rate는 계산된 파형과 분리된 reference anchor이고, 기본 telecom preset도 한 논문의
   단일 운전점을 재현하지 않는다. 폭·밝기·`g²`를 독립 예측값으로 읽으면 안 된다.

2026-07-24 Scheme 5 보고서 뒤 FWM 관련 커밋은 없었고, 오늘 재검증한 수치도 동일하다.
오늘의 새 실무 결론은 **seeded `loss_pct`를 heavy-solve cache key에서 분리하면 물리를
전혀 바꾸지 않고 손실 슬라이더 응답을 크게 줄일 수 있다**는 점이다.

## 3. 현재 구현이 보존하는 실제 물리

### 3.1 Seeded ⁸⁵Rb D1 double-Λ

실제 물리의 핵심 연결은 다음과 같다.

- `F=2,3 → F'=2,3`의 네 transition에 실제 D1 `3 C_F²`를 Rabi coupling과
  polarization readout에 적용한다 (`gabes/schemes/fwm.py:26-61`,
  `1085-1147`). Decay branching의 합과 비는 regression test가 고정한다
  (`tests/test_regression.py:164-182`).
- 온도에 따른 pure-⁸⁵Rb density, self broadening, Raman ground-coherence
  dephasing을 dissipator에 넣는다 (`gabes/schemes/fwm.py:1427-1448`,
  `1523-1531`).
- 각 probe detuning에서 두 reference solve로 `2×2` susceptibility matrix를 얻고,
  Maxwell velocity average를 수행한다 (`gabes/schemes/fwm.py:1150-1225`,
  `1533-1557`).
- Raman 두 branch를 독립 mode pair로 다루며 branch summation을 금지한다
  (`gabes/schemes/fwm.py:1451-1467`; `tests/test_regression.py:141-161`).
- susceptibility를 coupled Maxwell–Bloch matrix로 전파해 seed/conjugate gain을
  계산한다 (`gabes/observables.py:17-84`). 고밀도 runaway에는 smooth
  Manley–Rowe budget cap을 둔다 (`gabes/observables.py:87-115`).
- Fast부터 vacuum phase mismatch가 들어가고, Balanced는 refractive/segmented
  propagation, Ultra는 64-segment pump budget, Gaussian overlap, arm-resolved
  loss와 pump-scatter noise를 추가한다 (`gabes/schemes/fwm.py:1573-1688`,
  `1762-1779`).

이 구조는 “어느 detuning/온도/각도에서 gain과 squeezing이 좋아지는가”에는 실제
실험 가치가 높다. 반면 다음 경계는 반드시 유지해야 한다.

- macroscopic coupling은 first-principles `p_F/[2(2I+1)]` 위에 Sim et al.
  anchor `0.74`를 곱한다 (`gabes/schemes/fwm.py:43-88`, `1501-1515`).
- Ultra의 pump-scatter `κ=0.1`은 아직 측정으로 분리 검증된 값이 아니다
  (`gabes/schemes/fwm.py:128-137`, `1656-1688`).
- 24-level Zeeman은 CG-sum diagnostic일 뿐 main Floquet solve가 아니다
  (`gabes/schemes/fwm.py:1606-1625`).
- 현재 loss/noise는 full quantum-Langevin source-noise propagation이 아니다
  (`FWM_physics.tex:1614-1646`).
- Fast/Balanced/Ultra는 해상도만 다른 것이 아니다. Ultra는 noise physics 자체를
  바꾸므로 tier 간 squeezing 차이를 convergence error로만 해석하면 안 된다.

오늘 현재 기본점 재측정:

| fidelity | wall time | `G_s` | `G_c` | squeezing | velocity classes |
|---|---:|---:|---:|---:|---:|
| Fast | 0.363 s | 5.5861 | 4.6377 | -6.8365 dB | 297 |
| Balanced | 2.140 s | 13.8968 | 12.9924 | -8.0395 dB | 591 |
| Ultra | 8.912 s | 13.8289 | 12.9244 | -7.0819 dB | 1573 |

Fast는 정량 reference로 under-resolved다. Balanced와 Ultra gain은 약 0.5% 안에서
가깝지만 squeezing은 약 0.96 dB 다르며, 이는 Ultra의 loss/noise model 차이다.

### 3.2 Generic SFWM / biphoton

지원 topology는 ⁸⁷Rb 780/1529 nm telecom cascade, 두 ¹³³Cs BTW channel,
검증되지 않은 generic diamond template다 (`gabes/schemes/fwm.py:492-639`).

Predictive 경로의 유용한 실제 물리는 다음과 같다.

- `Ω_c²` Autler–Townes term을 가진 two-photon denominator와 Maxwell
  velocity-class coherent sum (`gabes/schemes/fwm.py:758-804`)
- source-resonance FWHM을 측정하고 velocity step을 절반화하는 수렴 검사
  (`gabes/schemes/fwm.py:842-921`)
- calibrated longitudinal mismatch와 absolute transverse mismatch를 합친
  vector `sinc²(|Δk|L/2)` (`gabes/schemes/fwm.py:307-359`, `936-958`)
- source/detected width, detector efficiency, dark count, true/accidental
  coincidence와 CAR (`gabes/observables.py:174-253`)

기본 telecom 현재값:

| 항목 | 현재값 |
|---|---:|
| compute time | 0.131 s |
| intrinsic source width | 0.17260 ns |
| positive-delay timing-smoothed width | 0.49652 ns |
| waveform-derived bandwidth | 914.76 MHz |
| anchored raw pair rate | 380.0 cps |
| 300 MHz filter 후 표시 pair rate | 124.62 cps |
| predictive `g²` peak | 308.71 |
| auto-refined velocity step | 0.54124 m/s, converged |

`g²≈308.7`은 reference `44(3)`의 재현이 아니다. Predictive에서는 target forcing을
끄고, anchored rate와 기본 detector/background/window로 CAR를 계산한 결과다
(`gabes/schemes/fwm.py:2328-2342`, `2595-2624`). 이 정직한 분리는 장점이지만,
absolute rate가 독립 예측이 아니므로 `g²` 역시 독립 source validation으로 볼 수 없다.

기존 신뢰 경계도 그대로 남아 있다.

- telecom default는 `90 °C`, `10 µW`, dimensionless coupling `1×`,
  `Ω_p/2π=2 MHz`, `Ω_c/2π=12 MHz`, zero detuning을 섞은 design default다
  (`gabes/schemes/fwm.py:492-530`, `695-719`, `2035-2074`). 07-24 보고서에서
  확인했듯 인용 논문의 width 운전점과 동일하지 않다.
- 파형에는 `OD`가 amplitude로 들어가지만 표시 pair rate는
  `pump × sqrt(coupling scale) × phase match × sqrt(N/N_ref)`만 사용해
  cell length/OD를 직접 반영하지 않는다 (`gabes/schemes/fwm.py:783-823`,
  `962-979`).
- 시간축은 `0…tau_max`의 481점으로 고정돼 temporal resolution과 delay convention이
  velocity convergence flag에 포함되지 않는다 (`gabes/schemes/fwm.py:983`;
  `gabes/lineshape.py:51-75`).
- filter는 waveform 전달함수가 아니라 rate throughput
  `min(1, BW_filter/BW_source)`만 바꾼다 (`gabes/observables.py:199-209`;
  `FWM_physics.tex:1524-1548`).

따라서 biphoton mode는 collection geometry, channel ordering, detector/background
trade-off에는 좋은 실험 설계 reference지만 absolute brightness·width·`g²` metrology
reference는 아니다.

## 4. 오늘의 새 순수 최적화: `loss_pct`를 heavy solve에서 분리

`loss_pct`는 현재 `ParamSpec`에서 기본 `recompute=True`다
(`gabes/schemes/fwm.py:1873-1875`). Streamlit은 모든 recompute knob를 heavy cache
key에 넣는다 (`streamlit_app.py:605-611`, `1417-1423`). 따라서 loss slider를 바꾸면
Floquet/Doppler solve가 다시 실행된다.

그러나 코드 경로를 따라가면:

- `loss_frac`은 `eta = qe*(1-loss)`를 만드는 데만 쓰인다
  (`gabes/schemes/fwm.py:1515`).
- `χ̄`, Doppler average, `G_s`, `G_c`에는 들어가지 않고, gain 계산 뒤
  squeezing/noise 식에서만 쓰인다 (`gabes/schemes/fwm.py:1542-1644`,
  `1646-1690`).
- 실제 loss `0%`와 `35%` Fast solve의 `G_s`, `G_c` 배열은 bitwise identical였다.
  두 heavy solve는 각각 `0.528 s`, `0.856 s`였지만 동일 gain에서 loss만 다시
  매핑하는 `intensity_difference_squeezing_dB` median은 `0.0284 ms`였다.
- Ultra loss sweep도 이미 별도 분석 예제가 raw gain/OD 배열을 재사용해 analytic
  remap한다 (`analysis/squeezing/scan_squeezing_v6_tolerance.py:146-164`).

권고:

1. `loss_pct`를 `recompute=False`로 바꾼다.
2. raw에 이미 있는 gain, `segment_absorption_od`, `hardened_noise` arm-OD 배열을
   사용해 `_seeded_observables()`에서 현재와 같은 squeezing 식을 계산한다.
3. Fast/Balanced/Ultra 각각에 대해 여러 loss 값에서 기존 `S_dB`와 bitwise 또는
   tight-tolerance 동등성 test를 추가한다.

이는 원자 모델, 격자, gain, noise 식을 바꾸지 않는 **순수 cache/post-processing
분리**다. app 전체에서는 figure 재렌더 비용이 남지만, loss 조절마다 수백 ms에서 수초인
원자 solve를 제거할 수 있다.

## 5. 우선순위와 비용

1. **P0 — paper operating-point preset + provenance.** 온도, cell, detuning,
   optical power, backend Rabi, linewidth, detector delay convention을 한 preset에 묶고
   `measured / paper theory / anchored / predicted`를 분리한다. scalar/default 작업이라
   runtime overhead는 0에 가깝다.
2. **P0 — temporal-resolution/delay-convention status.** `dt/FWHM`, edge tail,
   start–stop positive-delay 여부를 기존 배열에서 표시한다. 추가 solve가 없다.
   자동 fine grid는 별도 opt-in으로 두어야 메모리 비용을 통제할 수 있다.
3. **P1 — computed waveform norm으로 상대 brightness 연결.** fixed-domain
   reference norm을 cache하고 `R/R_ref = ∫|ψ|²/∫|ψ_ref|²`를 사용한다. 이미 `ψ`에
   drive·OD·phase matching이 들어가므로 현 scalar factor를 다시 곱해 double count하면
   안 된다.
4. **P1 — 실제 filter transfer option.** opt-in spectrum multiplication/IFFT는
   current source solve를 재사용하며 비용이 매우 작다.
5. **P1 성능 — `loss_pct` post-processing 분리.** 오늘 확인한 가장 큰
   behavior-preserving UI speedup이다.
6. **별도 GROUP C — quantum Langevin / full Zeeman Floquet.** absolute noise와
   full polarization physics에는 필요하지만 interactive 기본 solve에 넣을 저비용 수정은
   아니다.

## 6. 나머지 동작보존 코드 최적화

1. **Cs 반대 channel raw solve cache.** validation table은 선택하지 않은 channel을
   매 observables 호출마다 다시 계산한다 (`gabes/schemes/fwm.py:2633-2650`).
   source-physics key의 bounded cache와 detector-only 재계산으로 동작을 보존할 수 있다.
2. **1D angle trace vectorization.** figure 경로의 181-angle Python loop
   (`gabes/schemes/fwm.py:2372-2384`)를 기존 vector grid helper
   (`gabes/schemes/fwm.py:408-433`)로 바꿀 수 있다. 07-24 측정은
   `0.537 → 0.058 ms`, max difference `1.76e-18`이었다.
3. **현재 Numba/reference 경계 유지.** fused real-Hermitian kernel과 NumPy
   reference가 서로 검증된다 (`gabes/kernels.py:167-273`;
   `tests/test_kernels.py:53-89`). mutable public array를 공격적으로 global-cache하는
   것은 이득보다 correctness 위험이 크다.

## 7. 문서·테스트·예제의 실험 reference 적합성

### 강점

- legacy focused spectrum은 frozen baseline에 고정돼 있다
  (`tests/test_regression.py:21-50`).
- line strength/branch convention/coupling factorization은 별도 물리 test를 갖는다
  (`tests/test_regression.py:67-196`).
- generic tests는 vector phase matching, wrong-side suppression, detector
  background, jitter, velocity convergence, Cs width ordering, lazy phase map과
  Zeeman scope를 폭넓게 확인한다 (`tests/test_fwm_generic.py:60-258`,
  `383-615`).
- tolerance example은 loss를 재풀이 없이 remap하며, 실험 knob drift와 trust gate를
  분리한다 (`analysis/squeezing/scan_squeezing_v6_tolerance.py:97-164`).
- README와 app info는 absolute rate anchor, approximate width, full Langevin 부재를
  숨기지 않는다 (`README.md:179-204`; `gabes/schemes/fwm.py:2106-2163`).

### 남은 불일치와 누락

- archived CLI는 natural-abundance `atoms.rb85_density`를 출력하지만 backend는
  pure-85 `hyperfine.number_density`를 쓴다
  (`archive/fwm_obe.py:28,69`; `gabes/schemes/fwm.py:1523-1526`).
- 분석 예제 주석에는 현재 `QE_DETECTOR=0.92`와 다른 `0.9047` 설명이 남아 있다
  (`analysis/squeezing/scan_squeezing_delta_T.py:14-16,51`,
  `scan_squeezing_theory_max.py:39-47`).
- Numba benchmark의 `app-fast=121,dv=5`, `app-fine=301,dv=2` 명칭은 현재
  Fast `181,dv=4`, Balanced `301,dv=2`와 다르다
  (`analysis/squeezing/bench_numba_fwm.py:7-34`;
  `gabes/schemes/fwm.py:1762-1779`).
- app info는 Ultra를 “self-consistent phase refinement”라고 부르지만 현재
  `n(χ)`에 `Δk` feedback이 없어 one pass가 정확하다
  (`gabes/schemes/fwm.py:125`, `1361-1382`, `2122-2127`).
- physics 문서에는 제거된 `High fidelity`/`Fine mode` 명칭이 남아 있다
  (`FWM_physics.tex:79-90`).
- pair-rate/temporal convention/filter transfer와 오늘의 loss-cache 분리를 고정하는
  회귀 test가 아직 없다.

이 문서·예제 정리는 runtime 0이며, 실험 notebook으로 parameter를 옮길 때 생기는
재현 오류를 줄인다.

## 최종 결론

Seeded FWM은 GABES의 가장 강한 실험 물리 경로 중 하나이며, warm-vapor
double-Λ의 동작점과 parameter trend를 보는 반정량 reference로 충분히 유용하다.
그러나 calibrated residual, phenomenological Ultra noise와 full Langevin/Zeeman
부재 때문에 absolute squeezing 예측기로 승격해서는 안 된다.

Biphoton은 waveform ordering, phase matching과 detector trade-off를 묶은 설계
도구로 가치가 높지만, 현재 absolute rate와 기본 telecom reference는 여전히
anchored/composite다. 가장 값싼 물리 개선은 paper-specific provenance,
temporal-resolution status, waveform-normalized relative rate와 real filter response다.

순수 코드 측면에서는 오늘 확인한 `loss_pct` cache 분리가 최우선이다. 원자 solve와
gain은 그대로 두고 검출 손실만 후처리하면, 현재 물리를 보존하면서 loss slider의
heavy recompute를 제거할 수 있다.
