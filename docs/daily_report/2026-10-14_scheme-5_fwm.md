## 2. ⟦AI⟧ 실험 원자물리 관점의 결론

**실제 원자물리를 구현한다. detuning·온도·펌프·기하 변화의 방향을 찾고
수치 구현을 검산하는 반정량 reference로 유용하다. 그러나 절대 gain,
physical squeezing spectrum, 절대 pair rate와 gate-resolved CAR의 계측 reference는 아니다.**

실험 reference 등급: **B-**.

적합한 용도:

- ⁸⁵Rb D1 double-Λ의 detuning·온도·pump·cell·waist·교차각 민감도 탐색.
- finite-Floquet → Doppler 평균 → Maxwell 전파 사슬의 상대 효과 검산.
- Fast로 후보를 찾고 Balanced 직접점과 Floquet gate로 재확인.
- Biphoton 파형 폭, velocity-grid 수렴, vector phase matching, timing/filter
  trade-off 비교.

현재 피해야 할 주장:

- Fast/Balanced 표시 gain을 새 장치의 절대 예측값으로 인용.
- `S_dB` 또는 UI `Squeezing indicator`를 원자 Langevin squeezing으로 인용.
- Fast/Balanced와 Ultra 차이를 동일 물리 모델의 수치 오차막대로 해석.
- `pair_rate`, `g²`, CAR를 완전한 검출·coincidence-gate 예측으로 인용.

코드는 이 한계를 상당 부분 machine-readable하게 기록한다.
`quantitative_gain_supported=False`, `physical_squeezing_prediction=False`,
`physical_squeezing_dB=None`이다(`gabes/schemes/fwm.py:588-652,3379-3406`).
남은 핵심 문제는 계산 자체보다 보정 계보와 reduced-model 경계가 사용자 화면에
충분히 드러나지 않는 점이다.

### 3.3 ⟦AI⟧ 무시 가능한 overhead로 먼저 할 수 있는 것

1. **현재 local output calibration을 claim reason·diagnostics·README/Guide에 노출.**
   계산은 이미 `gain_closure["output_calibration"]`을 적용한다
   (`gabes/schemes/fwm.py:2974-2984,3300-3307`). 표시용 metadata 추가만 필요해
   runtime과 물리를 바꾸지 않는다.
2. **Fast adaptive score의 detector independence.** 현재 local fit이 활성일 때만
   `score_eta=1`; 그 밖에는 외부 검출 효율이 sampling node를 바꾼다
   (`gabes/schemes/fwm.py:3053-3129`). atomic solve 수를 늘리지 않고 source-side
   score로 고칠 수 있다. 표시 곡선은 더 일관되게 바뀌지만 underlying OBE·전파식은 보존된다.
3. **Biphoton gate capture.** detected `|ψ(τ)|²`를 gate에 적분하고 all-time rate와
   gate-captured rate를 분리한다. 현재 481점 축에서 `O(Nτ)`이므로 atomic solve보다
   무시 가능하다(`gabes/schemes/fwm.py:1521-1524`; `gabes/observables.py:303-363`).
4. **오래된 예제 schema 명명 수정.** `analysis/squeezing/scan_squeezing_delta_T.py`
   는 아직 `best_squeezing`, `S_dB`, “Best squeezing”을 쓴다(`:82-103,165-172,225-237`).
   `gain_referred_*`를 primary로 추가하고 legacy alias를 유지하면 계산값은 불변이다.

## 4. Seeded FWM 코드·물리 평가

### 4.1 구현된 유용한 물리

- 실제 ⁸⁵Rb D1 4-level double-Λ. drive와 readout에 `sqrt(3 C_F²)`가 각각 들어가
  곱에서 `3 C_F²`를 한 번 사용하고, trace-normalized population과 sublevel 평균
  `1/[2(2I+1)]=1/12`을 분리한다(`gabes/schemes/fwm.py:39-89`).
- finite-reference-field density-matrix Floquet solve. 기본 `N_F=3`과 인접 `N_F=2`
  full scan을 복소 χ, transfer, gain, phase, optimum까지 비교한다
  (`gabes/schemes/fwm.py:285-477,530-556`).
- Fast/Balanced pole-residue 경로는 동일한 truncated-Maxwell measure를 사용하며,
  guard 실패 시 직접 table solve로 되돌아간다(`gabes/schemes/fwm.py:2203-2473`).
- bare optical wavevector, geometric phase mismatch, collected-mode area, Maxwell
  propagation을 잇는다. Ultra는 64-segment overlap/pump-budget 경로를 가진다
  (`gabes/schemes/fwm.py:2518-2750,2842-3366`).
- pump-only infinitesimal Nambu reference와 별도 2-D non-collinear Doppler reference가
  있으나 production으로 몰래 대체하지 않는다(`gabes/schemes/fwm.py:480-527`).

### 4.2 ⟦AI⟧ 정량 한계

- inherited residual 0.74, phenomenological κ, transit floor에 독립 calibration이 없다
  (`gabes/schemes/fwm.py:92-118,559-585`).
- Fast/Balanced는 Sim 단일점 coupling correction에 더해 OPD-local 10점 final-power
  gain map을 사용한다. 생산 runtime fit은 아니지만, 외삽 가능한 microscopic 모델도 아니다
  (`gabes/fwm_gain_closure.py:13-15,116-187`;
  `analysis/fwm_gain_hotfix/tpd_affine_20261001/README_ko.md:83-135`).
- pump depletion은 self-consistent three-field propagation이 아니라 사후 cap이다
  (`gabes/schemes/fwm.py:3295-3307`; `gabes/observables.py:198-217`).
- production finite-seed Doppler는 1-D다. 별도 2-D reference가 production의 정량성을
  인증하지 않는다(`gabes/schemes/fwm.py:501-526,588-605`).
- full Zeeman manifold, distributed atomic/vacuum Langevin source와 RF covariance가 없다.
  따라서 mean transfer/gain만으로 physical IDS spectrum을 얻을 수 없다. 최신 analytic
  문서도 gain-only score를 covariance가 아니라고 명시한다
  (`docs/FWM physics and analytic reconstruction/squeezing_analytic_reconstruction_v3.tex:80-126,1008-1161,1985-1987`).

### 4.3 동일 해시의 봉인 수치 재사용

오늘 FWM 생산 파일 해시는 2026-10-09와 동일하다. 장기 검토 원칙에 따라 입력과 코드가
같은 기본점을 재실행하지 않고, 직전 보고서의 계산을 provenance와 함께 재사용했다
(`docs/daily_report/2026-10-09_scheme-5_fwm.md:83-121`).

조건: Δ=0.9 GHz, δ=−8 MHz, 121 °C, pump 600 mW, seed 8 µW, η=0.8694.

| tier | `G_s` | `G_c` | gain-referred indicator | physical squeezing |
|---|---:|---:|---:|---|
| Fast | 15.504216 | 14.741747 | −7.515184 dB | `None` |
| Balanced | 15.504247 | 14.741778 | −7.515187 dB | `None` |
| Ultra | 394.870678 | 397.097269 | −7.800492 dB | `None` |

Fast/Balanced와 Ultra의 큰 차이는 numerical convergence band가 아니라 서로 다른
calibration policy다. 이를 화면에 명시해야 한다.

## 5. Biphoton 코드·물리 평가

### 5.1 유용한 부분

- velocity-class coherent sum, Ωc² Autler–Townes denominator, natural linewidth,
  vector phase matching을 구현한다(`gabes/schemes/fwm.py:1298-1380`).
- velocity step 자동 refinement와 waveform-width 수렴을 검사한다
  (`gabes/schemes/fwm.py:1382-1461`).
- source FWHM과 timing-jitter 후 detected FWHM을 분리하고, source/readout cache key도
  나뉜다(`gabes/schemes/fwm.py:1622-1639`; `gabes/observables.py:299-320`).

동일 해시 직전 기본 ⁸⁷Rb telecom 결과는 source/detected FWHM `0.173/0.497 ns`,
filter 후 pair rate `124.6 cps`, CAR `307.710`이었다
(`docs/daily_report/2026-10-09_scheme-5_fwm.md:151-201`).

### 5.2 ⟦AI⟧ 정량 한계와 gate 결함

- pair-rate scale은 문헌 anchor다. pump·coupling·phase match·`sqrt(density ratio)`로
  scale하며 OD/cell length가 rate에 직접 들어가지 않는다
  (`gabes/schemes/fwm.py:1509-1519`). geometry/waveform 비교에는 유용하지만 절대
  brightness 모델은 아니다.
- filter는 waveform의 spectral convolution이 아니라 bandwidth 비율 scalar다
  (`gabes/observables.py:310-315`).
- true coincidence는 `pair_rate*η_s*η_i`로 window와 무관하고 accidental만 window에
  비례한다(`gabes/observables.py:322-340`). 직전 검산에서 0.01–10 ns gate 모두 true
  coincidence가 `1.246227 cps`였다. 0.497 ns 폭보다 훨씬 좁은 gate에서도 같으므로
  현재 CAR는 gate-integrated count prediction이 아니다.

gate capture 적분은 현재 481점 waveform에 대한 `O(Nτ)` 후처리다. 기존 all-time alias를
유지하면 source 물리와 호환값을 보존하면서 실험적으로 더 유용한 값을 추가할 수 있다.
