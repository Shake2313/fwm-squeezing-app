## 5. Seeded FWM 물리 평가

### 5.1 실제 구현된 물리

- ⁸⁵Rb D1 4-level double-Λ. 실제 hyperfine `C_F²`를 drive·readout에 한 번 사용. trace-normalized steady state가 manifold population 공급. 별도 sublevel 평균 `1/12`(`gabes/schemes/fwm.py:39-89`).
- finite-reference-field density-matrix Floquet. 기본 `N_F=3`, 인접 `N_F=2`와 full scan 비교. 복소 χ, transfer, gain, phase, optimum gate(`gabes/schemes/fwm.py:285-477,530-556`).
- Doppler 평균. Fast/Balanced는 exact pole-residue sum을 같은 truncated Maxwell nodes에서 수행. 각 solved row guard·grid fallback(`gabes/schemes/fwm.py:2253-2418`).
- bare optical wavevector, geometric phase mismatch, collected-mode area, Maxwell propagation. Ultra는 64-segment Gaussian overlap·근사 pump budget 경로(`gabes/schemes/fwm.py:2518-2750,2842-3366`).
- 충돌·transit reset 포함. 그러나 `ell_s`, κ, transit rate 독립 calibration 없음(`gabes/schemes/fwm.py:559-585`).
- 별도 pump-only infinitesimal Nambu reference와 2-D non-collinear Doppler reference 있음. production finite-seed는 1-D(`gabes/schemes/fwm.py:480-527,1737-2037`).

즉 장난감 scalar gain curve 아님. OBE→Doppler→Maxwell transfer를 잇는 유용한 실제 물리. 다만 full Zeeman, spatially self-consistent depletion, distributed vacuum/Langevin noise, measured collected modes 없음.

### 5.2 기본 동작점 재계산

조건: Δ=0.9 GHz, δ=−8 MHz, 121 °C, pump 600 mW, seed 8 µW, η=0.8694.

| tier | warm 단일 실행 | solved/display | `G_s` | `G_c` | gain-referred indicator | physical squeezing |
|---|---:|---:|---:|---:|---:|---|
| Fast | 1.303 s | 61/401 | 15.504216 | 14.741747 | −7.515184 dB | `None` |
| Balanced | 0.413 s | 401/401 | 15.504247 | 14.741778 | −7.515187 dB | `None` |
| Ultra | 12.941 s | 401/401 | 394.870678 | 397.097269 | −7.800492 dB | `None` |

시간은 이 PC의 단일 warm 관측. Fast/Balance 순위 보증 아님. Fast는 adaptive 준비·warmup 영향 큼.

핵심:

- 세 tier 모두 Floquet gate `CONVERGED`.
- pole guard 최대: Fast `3.13e-12`, Balanced `1.30e-11`; fallback 0.
- Fast/Balanced는 `C_mix=0.5594938027` 보정 적용. Ultra 미적용(`gabes/fwm_gain_closure.py:13-15,116-187`).
- 따라서 `15.5 ↔ 394.9` 차이는 numerical convergence band 아님. 서로 다른 calibration policy.
- field-only canonical commutator defect도 큼(Fast 352.38, Balanced 355.33, Ultra 81.44). 이것만으로 squeezing 부재를 증명하지도, gain-only noise식을 물리 공분산으로 만들지도 못함.

### 5.3 2026-10-01 TPD-local output calibration

Fast/Balanced 보정은 두 층.

1. Sim-2025 단일점 cross-coupling multiplier.
2. OPD-local 10점 final-power gain map.

두 번째 층:

- `0.90 < OPD/GHz < 1.22`, minus branch, correction ON, Fast/Balanced에서만 적용.
- OPD 1.06 GHz에서 최대 weight. 기본 OPD 0.9 GHz에서는 exact bypass.
- `F(G)=aG+b+c max(G-k,0)` 두 구간 affine. transfer matrix·χ·covariance calibration 아님(`gabes/fwm_gain_closure.py:17-95`).
- in-sample 최대 상대잔차: probe 7.7018%, conjugate 7.3580%.
- 반복 측정, uncertainty, CI, holdout 없음(`analysis/fwm_gain_hotfix/tpd_affine_20261001/README_ko.md:59-84`).
- 활성 시 1 MHz calibration nodes 10개를 scan에 삽입. coarse display의 affine-knee 오차 방지(`gabes/schemes/fwm.py:2971-2984`).

물리 판정: **국소 표시 gain fit. 실험 reference 등급 상승 아님.** 단조 output map은 원모델 peak 위치를 고치지 못함. 기존 체크리스트의 physical replacement가 맞는 장기 경로.

## 6. Biphoton 물리 평가

### 6.1 유용한 부분

- Maxwell velocity-class coherent sum, Ωc² Autler–Townes denominator, natural linewidth, vector phase matching 구현(`gabes/schemes/fwm.py:1298-1378`).
- velocity step 자동 refinement와 waveform-width convergence(`gabes/schemes/fwm.py:1382-1461`).
- source FWHM와 timing-jitter 후 detected FWHM 분리.
- detector/background/filter는 readout-only knob(`gabes/schemes/fwm.py:3864-3887`).
- source/readout key 분리 pattern 존재(`gabes/schemes/fwm.py:1622-1639`).

기본 ⁸⁷Rb telecom 재계산:

| 값 | 결과 |
|---|---:|
| source FWHM | 0.173 ns |
| detected FWHM | 0.497 ns |
| source bandwidth | 915 MHz |
| filter 후 pair rate | 124.6 cps |
| phase matching | 1.000 |
| `g²` peak / CAR | 308.710 / 307.710 |

좋은 geometry·waveform 설계 reference. 하지만 pair-rate scale은 문헌 anchor. pump·coupling·phase match·`sqrt(density ratio)`로 scale하고 OD/cell length는 rate에 직접 안 들어감(`gabes/schemes/fwm.py:1510-1519`). 절대 brightness 모델 아님.

### 6.2 coincidence gate 결함 재확인

현재 계산:

```text
coincidence = pair_rate * eta_s * eta_i
accidental  = singles_s * singles_i * window
```

즉 true coincidence에는 waveform gate capture가 없음(`gabes/observables.py:303-363`). 기본 waveform에서 재계산:

| gate | true coincidence | accidental | CAR |
|---:|---:|---:|---:|
| 0.01 ns | 1.246227 cps | 4.050e-5 cps | 30771.01 |
| 0.10 ns | 1.246227 cps | 4.050e-4 cps | 3077.10 |
| 1.00 ns | 1.246227 cps | 4.050e-3 cps | 307.71 |
| 10.0 ns | 1.246227 cps | 4.050e-2 cps | 30.77 |

detected FWHM 0.497 ns보다 50배 좁은 0.01 ns gate에서도 true coincidence 동일. 따라서 현재 CAR는 gate-integrated physical count가 아님.

기존 `biphoton-source-trust-boundary` 안에서 처리 가능:

1. normalized detected `|ψ(τ)|²`를 gate 범위에 적분.
2. `detected_all_time`와 `gate_captured` true rate 분리.
3. raw accidentals, target-`g²` calibration, displayed CAR 분리.
4. `window→0`이면 captured true coincidence도 0으로 가는 test 추가.

비용 `O(Nτ)`; 현재 481점. atomic solve 대비 무시 가능. 기존 all-time rate alias 유지하면 physics core·호환값 보존 가능.

## 9. 순수 코드 최적화

물리식·수치 measure·출력 행동을 바꾸지 않는 후보만.

### 9.1 `ChiPoleRows` 확대

- 구현: `gabes/schemes/fwm.py:2421-2473`.
- δ마다 eigendecomposition 1회. 임의 temperature/detuning의 같은 discrete velocity sample sum 재사용.
- 중앙 Δeff guard 실패 시 표 계산 fallback.
- exact-measure test: `tests/test_fwm_fast_tiers.py:65-88`.
- 기존 측정: delta-T 한 온도 χ table `1.54 s → 0.010 s`, 약 149×; χ 최대차 `1.8e-12`(`analysis/pole_reuse/DEVLOG.md:113-124`).

분석 scanner에 가장 큰 순수 이득. production default 변경보다 sweep helper 공통화가 안전.

### 9.2 detector readout cache 분리

- `detection_eff_pct`는 현재 heavy recompute knob(`gabes/schemes/fwm.py:3720-3724`).
- η와 phenomenological N/a algebra는 gain 배열 뒤 cheap readout(`gabes/schemes/fwm.py:3308-3366,4129-4183`).
- 선행조건: `fwm-fast-detector-independent-sampling`. 현재 fit 밖 Fast node 선택은 detector/noise score 영향 가능(`gabes/schemes/fwm.py:3053-3085,2253-2362`).

순서 지키면 Balanced/Ultra와 수정된 Fast에서 atomic solve 재사용 가능. 물리 결과 exact 동일.

### 9.3 atomic response와 calibration/propagation cache 분리

- `gain_closure_enabled`는 atomic Floquet solve 자체를 바꾸지 않음. cross-coupling·output map은 뒤에 적용(`gabes/schemes/fwm.py:2900-2913,3048-3085,3295-3307`).
- 단 local fit 활성 시 calibration node 10개 추가. cache axis를 합집합으로 고정하거나 missing node만 solve해야 exact 행동 유지(`gabes/schemes/fwm.py:2974-2984`).
- immutable arrays·fresh provenance dict 필요.

Correction ON/OFF·detector/noise sweep 가속. OBE 결과 불변.

### 9.4 Biphoton 1-D phase trace vector화

- fallback plot 경로가 181개 angle을 Python list comprehension으로 평가(`gabes/schemes/fwm.py:4398-4410`).
- 이미 존재하는 vector API `phase_mismatch_vector_grid()`의 1×N 경로 사용 가능(`gabes/schemes/fwm.py:948-974`).
- 동일 산술 순서 여부 test 후 적용. 이 경로는 figure 생성 때만. 이득 작지만 pure optimization.

## 10. 실험가 사용 지침

1. Fast로 후보 탐색. 최종 후보 Balanced 재계산.
2. Fast/Balanced와 Ultra 차이를 error bar로 쓰지 않음. calibration policy 다름.
3. `CONVERGED`는 Floquet truncation 통과. absolute gain·squeezing 인증 아님.
4. `physical_squeezing_dB=None` 유지한 채 gain-referred indicator로만 읽기.
5. OPD 0.90~1.22 GHz 안에서는 TPD-local output fit 여부와 blend weight 기록.
6. correction OFF 또는 fit 바깥 Fast에서 η/noise 변경 후 gain array가 바뀌면 adaptive sampling artifact 의심.
7. Biphoton pair rate·CAR·`g²`는 reference anchor와 gate 정의 함께 기록. 현재 true rate는 all-time 값.
8. 최종 장치 설계에는 full Zeeman/2-D Doppler/공간 전파·covariance 또는 직접 측정 추가.

## 11. 최종 판정

GABES FWM은 실제 OBE·Doppler·Maxwell·phase-matching 물리를 가진 유용한 연구 도구. 특히 내부 provenance, Floquet gate, reference solver, fallback이 강함.

하지만 현재 신뢰 경계:

- **Seeded:** relative trend·후보 탐색·numerical audit 가능. absolute gain과 physical squeezing 불가.
- **Biphoton:** waveform ordering·phase matching·detector trade-off 가능. absolute rate·CAR metrology 불가.
- **문서:** 첫 calibration은 보이지만 두 번째 local output fit은 숨겨짐.

가장 싼 다음 조치 세 개:

1. local output calibration provenance 사용자 표면 노출.
2. Fast detector-independent sampling 전 범위 적용.
3. gate-captured coincidence 481점 적분 추가.

셋 모두 큰 atomic physics 변경 없이 reference 신뢰도·속도·실험 해석을 개선 가능.
