## 3. Scheme 5가 실제로 구현하는 물리

### 3.1 Seeded 85Rb D1 double-Λ gain/squeezing

이 경로는 단순 Lorentzian gain toy가 아니다.

1. `85Rb D1`의 두 ground hyperfine level과 두 excited hyperfine level을 4준위 double-Λ로 구성한다. 실제 hyperfine `C_F²`로 drive/readout dipole과 spontaneous branching을 만든다 (`gabes/schemes/fwm.py:29-61`, `1142-1195`; `tests/test_regression.py:164-182`).
2. pump/seed power와 waist를 Rabi frequency로 바꾸고, two-photon detuning과 Maxwell velocity class마다 3-mode Floquet steady state를 풀어 네 susceptibility 성분을 얻는다 (`gabes/schemes/fwm.py:1102-1225`, `1473-1557`; `gabes/core.py:124-175`).
3. pure-85Rb CRC 밀도, optical self-broadening, ground Raman collision/transit dephasing을 온도마다 dissipator에 반영한다 (`gabes/schemes/fwm.py:1427-1448`, `1523-1531`). 따라서 온도 증가를 단순 density gain으로만 해석하지 않는다.
4. 네 susceptibility를 2×2 Maxwell–Bloch 전달행렬로 전파해 seed/conjugate gain을 구하고, detection loss를 포함한 intensity-difference noise를 계산한다 (`gabes/observables.py:17-84`, `256-289`).
5. 두 Raman branch를 서로 다른 mode pair로 유지한다. 잘못된 branch 합산은 테스트에서 거부된다 (`gabes/schemes/fwm.py:140-149`; `tests/test_regression.py:141-162`).
6. Fast는 진공 phase mismatch, Balanced는 굴절률 보정과 16-segment profile, Ultra는 64-segment Gaussian overlap·동적 pump budget·arm-resolved absorption·pump-scatter proxy를 더한다 (`gabes/schemes/fwm.py:1569-1688`, `1764-1779`). 24-level Zeeman 결과는 CG-sum 진단일 뿐 main coupling에는 곱하지 않는다 (`gabes/schemes/fwm.py:1606-1625`).

실험가 관점에서 이 경로는 **detuning convention, branch 선택, 온도·power·waist·cell 길이 민감도, phase matching 및 gain/squeezing 동작점 탐색에 유용한 semi-quantitative reference**다. 특히 실제 control knob와 계산 경로의 연결이 명시적이고 regression anchor가 있다.

한계도 명확하다. `0.74` residual, unit-default phenomenological penalties, Ultra의 `κ=0.1` pump-scatter leakage, smooth Manley–Rowe clamp는 독립적인 microscopic 예측이 아니다 (`gabes/schemes/fwm.py:64-88`, `128-137`, `1639-1688`; `gabes/observables.py:87-115`). full quantum-Langevin vacuum injection이 없으므로 absolute squeezing metrology나 noise spectrum의 최종 기준으로 인용해서는 안 된다.

### 3.2 Generic spontaneous FWM / biphoton

지원 topology는 `87Rb 780/1529 nm` telecom cascade, 두 `133Cs` BTW 채널, 그리고 검증되지 않은 generic diamond template다 (`gabes/schemes/fwm.py:492-673`; `README.md:104-107`). Predictive 경로는 다음 실제 물리를 갖는다.

- `Ω_c²` Autler–Townes 항, single/two-photon Doppler detuning, coherent velocity sum, natural-linewidth decay (`gabes/schemes/fwm.py:758-804`).
- narrow velocity-space source resonance를 측정하고 waveform FWHM이 안정될 때까지 velocity step을 자동 절반화한다 (`gabes/schemes/fwm.py:842-921`).
- calibrated longitudinal mismatch와 absolute transverse mismatch를 결합한 vector `sinc²(|Δk|L/2)` collection weight (`gabes/schemes/fwm.py:307-353`, `936-958`).
- intrinsic source FWHM과 timing-response-broadened detected FWHM을 분리하고, detector efficiency·background·window·filter를 singles/coincidence/CAR/heralding으로 변환한다 (`gabes/observables.py:174-250`; `gabes/schemes/fwm.py:2315-2350`). 이 source/detected 분리는 현재 코드의 중요한 개선이다.

따라서 Biphoton은 **geometry 정렬, wavelength-channel ordering, velocity convergence, filter/jitter/background trade-off를 보는 실험 설계 도구**로 유용하다. 반면 count scale은 first-principles가 아니다. `ψ(τ)`는 OD, pump/coupling, detuning, phase matching을 포함하지만 (`gabes/schemes/fwm.py:777-823`), 반환 `pair_rate_cps`는 별도의 `pump × sqrt(coupling scale) × phase matching × sqrt(N/Nref)` 식이다 (`gabes/schemes/fwm.py:969-979`). `g²`도 peak-normalized waveform과 이 anchored rate로 계산한 accidentals의 조합이다 (`gabes/observables.py:192-230`). 그러므로 absolute brightness, temperature/cell optimization, exact Cs 폭 비는 최종 source metrology로 쓰면 안 된다.

## 4. 오늘의 수치 재검증

### 4.1 Seeded 기준점과 fidelity

Sim 기준 입력 `Δ=+0.9 GHz`, `δ=-8 MHz`, `T=121 °C`, pump 600 mW, seed 8 µW, cell 12.5 mm, after-cell loss 5.5%에서 JIT warm 후 측정했다. 현재 `QE=0.92`, 따라서 `η=0.8694`다 (`gabes/schemes/fwm.py:99-106`).

| tier | solver 설정 | `G_s` | `G_c` | squeezing | 실행시간 |
|---|---|---:|---:|---:|---:|
| Fast | 181 points, `dv=4 m/s`, balanced phase | 5.586 | 4.638 | -6.836 dB | 0.755 s |
| Balanced | 301 points, `dv=2 m/s`, fine phase | 13.897 | 12.992 | -8.040 dB | 2.354 s |
| Ultra | 401 points, `dv=1 m/s`, ultra physics | 13.829 | 12.924 | -7.082 dB | 9.449 s |

Fast gain은 Balanced/Ultra보다 약 60% 낮아 reference 수치용으로는 under-resolved다. Balanced와 Ultra gain은 0.5% 안에서 가깝지만 squeezing은 약 0.96 dB 다르다. Ultra가 단순 고해상도 tier가 아니라 별도의 loss/noise physics를 켜기 때문이다. tier 간 squeezing 차이를 수치 convergence로만 해석하면 안 된다.

### 4.2 Telecom cell-length sweep: 계산된 파형과 표시 rate의 분리

다른 값을 기본값으로 고정하고 cell length만 바꿨다.

| cell | OD estimate | `∫|ψ|²dτ` | raw pair rate | filter 후 rate | source/detected FWHM |
|---:|---:|---:|---:|---:|---:|
| 6.25 mm | 56 | `3.2661e-14 s` | 380 cps | 124.62 cps | 0.1726 / 0.4965 ns |
| 12.5 mm | 112 | `1.3064e-13 s` | 380 cps | 124.62 cps | 0.1726 / 0.4965 ns |
| 25.0 mm | 224 | `5.2257e-13 s` | 380 cps | 124.62 cps | 0.1726 / 0.4965 ns |

파형 norm은 정확히 `1:4:16`, 즉 코드 주석과 물리 문서가 말하는 low-order `OD²` 경향을 이미 보존한다 (`gabes/schemes/fwm.py:800-820`; `docs/FWM_physics.tex:1400-1414`). 그러나 반환 rate는 세 경우 모두 같다. README와 UI는 이 한계를 정직하게 밝히지만 (`README.md:135-147`; `gabes/schemes/fwm.py:2132-2143`), 물리 문서의 “rate scales as OD²” 문장과 실제 사용자 출력 사이에는 해석상 충돌이 남는다 (`docs/FWM_physics.tex:1400-1401`, `1480-1498`).

## 5. 가장 우선할 물리 개선

### P1 — reference-normalized waveform norm으로 상대 brightness 연결

기존 2026-07-14 제안이 여전히 가장 비용 대비 효과가 크다. topology별 측정 anchor `R_ref`는 절대 collection coefficient를 대신해 유지하되,

`R(p) = R_ref × I(p) / I(p_ref)`,  `I = ∫|ψ_phys(τ)|²dτ`

로 상대 변화만 계산 파형에 연결한다. 현재 `ψ_phys`에는 pump/coupling Rabi, detuning, OD, coherent velocity sum, phase matching이 이미 들어 있다 (`gabes/schemes/fwm.py:777-823`). 따라서 현재의 pump/coupling/phase/density scalar를 다시 곱하면 double counting이다.

안전 조건은 다음과 같다.

1. 사용자 plot knob인 `tau_max_ns`를 integration domain으로 그대로 쓰면 rate가 표시창에 의존한다 (`gabes/schemes/fwm.py:983`, `1990-1991`). 고정된 충분한 내부 시간축 또는 frequency-domain Parseval norm을 사용해야 한다.
2. topology별 reference norm은 immutable scalar parameter key로 bounded-cache 한다. 첫 reference solve는 오늘 기준 0.03–0.15 s, 이후 481-point norm 비용은 무시 가능하다.
3. OD reshaping이 기본 off이고 pump depletion도 없는 현재 biphoton 모델에서는 결과를 “reference-normalized relative brightness”로 표시해야 한다. 고-OD absolute metrology라고 부르면 안 된다.
4. 테스트는 reference anchor 보존, `tau_max_ns` 불변성, 6.25/12.5/25 mm에서 low-order `1:4:16`, phase-mismatch suppression, pump/coupling scaling, 기존 scalar의 double-counting 부재를 고정해야 한다. 현재 테스트는 geometry/rate positivity와 폭 수렴은 잘 다루지만 cell-length rate law는 고정하지 않는다 (`tests/test_fwm_generic.py:69-124`, `174-243`).

### P2 — 비용 0인 실험 재현성 정리

- **CLI density:** `fwm_obe.py:28,69-72`는 `atoms.rb85_density`를 출력하지만 실제 solve는 pure-85Rb `hyperfine.number_density`를 쓴다 (`gabes/schemes/fwm.py:1523-1526`). 121 °C에서 각각 `1.2720e19`와 `2.1496e19 m⁻³`, 비는 0.5918이다. 예제 출력이 계산과 다르므로 반드시 통일하는 편이 좋다.
- **QE/reference 표:** 현재 코드는 `QE=0.92`, responsivity `0.59 A/W`이고 물리 문서도 이를 사용한다 (`gabes/schemes/fwm.py:99-104`; `docs/FWM_physics.tex:1018-1021`). 그러나 README 기준표는 아직 `90.47%`, `0.58 A/W`다 (`README.md:238-242`). `analysis/scan_squeezing_delta_T.py:14-15,51`의 설명 주석도 0.9047로 남아 있으나 실행 변수는 현재 상수를 읽는다.
- **fidelity 명칭/위상 설명:** 현 tier는 Fast/Balanced/Ultra (`gabes/schemes/fwm.py:1764-1779`)인데 `docs/FWM_physics.tex:79-89`에는 High fidelity와 Fine mode가 남아 있다. 앱 `info()`는 Ultra를 “self-consistent phase refinement”라고 부르지만 (`gabes/schemes/fwm.py:2117-2122`), 구현은 굴절률이 Δk에 feedback되지 않는 single pass가 정확하다고 명시한다 (`gabes/schemes/fwm.py:1361-1382`).
- **주석/서지:** 모듈 주석은 rate scaling까지 computed라고 표현하지만 실제 출력은 별도 anchor 식이다 (`gabes/schemes/fwm.py:161-166` 대 `969-979`). 같은 주석과 predictive docstring에는 Chen PRR 논문 연도가 2024로 적혀 있으나 README와 앱 reference의 현재 값은 2022다 (`README.md:124-127`; `gabes/schemes/fwm.py:2154-2155`).

이 항목들은 계산 결과를 바꾸지 않지만, 실험 notebook에서 조건을 복제하는 연구자에게는 직접적인 신뢰도 문제다.

Numba fused kernel은 NumPy reference와 수치적으로 일치한다 (`gabes/kernels.py:166-273`; `tests/test_kernels.py:28-59`). 오늘 A/B 결과는 다음과 같다.

|---|---:|---:|---:|---:|
| scan-point | 2.15 s | 0.28 s | 7.8× | `8.63e-13 dB` |
| benchmark `app-fast` | 2.48 s | 0.36 s | 6.8× | `5.63e-14 dB` |
| benchmark `app-fine` | 19.35 s | 2.56 s | 7.5× | `3.91e-14 dB` |

단, benchmark 설명의 `app-fast=121, dv=5`는 현재 UI Fast `181, dv=4`와 다르므로 (`analysis/bench_numba_fwm.py:7-34`; `gabes/schemes/fwm.py:1769-1778`) UI 예상시간으로 직접 인용해서는 안 된다.

### 남은 안전한 후보

1. **Cs 반대 channel raw solve cache:** validation table은 선택하지 않은 Cs channel을 매 headless/figure readout마다 다시 계산한다 (`gabes/schemes/fwm.py:2628-2645`). 오늘 median은 선택 raw가 이미 있을 때 headless 66.9 ms, 반대 channel compute 68.5 ms로 거의 전부가 중복 solve였다. source-physics parameter만 key로 하는 작은 bounded raw cache를 두고 detector-only 통계는 즉시 다시 계산하면 물리를 바꾸지 않는다.
2. **1D angle trace vectorization:** figure 경로는 181개 angle을 Python list comprehension으로 계산한다 (`gabes/schemes/fwm.py:2370-2379`). 이미 있는 vector-grid helper (`gabes/schemes/fwm.py:408-433`)를 1×181 trace에 재사용하면 오늘 median 0.551 ms에서 0.053 ms로 약 10.4배 빨라졌다. 절대 절감은 약 0.5 ms라 우선순위는 낮다.
3. **현재 cache 경계를 유지:** public mutable velocity/scan array를 rounded-float global cache에 넣는 것은 correctness 위험 대비 이득이 작다. 체크리스트가 선택한 bounded topology/solver cache와 figure-only map 분리가 적절하다 (`docs/checklist.json:95-99`).

## 7. 문서·테스트·예제의 실험 레퍼런스 적합성

### 강점

- regression은 frozen seeded baseline, branch convention, CG/decay, coupling factorization을 고정한다 (`tests/test_regression.py:21-50`, `67-196`).
- generic tests는 vector phase matching, wrong-side suppression, detector background, source/detected jitter 폭, predictive velocity convergence, Cs ordering, lazy map, Zeeman diagnostic 범위를 확인한다 (`tests/test_fwm_generic.py:69-243`, `427-492`, `536-610`).
- README와 앱은 absolute pair rate, width calibration, full Langevin 부재를 현재 대체로 정직하게 밝힌다 (`README.md:123-147`; `gabes/schemes/fwm.py:2101-2158`).
- `analysis/scan_squeezing_delta_T.py`는 온도마다 collisional dissipator를 다시 만드는 이유를 설명하고, `analysis/bench_numba_fwm.py`는 최적화가 reference 수치를 바꾸지 않는지 검사한다.

### 주의점

- frozen regression은 legacy compact model의 재현성을 보장하지, 실험의 독립 validation을 보장하지 않는다.
- Fast는 동작점 수치용으로 부족하고 Ultra는 다른 noise model이므로 fidelity를 단순 수렴열로 취급하면 안 된다.
- `fwm_obe.py`의 밀도 출력, README의 QE 표, benchmark tier 이름이 현재 backend와 달라 예제를 그대로 논문 조건표로 옮기면 오류가 생긴다.
- diamond topology는 명시적으로 generic template이며 paper-validated atomic preset이 아니다 (`gabes/schemes/fwm.py:587-639`, `2662-2666`).
- Biphoton의 source/detected width 분리는 좋아졌지만 absolute rate와 `g²` count scale은 anchored이므로, 셀·온도 최적화의 최종 근거로 쓰면 안 된다.

## 9. 최종 결론

Scheme 5의 seeded 경로는 GABES에서 가장 물리적으로 풍부한 축에 속한다. 실제 `85Rb D1` hyperfine coupling, 충돌 dephasing, Doppler 평균, Raman branch, phase mismatch, Maxwell–Bloch propagation, arm loss가 연결되어 있어 **실험 동작점과 민감도 경향을 보는 semi-quantitative reference**로 충분히 유용하다. 그러나 residual calibration, phenomenological Ultra noise와 pump clamp, full Langevin 부재 때문에 absolute noise metrology 도구는 아니다.

Biphoton 경로도 velocity-class waveform, vector phase matching, source/detected 폭, detector/background trade-off를 함께 보는 설계 도구로 가치가 높다. 가장 큰 남은 신뢰도 간극은 계산 파형이 이미 `OD²` 상대 정보를 갖는데 표시 rate가 이를 사용하지 않는다는 점이다. **기존 absolute anchor를 유지하면서 고정 내부 domain의 waveform norm으로 상대 brightness를 연결하는 개선**이 가장 낮은 비용으로 가장 큰 물리 일관성 향상을 준다. 그 전에 또는 동시에 CLI 밀도·QE·fidelity·위상 보정 문구를 현재 backend와 맞추면, runtime 0으로 실험 레퍼런스의 재현성을 크게 높일 수 있다.
