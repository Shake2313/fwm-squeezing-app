## 4. 2026-10-01 이후 핵심 변화: TPD 국소 출력 보정

### 4.1 구현 내용

Fast/Balanced에는 이제 보정 두 층 존재.

1. 원래 hotfix: 교차 susceptibility에 `0.5594938027` 곱함. Sim 2025의 대표 probe gain 15.5 한 점 기준(`gabes/fwm_gain_closure.py:13-15,116-176`).
2. 새 국소 TPD fit: 전파·soft saturation 뒤 두 power gain에 piecewise affine 적용(`gabes/fwm_gain_closure.py:17-28,31-71,74-95`; `gabes/schemes/fwm.py:3295-3307`).

새 fit:

```text
F(G) = aG + b + c max(G-k, 0)
G_out = G + w [F(G)-G]
w = (1-r²)²,  r = |OPD-1.06 GHz|/0.16 GHz
```

- 적용: Fast/Balanced, correction ON, minus branch, `0.90 < OPD/GHz < 1.22`.
- 중심 조건: 118 °C, pump 380 mW, cell-input seed 3.7 µW, 12.5 mm, waist 530/330 µm, 0.32°.
- 10점 EOM 3.030–3.039 GHz.
- ±0.16 GHz는 측정 신뢰구간 아님. 단지 smooth transition width.
- passive cell transmission 없음, 통계 CI 없음, 독립 holdout 없음, transfer matrix calibration 아님(`gabes/fwm_gain_closure.py:51-70`).

개발 기록도 같은 한계를 명시한다(`analysis/fwm_gain_hotfix/tpd_affine_20261001/README_ko.md:8-24,26-57,59-84`).

## 5. Seeded FWM 물리 평가

### 5.1 실제 구현된 물리

- ⁸⁵Rb D1 double-Λ coupling·branch bookkeeping.
- finite-seed Floquet `N_F=3`; 전체 scan을 `N_F=2`와 비교하는 convergence gate.
- 충돌·trace-preserving transit replenishment.
- Maxwell velocity average.
- frequency-specific wavevector, longitudinal phase mismatch, segmented propagation.
- finite pump energy를 위한 post-hoc Manley–Rowe cap.
- pump-only weak-response와 2D non-collinear Doppler는 별도 느린 reference.

claim gate가 제한을 정확히 열거한다: finite reference fields, 별도 pump-only reference, production 1D, 미교정 `ell_s/κ/γ_transit`, Langevin covariance 부재(`gabes/schemes/fwm.py:588-652`).

### 5.2 기본 조건 tier 재검산

조건: OPD 0.9 GHz, TPD -8 MHz, 121 °C, cell 12.5 mm, pump 600 mW, seed 8 µW, η=0.8694.

| tier | 단일 실행 시간 | Probe gain | Conjugate gain | gain-referred diagnostic | 표시 / solve | closure |
|---|---:|---:|---:|---:|---:|---|
| Fast | 1.196 s | 15.504216 | 14.741747 | -7.515184 dB | 401 / 61 | Sim closure ON, local TPD OFF |
| Balanced | 0.368 s | 15.504247 | 14.741778 | -7.515187 dB | 401 / 401 | Sim closure ON, local TPD OFF |
| Ultra | 13.170 s | 394.870678 | 397.097269 | -7.800492 dB | 401 / 401 | 모두 OFF |

모두 Floquet `CONVERGED`, `physical_squeezing_dB=None`.

중요:

- Fast 1회가 Balanced보다 느린 값은 warm 상태·adaptive overhead가 섞인 단일 측정. 속도 서열 보증 아님.
- Ultra의 25배 gain은 더 정밀한 같은 모델 결과가 아님. closure가 꺼진 다른 모델.
- 코드 주석도 Fast/Balanced에 두 보정층, Ultra에는 둘 다 없다고 명시(`gabes/schemes/fwm.py:3533-3548`).

실험 reference로는 Fast에서 후보 탐색, Balanced로 node 보간 제거 확인, Ultra는 **unfitted sensitivity reference**로 따로 기록해야 함. 세 값을 numerical convergence band로 묶으면 안 됨.

### 5.3 Fast detector 의존 adaptive sampling

구조 문제 남음.

- local TPD calibration 활성일 때만 `score_eta=1`(`gabes/schemes/fwm.py:3053-3129`).
- 그 밖에는 사용자의 η가 adaptive score에 들어감.
- 오늘 기본 조건 η `0.8694→0.5`: solve점 `61→55`, 최대 gain 절대차 Probe `0.001431`, Conjugate `0.001447`. 작지만 source가 detector knob에 의존하는 것은 물리 계층 위반.
- 저장 진단에는 다른 OPD full axis에서 최대 상대차 `51.5900%` 존재(`analysis/fwm_gain_hotfix/tpd_gain_diagnostic_20261001/additional_checks.json:3-4`).
- 새 TPD 중심에서는 두 η의 axis/gain 정확히 같음. test도 이 좁은 scope만 고정(`tests/test_fwm_tpd_gain_hotfix.py:63-77`).

기존 `fwm-fast-detector-independent-sampling`을 그대로 우선 처리해야 함. atomic response/gain 기반 detector-free score 사용 가능. 같은 solve budget이면 runtime overhead 거의 없음. 물리식 변경 없음. 보간 선택만 올바른 계층으로 이동.

### 5.4 squeezing 판정

## 6. Biphoton 물리 평가

### 6.1 유용한 부분

- Maxwell velocity-class coherent waveform.
- velocity step 자동 절반 refinement, FWHM 3% 수렴 gate(`gabes/schemes/fwm.py:1418-1461`).
- longitudinal + transverse vector phase matching.
- detector timing response 뒤 source/detected FWHM 분리.
- source 계산과 detector readout cache 이미 분리(`gabes/schemes/fwm.py:1622-1639`).

이 부분은 파형 모양·수렴·수집각 후보 평가에 쓸 만함.

### 6.2 절대 rate 한계

pair rate는 원자 유도 절대율 아님.

```text
R = R_ref/mW × P_pump × sqrt(coupling ratio)
    × vector phase-match weight × sqrt(N/N_ref)
```

OD와 cell length는 waveform을 바꾸지만 rate를 직접 scale하지 않는다(`gabes/schemes/fwm.py:1509-1519`). 따라서 rate·brightness는 literature anchor 기반 source estimate.

filter도 현재 `min(1, BW_filter/BW_source)`인 scalar 비율(`gabes/observables.py:310-315`). 실제 filter transfer convolution 아님.

### 6.3 coincidence gate 문제 재확인

`biphoton_stats()`는

- true coincidence = `pair_rate × η_s × η_i`;
- accidental만 `coincidence_window_ns` 곱함;
- `target_g2_peak`가 있으면 added accidental을 역산해 목표 CAR를 맞춤

으로 계산한다(`gabes/observables.py:322-363`). waveform 안 gate capture fraction이 true coincidence에 안 들어감.

오늘 기본 Reduced model:

- raw source pair rate: `380 cps`.
- filter transmission: `0.32795`; filtered pair rate 약 `124.62 cps`.
- source FWHM `0.173 ns`; detected FWHM `0.497 ns`.
- η_s=η_i=0.1 → true coincidence `1.246 cps`.

| gate | true coincidence | raw accidental | displayed accidental | raw CAR | displayed CAR |
|---:|---:|---:|---:|---:|---:|
| 0.01 ns | 1.246 | 0.0000405 | 0.02898 | 30,771 | 43 |
| 0.05 ns | 1.246 | 0.0002025 | 0.02898 | 6,154 | 43 |
| 1 ns | 1.246 | 0.00405 | 0.02898 | 307.7 | 43 |
| 100 ns | 1.246 | 0.405 | 0.405 | 3.08 | 3.08 |

0.01 ns gate가 detected FWHM보다 약 50배 좁은데 true coincidence 동일. physical gate model 아님.

기존 `biphoton-source-trust-boundary` 안에서 개선 가능:

- normalized detected intensity를 gate 범위에 적분.
- `source_raw`, `filter_passed`, `detected_all_time`, `gate_captured`, `calibrated_display` 분리.
- 비용 `O(Nτ)`, 현재 481점. 무시 가능.
- 기존 값은 legacy/raw key로 보존 가능. 물리 보존하면서 새 quantity 추가 가능.

## 10. 순수 코드 최적화

물리식·출력 행동을 바꾸지 않는 것만 분리.

### 10.1 `ChiPoleRows` 유지·확대

현재 작업 트리에 이미 구현:

- `gabes/schemes/fwm.py:2421-2473`.
- δ마다 eigendecomposition 1회.
- `ChiPoleRows.mean(nodes, weights)`가 같은 discrete velocity sample sum 계산.
- 전 행 guard 실패 시 grid fallback.
- exact measure contract test: `tests/test_fwm_fast_tiers.py:66-89`.

기존 벤치 기록:

- delta-T 한 온도 χ table `1.54 s → 0.010 s`, 약 149×.
- χ 최대차 `1.8e-12`(`analysis/pole_reuse/DEVLOG.md:113-124`).

이것은 순수 최적화. scanner 온도·detuning sweep에 가장 확실한 이득.

### 10.2 detector readout cache

현재 `detection_eff_pct`는 heavy recompute knob(`gabes/schemes/fwm.py:3720-3724`). 그러나 gain 배열 뒤 noise algebra는 싸다(`gabes/schemes/fwm.py:3308-3366`).

순서:

1. `fwm-fast-detector-independent-sampling` 완료.
2. immutable source result: axis, χ/transfer, G_s/G_c, convergence ledger.
3. cheap readout: η, phenomenological N/a, selected TPD.

Balanced/Ultra는 즉시 분리 가능. Fast는 1번 전 단순 cache 금지. 현재 detector-dependent node selection을 숨기게 됨.

### 10.3 atomic response와 보정/전파 cache 층 분리

`gain_closure_enabled` toggle은 원자 Floquet response 자체를 바꾸지 않는다. cross-coupling scale·출력 affine는 그 뒤 적용(`gabes/schemes/fwm.py:2905-2913,3166,3295-3307`).

따라서 atomic χ cache 재사용 가능. 단:

- local calibration 활성 시 10개 axis node 추가(`gabes/schemes/fwm.py:2974-2984`).
- cache axis를 합집합으로 정의하거나 missing node만 solve해야 exact 행동 보존.
- mutable dict/array 공유 금지.

성공 시 correction ON/OFF·detector/noise sweep 가속. 물리 결과 동일.

### 10.4 Biphoton source/readout cache 패턴 재사용

Biphoton은 이미 readout key를 빼고 source를 `lru_cache(maxsize=8)`로 분리(`gabes/schemes/fwm.py:1622-1639`). Seeded 경로가 따라야 할 좋은 내부 예제.

## 11. 실험가용 사용 지침

1. Fast로 넓게 탐색. 최종 후보는 Balanced로 재계산.
2. Fast/Balanced와 Ultra 차이를 error bar로 쓰지 말 것. calibration policy 다름.
3. 결과마다 `gain_closure.model_id`, `output_calibration.model_id/applied/weight`, tier, commit, 조건을 함께 저장.
4. OPD 1.06 GHz TPD data와 비교할 때도 7.7%를 불확도로 쓰지 말 것. in-sample residual일 뿐.
5. η를 바꿨는데 correction-off Fast gain이 바뀌면 detector-dependent refinement artifact 의심.
6. `gain_referred_noise_dB`만 진단값으로 기록. `physical_squeezing_dB=None`도 함께 기록.
7. Biphoton `pair_rate/CAR/g²`는 anchor·target calibration 의존. raw accidental과 gate 정의 같이 보관.
8. 절대 squeezing·bandwidth·nonclassicality는 microscopic covariance, detector SQL, 독립 holdout 전까지 주장 금지.

## 12. 최종 판정

FWM scheme은 빈 toy 아님. finite-seed Floquet, Doppler, Maxwell propagation, phase matching, convergence ledger가 실제 연구 가치 있음. 특히 조건 탐색과 실패 원인 분해에 유용.

그러나 2026-10-01 국소 gain fit은 **물리 모델 교체가 아니라 출력 보정**. 10개 적합점 안에서만 7.7%/7.4%. 사용자 문서와 진단 표가 이 두 번째 보정층을 거의 숨긴 상태가 오늘 가장 큰 신뢰 문제.

가장 싼 다음 행동:

1. output calibration provenance를 UI·claim gate·README·Guide에 노출.
2. Fast detector-independent sampling을 전 OPD로 확대.
3. Biphoton gate-captured coincidence를 waveform 적분으로 추가.
4. seeded source/readout cache 분리.

1–3은 계산 overhead 거의 없음. 물리 경계를 크게 개선. 반면 absolute gain/squeezing 정확도는 문서 수정으로 생기지 않음. 그 부분은 기존 `fwm-tpd-gain-physical-replacement`, 2D finite-seed, depleted propagation, microscopic Langevin covariance, 독립 holdout이 필요.
