## 요약 판단

Scheme 5는 두 층으로 나눠 봐야 한다.

1. **현재 앱의 seeded FWM**은 실제 ⁸⁵Rb D1 finite-seed Floquet OBE, Doppler 평균,
   Maxwell 전파, hyperfine branching, 충돌·transit, 위상부정합을 계산한다. Gold 근방의
   knob 추세와 후보 운전점 탐색에는 유용하다. 그러나 Fast/Balanced의 기본 이득은
   Sim 2025 한 점에 맞춘 `C_mix=0.5594938027`을 쓴 반경험적 추정이고, Ultra는 이 보정을
   쓰지 않는다. solver tier를 바꾸면 수치 정밀도뿐 아니라 물리 모델이 바뀐다.
2. **새 microscopic quantum 연구 경로**는 GKSL reservoir에서 atomic diffusion,
   Nambu field transfer, Gaussian channel, covariance와 검출 PSD까지 실제로 구현했다.
   내부 물리·대수 검사는 강하다. 그러나 production `FWMScheme`는 이를 import하지 않고
   `physical_squeezing_dB=None`을 계속 반환한다. thermal ensemble은 수렴하지 않았고
   no-fit 입력·full atom·holdout도 없다. 실험 절대 squeezing reference는 아직 아니다.
3. **Generic biphoton**은 Doppler velocity-class 복소합, Autler–Townes denominator,
   vector phase matching, timing response를 포함한다. 파형 ordering·geometry·검출 trade-off에는
   유용하다. absolute rate는 문헌 anchor이고 gate/filter/rate 표기 결함이 남아 brightness,
   `g²`, CAR의 독립 예측으로 쓰면 안 된다.
4. 오늘의 가장 중요한 새 수치 발견은 **보정된 기본 Fast가 자체 적응 허용치를 국소적으로
   위반**한다는 점이다. Balanced 대비 최대 `G_s` 상대오차 3.551%, `log10(G_s)` 오차
   0.01515, 진단값 오차 0.17755 dB다. 선언 허용치는 각각 0.01 decade, 0.05 dB다.
   `δ=+99 MHz` 한 곳에 집중돼 p95 오차는 작지만, reference curve의 국소 feature를 놓친다.
   시작 stride를 32→8로 줄이면 61→115 exact node, 이 환경 0.143→0.154 s에서 최대 진단
   오차가 0.00810 dB로 줄었다. 작은 비용으로 즉시 막을 수 있다.
5. 코드·문서·테스트는 강하지만 서로 완전히 동기화되지 않았다. README와 gain-hotfix
   ledger는 정직하다. User Guide와 대표 Δ–T scanner는 현재 gain closure·Fast audit·noise
   경계와 어긋난다. 집중 테스트는 UI 상태 회귀 1건, 양자 테스트는 Windows capsule 경로
   1건이 실패했다.

결론: **실제 반정량 원자물리 및 수치 연구 reference로 유용. Gold 한 점 밖의 절대 gain,
physical squeezing/RF bandwidth, 독립 biphoton brightness reference로는 부적합.**

### 3.1 Fast/Balanced gain closure

`fwm_gain_closure.py`는 off-diagonal `χ_sc`, `χ_cs`만 고정 계수로 줄인다
(`gabes/fwm_gain_closure.py:1-5`, `104-109`). 계수는
`0.5594938027`이며 (`:10-12`), Sim 2025 Gold의 대표 probe gain 15.5 한 점에 fit됐다
(`:54-91`). 불확도는 없고, Zeeman/polarization/angular/Raman/spatial 기여는 분해되지
않는다 (`:58-61`). held-out은 Liu `6.445 vs 8`, McCormick `1.926 vs 9`로 혼합/실패다
(`:92-99`).

추가 atomic solve는 0이다. 기존 χ 배열 두 개의 O(Nscan) 곱과 같은 propagation만 한다.
저장된 통제 benchmark도 on/off runtime regression을 찾지 못했다
(`analysis/fwm_gain_hotfix/DEVLOG.md`, 성능 절). 이 비용 선택은 합리적이다.

그러나 eligibility가 `model_fidelity`에 묶였다. Fast/Balanced만 적용, Ultra와 untiered API는
무조건 미적용이다 (`gabes/schemes/fwm.py:2905-2912`; tests는 이 차이를 의도적으로 고정,
`tests/test_fwm_gain_hotfix.py:102-130`). `resolution` help는 scan/propagation control이라고만
한다 (`gabes/schemes/fwm.py:3865-3868`). 결과적으로 fidelity와 physics variant가 섞였다.

### 3.2 source excess-noise control

UI는 constant `N`과 `N=a·max(G_s−1,0)`를 readout-only knob로 제공한다
(`gabes/schemes/fwm.py:3693-3717`). 기본은 `N=0`, `a=0`이라 기존 출력은 유지한다
(`:3894-3901`). cached mean-field를 건드리지 않고 검출 noise에 `ηN`을 더한다
(`:4097-4115`). 이는 빠른 sensitivity knob로 유용하다.

다만 `N`/`a`는 measured PSD나 microscopic diffusion이 아니다. 코드도
`physical_squeezing_dB=None`과 claim gate를 유지한다 (`:3371-3376`, `4156-4169`).
실험 reference에는 “가정한 source-referred excess가 있으면 어떻게 변하는가”로만 쓴다.

### 3.3 microscopic quantum 연구 경로

새 `gabes/quantum/`, `gabes/fwm_quantum/`는 단순 placeholder가 아니다.

- pump Hamiltonian과 radiative/reset reservoir를 한 generator로 만든다
  (`gabes/fwm_quantum/model.py:13-45`).
- jump commutator에서 channel별 ordered diffusion을 계산한다
  (`gabes/quantum/diffusion.py:57-75`).
- stationary state, Lyapunov moment closure, commutator, PSD/Hermiticity를 수치 gate한다
  (`gabes/quantum/diffusion.py:176-229`).
- field transfer, sideband covariance, carrier power와 intensity-difference PSD를 같은
  reduced model에서 연결한다 (`gabes/fwm_quantum/readout.py:39-68`).
- thermal path packet은 units/frame/source ledger, PSD, digest, path/ensemble convergence
  evidence를 강제한다 (`gabes/fwm_quantum/transport_ensemble.py:192-325`, `328-418`).

이는 experimental code reference로 좋은 설계다. unsupported assumption을 숫자로 덮지 않고
typed evidence와 실패 상태를 유지한다. 그러나 앱 production은 이 모듈을 import하지 않는다.
`gabes/schemes/fwm.py:1-14`, `21-38`의 import/pipeline은 기존 finite-seed mean-field이고,
결과도 microscopic covariance unavailable을 명시한다 (`:3371-3414`).

9월 18일 checkpoint도 전체 목표 20–30%, 공식 milestone 0/4로 평가한다
(`docs/grand_challenge/checkpoint_2026_09_18.md:3-27`). thermal 계산은 360/1,440,
독립 seed 수렴은 0/6, optical 인증 false다 (`:29-39`). 현재 최대 문제는 개별 ODE 정밀도보다
ensemble 수렴과 실험 적용 범위다 (`:69-88`).

## 5. 새 P0 수치 문제: corrected Fast가 허용치를 넘음

기본 Fast와 corrected Balanced의 전체 401점을 비교했다.

| 항목 | 결과 |
|---|---:|
| Fast exact nodes | 61/401 |
| max relative `G_s` error | 3.55114% |
| p95 relative `G_s` error | 5.35×10⁻⁶ |
| max `log10(G_s)` error | 0.0151549 |
| max diagnostic error | 0.177550 dB |
| p95 diagnostic error | 0.0001649 dB |
| declared tolerances | 0.01 decade, 0.05 dB |
| worst location | δ=+99 MHz |

적응 코드는 complex response를 spline하고 high-order `G_s`와 diagnostic의 midpoint disagreement만
본다 (`gabes/schemes/fwm.py:2337-2368`). 최종 spline은 모든 display 점에서 재평가되지만
unsolved quarter point 감사가 없다 (`:2374-2382`). N_F−1 response와 `G_c`도 refinement criterion에
없다. exact row pole guard와는 다른 문제다.

현재 정확도 테스트는 `compute_spectrum()`에 `model_fidelity`를 주지 않는다
(`tests/test_fwm_fast_tiers.py:96-116`). 따라서 gain closure가 ineligible인 **교정 전 모델**만
검사한다. hotfix 테스트는 Gold 동작점 범위 10–20과 유한성만 확인한다
(`tests/test_fwm_gain_hotfix.py:66-92`). corrected Fast 전체 curve 대 corrected Balanced 계약이 없다.

η도 adaptive score에 들어가 source node를 바꾼다. 오늘 측정:

| η | exact nodes | corrected Balanced 대비 max `G_s` error |
|---:|---:|---:|
| 0 | 41 | 39.15% |
| 0.10 | 49 | 3.55% |
| 0.50 | 55 | 3.55% |
| 0.8694 | 61 | 3.55% |
| 1.00 | 67 | 3.18% |

η=0에서 noise curve가 상수라 gain feature refinement가 약해진다. source gain이 detector knob에
따라 바뀌는 것은 layer violation이다. Balanced는 η를 86.94→50%로 바꿔도 `G_s`, `G_c`가
bit-identical했다.

### 값싼 수정

1. corrected Fast 대 corrected Balanced를 full displayed axis에서 test한다.
2. adaptive score를 detector-independent source observables로 만든다. `G_s`, `G_c`,
   high/low-order complex response를 포함한다.
3. 각 surviving interval의 quarter point 또는 최종 unsolved display 점 일부를 audit한다.
4. 임시 안전값으로 stride 8을 쓴다. 오늘 결과:

| stride | exact nodes | 관측 시간 | max `G_s` error | max diagnostic error |
|---:|---:|---:|---:|---:|
| 32 | 61 | 0.143 s | 3.551% | 0.17755 dB |
| 16 | 71 | 0.121 s | 3.551% | 0.17755 dB |
| 8 | 115 | 0.154 s | 0.0180% | 0.00810 dB |

절대 timing noise는 있으나 stride 8의 추가비용은 수십 ms 수준이다. atomic model과 Maxwell
measure를 바꾸지 않고 exact node만 늘린다. **물리 보존, 작은 overhead, P0 권고**다.

## 6. 실험 원자물리 관점

### 6.1 Seeded ⁸⁵Rb double-Λ

유용한 실제 물리:

- real D1 hyperfine `C_F²`, trace-preserving decay, collision dephasing, transit reset.
- beam power/waist→Rabi, pure-⁸⁵Rb vapor density, finite-seed N_F Floquet solve.
- 4σ Maxwell average, frequency-specific bare wavevectors, geometric mismatch,
  64-segment Gaussian overlap와 pump-budget propagation.
- N_F/N_F−1 gate, canonical transfer, photon-flux gap, commutator defect,
  provenance/claim gate.

따라서 resonance 위치, branch 구조, 상대 detuning/temperature/power/geometry trend, solver 부호와
truncation 검산에는 유용하다.

정량 한계:

- `C_mix`가 Gold 한 점 fit. held-out absolute gain 검증 실패.
- Ultra와 calibrated tier가 다른 physics.
- finite-seed production은 1-D Doppler. Gold geometry의 transverse Raman rms 1.380 MHz를
  별도 pump-only reference만 계산한다.
- local pump state를 z마다 self-consistent하게 다시 풀지 않는다. post-hoc pump cap은
  세 field의 nonlinear depletion solution이 아니다.
- production에는 frequency-dependent atomic Langevin diffusion/covariance가 없다.
- inherited residual 0.74, transit 100 kHz, lab penalties의 독립 uncertainty/identifiability가 없다.

실험 사용 등급:

- **가능:** Gold 근방 조건부 gain estimate, knob leverage, 후보점, solver/numerics 비교.
- **불가:** 넓은 조건 absolute gain, IDS squeezing, RF bandwidth, robust tolerance의 독립 예측.

### 6.2 Microscopic quantum path

이 경로는 “유용한 real physics”에 가장 가까운 새 진전이다. 동일 reservoir generator에서 drift와
diffusion을 만들고, companion sideband와 full covariance를 보존하며, detector SQL까지 연결한다.
오늘 `tests/quantum` 1,153건이 통과했다. 연구자에게는 convention·normalization·CP·QRT·loss
처리의 좋은 코드 reference다.

그러나 current example 자체가 `absolute_hot_vapor_prediction=False`,
`experimental_validation=False`라 한다 (`analysis/grand_challenge/readout_audit.py:143-163`).
checkpoint의 local single-velocity API는 9.40–12.51 ms지만, 최근 24-path/120-solve thermal batch는
131.76분이다 (`docs/grand_challenge/checkpoint_2026_09_18.md:101`). thermal promotion은
negligible overhead가 아니다. production 연결 전에 ensemble 수렴, inflow history,
nonlocal Maxwell field, finite seed, depletion, full atom, measured SQL/holdout이 필요하다.

### 6.3 Generic SFWM / biphoton

기본 reduced Rb87 telecom 실행:

- compute 0.247 s.
- raw anchored pair rate 380 cps = 38,000 cps/mW.
- computed source bandwidth 914.761 MHz.
- 300-MHz filter 뒤 pair rate 124.623 cps.
- intrinsic/detected width 약 0.17/0.50 ns.
- displayed peak `g²=308.71`, CAR=307.7.

파형/geometry는 유용하지만 기존 결함이 그대로다.

1. `biphoton_stats()`는 filter를 단순 bandwidth ratio로 줄인다
   (`gabes/observables.py:310-315`). 실제 spectral transfer/convolution이 아니다.
2. true coincidence는 gate window와 무관하고 accidental만 window에 비례한다
   (`gabes/observables.py:322-340`). 오늘 0.01/0.05/1/100 ns에서 true coincidence는 모두
   1.246227 cps, CAR은 30,771/6,154/307.7/3.08이었다. window→0에서 true count가 0으로
   가지 않는다.
3. literature table은 filtered 12,462 cps/mW를 raw anchor 38,000과 비교하면서
   `by construction`이라 표시한다 (`gabes/schemes/fwm.py:4570-4584`). 실제 by-construction 값은
   filter 전 38,000이다.
4. computed bandwidth 915 MHz가 아니라 사용자가 입력한 filter 300 MHz를 reference 300 MHz와
   비교해 PASS한다 (`gabes/schemes/fwm.py:4601-4608`). 입력 자기비교다.

waveform PDF gate 적분, raw/filtered rate plane 분리, configured/computed bandwidth 분리는
O(Nτ) 또는 O(1)이다. source waveform physics를 보존하고 overhead는 사실상 없다.

## 8. 순수 코드 최적화

### 8.1 detector/source cache 분리

`detection_eff_pct`, hidden loss/QE가 아직 `recompute_keys()`에 들어간다
(`gabes/schemes/fwm.py:3688-3728`). Balanced에서 η=86.94→50% 변경은 source gains를
bit-identical하게 유지했다. 전체 recompute는 0.391 s, 같은 cached gains와 pump-scatter를
사용한 정확한 detector remap은 평균 50.4 µs, max error 0이었다. 약 7,800× latency 차이다.

Balanced/Ultra는 즉시 분리 가능. Fast는 먼저 5절처럼 detector-independent refinement로
고쳐야 한다. 그 뒤 η/loss/QE는 pure readout cache로 이동 가능하다. 물리·배열 보존.

### 8.2 atomic response와 gain closure/propagation cache 분리

gain correction은 atomic state/poles/χ diagonal을 바꾸지 않고 cross χ 두 개만 곱한다
(`gabes/fwm_gain_closure.py:104-109`). 현재 checkbox는 heavy recompute key다
(`tests/test_fwm_gain_hotfix.py:175-182`). pole/averaged χ를 cache하고 closure+64-segment
propagation만 다시 하면 atomic eigensolve를 피할 수 있다. 정확한 same-array contract를
test로 고정할 수 있다.

### 8.3 corrected model의 tier 축 분리

physics selector와 numerical fidelity를 분리하고 동일 closure on/off를 Fast/Balanced/Ultra에
허용한다. Ultra corrected reference도 cross χ O(Nscan) 곱만 추가하므로 atomic solve 비용은
늘지 않는다. 이는 속도 최적화라기보다 검증 구조 정리지만, 동일 모델의 cross-tier 비교를
가능하게 해 불필요한 중복 계산/혼동을 줄인다.

### 8.4 biphoton angle trace vectorization

현재 181 angles를 Python loop로 `phase_mismatch_vector()`에 넣는다
(`gabes/schemes/fwm.py:4366-4378`). 이미 있는 vector-grid helper로 1×181 호출 가능하다.
이전 Scheme 5 측정은 약 0.54→0.043 ms였다. 절대 이득은 작지만 behavior-preserving P3다.

### 8.5 test discovery와 Windows capsule

루트 pytest가 ignored `references/AutoOD`의 optional SymPy에서 수집 중단된다. production test
경계를 `testpaths=tests` 등으로 고치면 매일 검증이 실제 suite까지 진행된다. physics 변경 없음.

양자 capsule 실패는 중첩 `.git/grand-challenge-runs/.../.git/grand-challenge-runs/...`에서
source file 생성이 실패했다. extraction은 parent mkdir을 이미 한다
(`analysis/grand_challenge/thermal_campaign.py:291-309`). Windows long-path-safe scratch root 또는
더 짧은 temp root를 쓰면 계산 behavior 없이 portability를 개선할 수 있다
(`tools/thermal_campaign_extend.py:294-307`).

## 9. 문서·테스트·예제 적합성

### 강점

  (`README.md:250-266`, `526-533`). microscopic 연구 디렉터리와 전용 tests도 분리한다
  (`README.md:163-188`).

  runtime, experimental/physical validation false를 보존한다
  (`analysis/fwm_gain_hotfix/validate.py:90-119`, `180-204`). 좋은 연구 기록이다.
- current scientific publication manifest는 squeezing report v8, analytic reconstruction v3,
  quotient v3.1을 분리한다 (`docs/grand_challenge/current_publications.json`). 구조/링크/PDF 검증도
  모두 통과한 기록이 있다 (`docs/grand_challenge/publication_refresh_2026_09_18/validation.json`).
- production tests는 pole/grid, row guard, Floquet convergence, propagation, gain closure,
  excess noise, biphoton, regression을 넓게 덮는다. quantum tests는 reservoir/QRT/CP/channel/
  transport/ensemble 증거 계약을 매우 넓게 덮는다.

1. User Guide는 Fast도 N_F=3/2를 “전체 스캔” 비교한다고 쓴다
   (`docs/Userguide/GABES_User_Guide_v2.html:650-656`). 실제 Fast audit는 solved nodes만 exact다.

## 최종 사용 지침

- **Fast:** 빠른 Gold 근방 탐색. 현재 corrected curve의 국소 +99 MHz feature는 믿기 전
  Balanced 확인.
- **Balanced:** calibrated 1-D/4σ reduced model의 현재 수치 reference. 절대 실험 reference 아님.
- **Ultra:** uncalibrated original reduced model의 grid reference. corrected Fast/Balanced의
  상위 정밀도 버전으로 해석 금지.
- **Microscopic quantum API:** convention, reservoir, covariance, transport 연구와 오류 진단.
  production/실험 absolute prediction으로 승격 금지.
- **Biphoton:** waveform ordering, phase-matching geometry, timing/filter/background 설계.
  absolute rate, gate-dependent coincidence, `g²`/CAR validation에는 사용 금지.

Scheme 5는 비어 있는 toy가 아니다. 실제 원자·전파·양자 연구 코드가 상당하다. 지금의 병목은
더 큰 Hamiltonian 자체보다 **calibration과 fidelity의 분리, adaptive certificate, source/detector
layer, thermal convergence, held-out evidence**다. 이 경계를 닫으면 계산비용을 거의 늘리지 않고도
experimental reference 품질을 크게 높일 수 있다.
