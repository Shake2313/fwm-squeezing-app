## 요약 판단

Scheme 5는 **실제 물리를 상당히 포함하는 유용한 반정량 실험 설계 도구**이지만,
두 모드의 신뢰 범위를 분리해야 한다.

1. **Seeded ⁸⁵Rb D1 FWM**은 hyperfine-weighted 4-level double-Λ, 충돌·transit
   reset, Doppler 평균, finite-seed Floquet OBE, Maxwell–Bloch 전파, 위상 부정합과
   pump-energy ledger를 계산한다. detuning·온도·세기·셀 길이·빔 기하의 **상대 추세와
   후보 운전점 탐색**에는 가치가 있다. 그러나 기본점에서 `G_s=406.9205`는 문헌의
   약 15보다 약 27배 크고, field-only canonical map도 photon-flux gap `−2.3796`,
   commutator defect `3.4591`을 보인다. `physical_squeezing_dB=None`이 맞는 결론이다.
   절대 이득, IDS squeezing, RF bandwidth의 정량 reference로 쓰면 안 된다.
2. **Generic SFWM / biphoton**은 cascade/diamond topology, velocity-class coherent
   sum, Ω_c² Autler–Townes denominator, vector phase matching, timing response와
   detector/background bookkeeping을 포함한다. 파형 ordering, collection geometry,
   jitter/filter/window trade-off를 살피는 데 유용하다. 그러나 절대 pair rate는
   문헌 anchor이고, 기본 reduced source bandwidth는 `914.761 MHz`인데 validation
   table의 `300 MHz` 행은 계산 폭이 아니라 사용자가 넣은 filter 설정을 검사한다.
   coincidence window가 true coincidence를 자르지 않는 오류도 남아 있다. 따라서
   절대 brightness, `g²`, CAR, ns 폭의 독립 예측 reference로는 부적합하다.
3. 8월 29일 이후 **Cs 반대 채널 source cache**와 **gain-only 신뢰 경계 문구**는
   개선됐다. 반면 seeded detection efficiency의 source/detection cache 분리,
   biphoton gate 적분, covariance typing, 오래된 scan example 정리는 아직 미완료다.
4. 가장 높은 비용 대비 효과는 새 고차원 원자 모델보다 현재 `in_progress/ready`
   trust-boundary 항목을 닫는 데 있다. 그중 metadata·명칭·cache 분리는 O(1) 또는
   O(scan) 후처리라 원자 물리를 바꾸지 않고 거의 무부하로 가능하다. 2-D finite-seed,
   microscopic Langevin, full Zeeman은 유용하지만 별도 연구 규모다.

## 3. 현재 구현된 물리와 실험적 가치

### 3.1 Seeded ⁸⁵Rb D1 double-Λ

실제 물리로 인정할 수 있는 층은 다음과 같다.

- F=2,3 ↔ F'=2,3 네 준위와 `sqrt(3 C_F²)` drive/readout, pure-⁸⁵Rb density,
  trace-normalized manifold population을 한 번만 세는 `1/[2(2I+1)]=1/12`
  coupling ledger가 있다 (`gabes/schemes/fwm.py:38-85`).
- temperature-dependent collision broadening, ground-Raman dephasing와
  trace-preserving thermal transit reset이 있다
  (`gabes/schemes/fwm.py:2349-2418`).
- finite reference seed/conjugate field를 둔 Floquet susceptibility 네 성분을 풀며,
  일반 `N_F≥1` kernel을 제공한다 (`gabes/schemes/fwm.py:2087-2105`). 보고 가능한
  production 경로는 `N_F≥3`을 요구하고 (`:2441-2481`), 현재 기본 스캔 전체에서
  N_F=3을 N_F=2와 복소 응답·전달·이득·위상·최적점으로 비교한다 (`:2678-2697`).
- photon-flux basis의 `Q⁻¹T_fieldQ`, gain, gap, commutator defect를 따로 보존한다
  (`gabes/observables.py:166`, `gabes/schemes/fwm.py:2791-2819`). 이는 두 power gain만
  보고 이상 Bogoliubov map이라고 가정하는 것보다 훨씬 좋은 audit surface다.
- nonlegacy propagation은 bare frequency별 k와 vacuum/geometric mismatch를 쓰며,
  diagonal susceptibility 안의 loss를 post-cell loss로 다시 세지 않는다. 최종
  Manley–Rowe cap은 에너지 ledger이지 self-consistent depleted three-field solve가
  아님을 코드가 명시한다 (`gabes/schemes/fwm.py:2720-2724`).
- pump-only stationary state/trace-zero weak response와 2-D non-collinear Maxwell
  평균은 독립적인 느린 audit reference로 있다. production finite-seed 경로를 몰래
  대체하지 않으며, production은 여전히 1-D다 (`gabes/schemes/fwm.py:117-200`,
  `1722`, `1824`; `README.md:246-259`).

이 물리는 공명 branch와 feature 위치, 상대적인 knob leverage, Floquet truncation과
전파 부호를 연구하는 데 충분히 유용하다. 다만 field-only map이 noncanonical이고
frequency-dependent reservoir diffusion/covariance가 없으므로, 수치 수렴만으로
quantitative gain이나 squeezing을 만들 수 없다. 현재 claim gate가
`MEAN_FIELD_DIAGNOSTIC`, `QUANTITATIVE_GAIN_UNSUPPORTED`,
`PHYSICAL_SQUEEZING_UNAVAILABLE`을 강제하는 것이 옳다
(`gabes/schemes/fwm.py:570-626`, `2797-2802`, `2838-2848`).

### 3.2 Generic SFWM / biphoton

이 경로도 단순 그림만 그리는 코드는 아니다.

- ⁸⁷Rb telecom cascade, ¹³³Cs cascade 두 채널, generic diamond topology를
  실제 wavelength/direction/decay 자료 구조로 만든다
  (`gabes/schemes/fwm.py:1000`, `1041`, `1095`).
- reduced waveform은 Maxwell velocity class를 **복소 진폭으로 합산**하고, two-photon
  denominator에 Ω_c² Autler–Townes 항을 포함하며, 자연붕괴 envelope와 vector
  phase-matching amplitude를 적용한다 (`gabes/schemes/fwm.py:1266-1331`).
- 좁은 velocity-space source resonance를 먼저 측정하고 step을 반감해 파형 FWHM이
  수렴할 때까지 계산한다 (`gabes/schemes/fwm.py:1350-1429`).
- longitudinal OD reshaping은 lumped model의 high-OD 과장을 인정해 default off로 둔다
  (`gabes/schemes/fwm.py:1314-1327`). 이것은 과도한 모델을 기본값에 숨기지 않는 좋은
  실험적 판단이다.
- intrinsic source width와 timing-response-broadened detected width를 분리하고,
  detector efficiency/background/window/filter를 count ledger로 전달한다
  (`gabes/observables.py:285-364`).

그러나 absolute pair-rate 법칙은 pump × sqrt(coupling scale) × vector phase match ×
sqrt(density ratio)인 문헌 anchor다. OD와 cell length가 파형에는 들어가도 rate를 직접
스케일하지 않는다 (`gabes/schemes/fwm.py:1477-1487`). README도 이 경계를 정확히
밝힌다 (`README.md:208-225`). 따라서 유용한 출력은 waveform ordering, geometry,
상대적인 detector trade-off이며, absolute brightness validation이 아니다.

## 4. 2026-08-29 이후 반영된 변화

### 개선된 부분

1. **UI와 문서의 trust boundary.** 현재 title은 `Squeezing / Biphoton`이고 통합
   `Detection efficiency η`를 노출한다 (`gabes/schemes/fwm.py:2986-2999`,
   `3080-3095`). diagnostics table은 이제 `Gain-only diagnostic (physical squeezing
   unavailable)`을 직접 표시한다 (`:3532-3541`; commit `8d8bbe7`). User Guide도
   절대 이득 미지원, production 1-D, Langevin/covariance 부재를 명시한다
   (`docs/Userguide/GABES_User_Guide_v2.html:650-677`, `855-862`).
2. **Cs 비교 source cache.** detector-only parameter를 source key에서 빼고 bounded
   LRU cache를 추가했다 (`gabes/schemes/fwm.py:1585-1608`). detector efficiency만
   바꿔 두 번 reference table을 읽어도 반대 채널 source solve가 한 번뿐임을 테스트한다
   (`tests/test_fwm_generic.py:675-720`; commit `d98bdf4`). 8월 29일 보고서의 순수
   최적화 후보 하나는 완료된 셈이다.
3. **분석 문서의 층 분리.** low-pump와 variable-audit README는 gain-referred
   ideal-law 진단을 microscopic squeezing과 구분한다
   (`analysis/squeezing/low_pump_power/README.md:1-8`, `32-43`;
   `analysis/squeezing/variable_audit/README.md:1-10`). v7도 gold gain에 맞춘 residual과
   별도 Gaussian covariance를 **조건부** 결과로 밝히며 1-D 수치 수렴과 실험 검증을
   구분한다 (`docs/squeezing_report/README_v7.md:12-18`).

### 아직 닫히지 않은 부분

- `fwm-gain-only-trust-boundary`는 `in_progress`다. `S_dB` compatibility alias,
  `historical_gain_only_diagnostic` 명칭, passive floor/cap mask, source/detection cache
  contract와 acceptance fixtures가 남아 있다 (`docs/checklist.json:713-750`).
- 통합 `detection_eff_pct`와 hidden `loss_pct`, `qe_pct`는 `recompute=False`가 없어서
  default인 heavy key가 된다 (`gabes/schemes/base.py:44-56`;
  `gabes/schemes/fwm.py:3080-3095`). 실제 atomic transfer에는 영향을 주지 않는데도
  전체 N_F=3/N_F=2 solve를 다시 한다.
- biphoton gate/filter semantics와 seeded covariance typing은 미완료다.

## 5. 오늘의 직접 수치 확인

### 5.1 Seeded 기본점

조건: Δ=+0.9 GHz, δ=−8 MHz, 121 °C, L=12.5 mm, pump=600 mW,
seed=8 µW, angle=0.32°, η=0.8694, Fast, N_F=3 대 N_F=2 전체 스캔.

| 항목 | 현재 값 |
|---|---:|
| 새 Python process 첫 compute | 6.349 s |
| 보간된 `G_s` / `G_c` | 406.920464 / 409.231143 |
| gain-referred diagnostic | −8.654249 dB |
| small-signal photon-flux gap | −2.379569 |
| 동작점 commutator defect | 3.459118 |
| Floquet gate | `CONVERGED` |
| validation level | `MEAN_FIELD_DIAGNOSTIC` |
| `physical_squeezing_dB` | `None` |

문헌 reference는 gain≈15, IDS −7.8 dB지만 현재 reduced model이 이를 재현한다고
주장하지 않는다고 README가 명시한다 (`README.md:404-418`). 위 결과에서 Floquet
`CONVERGED`는 **같은 축약 모델의 절단 수렴**일 뿐, 절대 이득이나 noise covariance의
실험 검증이 아니다.

η만 0.8694→0.5로 바꾼 두 번째 계산은 2.165 s가 걸렸고, `G_s`, `G_c`, 두 small-signal
gain, `T_field_small_signal`, `T_canonical_small_signal`은 모두 bitwise identical였다.
바뀐 것은 gain-referred detector diagnostic뿐이다. 같은 이미 계산된 gain array의 η
remap median은 15.63 µs였다.

### 5.2 ⁸⁷Rb telecom biphoton 기본점

| 항목 | 현재 값 |
|---|---:|
| cold source compute | 0.227 s |
| raw anchored pair rate | 380.000 cps |
| reduced source bandwidth | 914.761 MHz |
| 300-MHz scalar filter throughput | 0.327955 |
| filter 뒤 pair rate | 124.622727 cps |
| intrinsic / detected FWHM | 0.172599 / 0.496519 ns |
| `g²` peak / CAR | 308.710 / 307.710 |
| velocity step / status | 0.179153 m/s / converged |
| OD / vector phase-match weight | 112.0 / 1.0 |

source bandwidth `914.761 MHz`와 문헌 anchor `약 300 MHz`의 차이는 validation table에서
검사되지 않는다. 현재 행은 `params['filter_bandwidth_mhz']`가 300에 가까운지만 보고
`user filter-bandwidth setting check`라고 쓴다 (`gabes/schemes/fwm.py:3879-3881`).
문구는 사실이지만 표의 `PASS`를 source-bandwidth validation으로 읽을 위험이 있다.
이 행을 `configured`로 바꾸거나 literature comparison 밖으로 옮기는 것은 runtime 0의
신뢰도 개선이다.

### 5.3 coincidence window 오류 재현

동일한 계산 파형에서 detector window만 바꿨다.

| coincidence window | true coincidence | CAR |
|---:|---:|---:|
| 0.05 ns | 1.246227 cps | 6154.202 |
| 1.00 ns | 1.246227 cps | 307.710 |

`biphoton_stats()`는 accidental에만 window를 곱하고 true coincidence는
`pair_rate × η_s × η_i`로 고정한다 (`gabes/observables.py:322-340`). 그래서
window→0에서 true count가 줄지 않고 CAR가 발산한다. 기존 테스트는 background와
window를 동시에 키운 뒤 CAR가 감소하는지만 확인해 이 오류를 잡지 못한다
(`tests/test_fwm_generic.py:128-140`). detected delay PDF의 정의와 gate 중심을 명시하고
그 구간의 capture fraction을 적분해야 한다. 481-point 배열의 O(Nτ) 후처리라 source
solve와 원자 물리는 그대로이며 비용은 사실상 무시할 수 있다.

| `fwm-finite-seed-angular-doppler-production` | P1, large, `ready` | 기존 velocity 축에 독립 `v_x` quadrature가 추가됨 | 1.38-MHz transverse Raman scale을 production에 넣는 실제 물리 개선이다. 그러나 2-D×Floquet 전체 스캔이므로 opt-in bounded reference부터 해야 한다 (`docs/checklist.json:1582-1603`). |
| `fwm-quantum-langevin-microscopic-core` | P2, research, `parked` | Ω_RF×velocity×segment covariance/Van Loan 전파 | physical squeezing에는 필요하지만 큰 연구 과제다. 값싼 trust gate를 닫기 전에 기본 경로에 넣지 않는다 (`docs/checklist.json:950-983`). |
| `fwm-rf-squeezing-spectrum-and-bandwidth` | P1, large, `parked` | 주파수별 full covariance + detector transfer | TPD scan을 RF spectrum으로 재명명해서는 안 된다. covariance provider가 생긴 뒤 활성화하는 현재 순서가 맞다 (`docs/checklist.json:1607-1630`). |
| held-out biphoton/squeezing validation | `blocked_external` | 실험·calibration 비용 지배 | 같은 data를 fit과 validation에 재사용하지 않는 predeclared holdout이 필요하다. 코드 최적화로 해결할 수 없다. |
| full Zeeman reference | P2, research, `parked` | density vector 4²=16 → 24²=576, Floquet·velocity와 결합 | 물리적으로 매력적이나 편광/B-resolved holdout 전에는 계산비용과 미식별 자유도만 크게 늘어난다 (`docs/checklist.json:991-1016`). |

결론적으로 **물리를 보존하며 거의 무부하인 것**은 trust/provenance metadata, η cache
분리, gate 적분, validation-row 명칭, detector-only filter 후처리다. Exact covariance는
싸지만 현재 잘못된 출력의 동작을 그대로 보존하는 최적화가 아니라 physics correction이다.
2-D finite-seed, Langevin, full Zeeman은 negligible-overhead로 분류하면 안 된다.

## 7. 순수 코드 최적화 후보

### 7.1 최우선 — seeded detector knobs를 heavy cache key에서 분리

`ParamSpec.recompute`의 기본값은 `True`이고 (`gabes/schemes/base.py:44-56`),
`detection_eff_pct`, `loss_pct`, `qe_pct`에는 override가 없다
(`gabes/schemes/fwm.py:3080-3095`). UI cache도 recompute key 전체를 그대로 heavy
`compute()`에 넘긴다 (`streamlit_app.py:637-642`, `1920-1923`).

- η 변경 heavy recompute: 2.165 s
- 이미 계산된 gain array의 η remap: 15.63 µs
- 비율: 약 138,500×
- source arrays: 확인한 6개가 모두 bitwise identical

source result에서 η-dependent `gain_referred_noise_dB`를 떼고 `_seeded_observables()`에서
계산하면 된다. 세 knob를 navigate-only로 만들고 legacy override 우선순위를 그대로
테스트하면 원자 물리와 현재 숫자를 정확히 보존할 수 있다. 이 변경은 checklist
acceptance criterion에도 이미 명시돼 있다 (`docs/checklist.json:746`).

### 7.2 Biphoton 1-D angle trace vectorization

figure 경로는 181개 angle을 Python loop로 `phase_mismatch_vector()`에 넣는다
(`gabes/schemes/fwm.py:3639-3651`). 이미 있는
`phase_mismatch_vector_grid()` (`:916-942`)를 1×181 grid로 재사용할 수 있다.

- loop median: 553.18 µs
- vector grid median: 48.23 µs
- speedup: 11.47×, 절감 약 0.505 ms/render
- Δk 최대 절대차: `1.16×10⁻¹⁰ m⁻¹` (floating-order 차이 수준)

절대 이득은 작지만 계산 의미를 바꾸지 않는 안전한 정리다.

### 7.3 이미 완료된 최적화는 다시 제안하지 않음

Cs 반대 채널 source-result bounded cache와 detector key 제외는 이미
`gabes/schemes/fwm.py:1585-1608` 및 `tests/test_fwm_generic.py:675-720`에 들어왔다.
이전 보고서의 제안을 반복 구현 대상으로 세면 안 된다.

## 8. 문서·테스트·예제의 experimental-reference 적합성

### 강점

- README와 User Guide가 seeded absolute gain 미지원, physical squeezing unavailable,
  production 1-D / separate 2-D reference, biphoton anchored rate를 현재 코드와 일치하게
  설명한다 (`README.md:185-225`, `230-274`; User Guide `:650-677`, `855-862`).
- Floquet direct/block/kernel parity, full-scan N_F gate, passive Beer–Lambert,
  Option-A, pump-only null/trace-zero response, pole/residue, 2-D angular grid/cutoff,
  claim gate를 서로 다른 테스트가 맡는다 (`tests/test_fwm_floquet.py`,
  `test_fwm_propagation.py`, `test_fwm_pump_response.py`,
  `test_fwm_angular_doppler.py`, `test_fwm_validation.py`).
- v7은 source hash, conditional model, independent Gaussian limit와 실험 validation을
  구분한다 (`docs/squeezing_report/README_v7.md:12-18`, `34-51`). thermal/excess-noise
  report도 생성한 frequency response가 physical squeezing spectrum이 아니라고 명시한다
  (`docs/fwm_thermal_excess_noise_report/README.md:1-16`).

### 남은 위험

1. **오래된 Δ–T 예제의 과도한 명명과 solver 불일치.** 현재
   `analysis/squeezing/scan_squeezing_delta_T.py:1-28`은 여전히 “Maximise
   intensity-difference squeezing”, “squeezing peaks”라고 말하고 `S_dB`를 직접
   최적화한다. 더 심각하게 batch shortcut은 `chi_matrix_table(..., n_f=...)`를 생략해
   함수 기본값 N_F=1을 사용한다 (`:101-120`; `gabes/schemes/fwm.py:2087-2105`).
   production은 N_F≥3 full-scan gate를 요구한다 (`gabes/schemes/fwm.py:2478-2481`).
   기본점의 81-point 비교에서는 N_F=1과 N_F=3 진단 차이가 약 0.009 dB로 작았지만,
   이것은 전체 Δ–T domain의 truncation validation이 아니다. 예제를
   `gain_referred_diagnostic`으로 재명명하고 N_F=3/N_F=2 gate 또는 명시적인 historical
   fixture 표지를 붙여야 한다.
2. **예제의 stale parameter provenance.** 같은 파일 `:14-15`, `:46-52`는 QE를
   0.9047이라고 주석 처리하지만 `fwm.QE_DETECTOR`의 현재 값은 0.92다
   (`gabes/schemes/fwm.py:211-216`). `:136-142`는 normalization을
   `p_F/[2(2I+1)]`라고 설명하지만 현재 코드는 외부 `p_F` 없이 `1/[2(2I+1)]`만 쓴다
   (`gabes/schemes/fwm.py:52-85`). 실험 reference로 배포하기 전에 고쳐야 하며 비용은 0이다.
3. **legacy coincidence test의 주장 강도.** `coincidence_stats()` 자체는 ideal lossless
   TMSV 가정을 문서화하지만 (`gabes/observables.py:229-245`),
   `tests/test_coincidence.py:35-48`은 noncanonical GABES gain을 넣고 “FWM spectrum
   nonclassical”을 자동으로 assert한다. 이것은 물리 검증이 아니라 공식상 R>1이 되도록
   만든 ideal-law fixture다. checklist도 이미 이를 지적한다
   (`docs/checklist.json:755-786`). 테스트 이름과 출력 문구를 ideal fixture로 제한하고
   production claim gate가 nonclassical badge를 막는 test를 병행해야 한다.
4. **biphoton validation table의 bandwidth 행.** 계산된 source bandwidth와 filter 설정을
   분리해 표시해야 한다. 현재 default의 914.761 대 300 MHz 차이를 사용자가 즉시 볼 수
   있어야 하며, input knob 일치는 `PASS`가 아니라 `configured/by construction`이다.
5. **detector gate coverage 누락.** 작은 window가 true coincidence capture를 줄인다는
   단일변수 test가 없다. current test는 window와 background를 동시에 바꾼다
   (`tests/test_fwm_generic.py:128-140`).

## 10. 실험 연구자용 최종 권고

현재 Scheme 5를 다음처럼 사용하는 것은 타당하다.

- seeded: 공명 branch, 상대 detuning/temperature/power/geometry 민감도, 수치 truncation과
  propagation convention 점검.
- biphoton: waveform ordering, phase-matching geometry, timing response와 detector/background
  trade-off 탐색.

다음 용도에는 아직 사용하지 않는다.

- 절대 seeded gain이나 −dB squeezing의 prediction/fit reference.
- TPD 축을 RF squeezing spectrum 또는 bandwidth로 해석.
- reduced biphoton의 absolute pair rate, `g²`, CAR, 폭을 독립 validation으로 인용.
- gain-derived ideal TMSV helper를 실제 open atomic channel의 nonclassicality 증거로 사용.

실행 우선순위는 다음이 적절하다.

1. η/loss/QE를 atomic cache에서 분리하고 `S_dB`/passive floor/cap compatibility surface를
   정리한다.
2. biphoton true-coincidence gate 적분, computed source bandwidth와 configured filter의
   분리, detector test를 추가한다.
3. stale `scan_squeezing_delta_T.py`의 명칭·QE·normalization·N_F 경계를 고친다.
4. reference parameter provenance와 residual/transit uncertainty를 닫는다.
5. 그 뒤에만 opt-in finite-seed 2-D reference를 연결한다.
6. microscopic Langevin/full covariance/RF bandwidth와 full Zeeman은 별도 연구 과제로
   유지하고 held-out data와 함께 검증한다.

요약하면, **Scheme 5는 실제 원자·전파 물리를 계산하는 좋은 “방향과 구조” reference**다.
현재 코드가 스스로 선언하듯 **절대 이득·물리적 squeezing·독립 biphoton brightness의
reference는 아니다.** 가장 싼 다음 단계는 더 큰 Hamiltonian이 아니라 source/detection
경계, gate 정의, 명칭과 예제의 정확성을 닫는 일이다.
