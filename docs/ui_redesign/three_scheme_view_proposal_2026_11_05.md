# Λ·리드버그·Magneto 뷰 개선안 — 2026-11-05

직접 사용자 요청: 앞서 확인한 논문 그림과 그래프 조사에 따라 세 뷰의 개선안을 제시한다.

## ⟦AI⟧ 채택·진행 상태

사용자가 후속 요청으로 **1단계 공용 지도·선택 체계 구현**을 승인했다. 2026-11-05 이 단계의 공용 지도, 선택 연동, 네이티브 행 스캔·캐시·중단/재개, 판독 필터와 내보내기를 구현했다. [검증 기록](audit/common_map_stage1_2026_11_05.md) 참조.

이후 사용자가 **2단계 Λ EIT/AT·CPT·이조 지도 구현**을 요청해 완료했다. [2단계 검증](audit/lambda_stage2_2026_11_05.md). 원래 제안의 Λ 비교 축 Δc·바닥상태 완화율·빔 각도를 기존 해에 연결했다. 새로운 시간영역·시계 안정도·통계적 EIT/ATS 판정은 포함하지 않는다.

이어 **3단계 리드버그 EIT/AT 지도·출력·온도·유한 IF 감도 연결**을 요청해 완료했다. [3단계 검증](audit/rydberg_stage3_2026_11_05.md). 현재 대기는 4–5단계이다. 기존 계산의 실제 IF 좌표·위상·잡음 예산과 opacity 가정 시나리오를 보존하며, Doppler의 제한된 표본 범위를 전체 이조 최적화로 확대 해석하지 않는다.

## ⟦AI⟧ 원래 제안과 근거

최초 요청은 개선안 제시였다. 아래의 기본 화면·구성·순서는 그때 작성한 AI 제안이며, 이후 승인·진행 범위는 위 상태와 [단계 계획](plan.md)에 기록한다. 물리 기본값 변경의 승인은 포함하지 않는다. 근거는 [리드버그·Λ 그림 조사](audit/rydberg_lambda_figures_2026_11_05.md), [Magneto 원문 확인 기록](log.md), 기존 사용자 결정 [D17·D18](decisions.md#d18)이다.

### 1. 공통 화면

**Conditions → 비교 조건 선택 → 지도·곡선 → 선택 단면 → 성능 지표**의 순서로 통일한다. 물리량과 강조점은 스킴이 선언한다.

| 위치 | 구성 | 역할 |
|---|---|---|
| 상단 Conditions | 공통 Atom 팝오버, 스캔 축·고정 조건, Advanced | 원자·셀과 실험 조건 설정. 온도·셀 길이 직접 입력 유지 |
| 비교 영역 첫 줄 | 비교할 변수, `Map / Curves`, 범위·계산 표본 수 팝오버 | 지금 무엇을 변화시키는지 명시. 물리 변수 하나를 주 비교 축으로 사용 |
| 비교 영역 입력 줄 | 현재 비교 변수의 숫자 입력, 해당 스킴의 빔 출력·동작점 입력 | 직접 입력과 지도 선택이 같은 현재 조건을 가리킴. 위 Conditions에 중복 배치하지 않음 |
| 중심 그래프 | 2차원 지도 또는 조건별 곡선 | 전체 변화와 선택한 조건 확인. 변수의 주파수·자기장 단위를 축에 표시 |
| 정밀 단면 | 같은 x축의 1–2개 물리량 | 확대·판독선·툴팁으로 원래 표본 읽기 |
| 오른쪽 판독부 | 현재 표본의 값, 현재 조건의 대표 지표 | 포인터 위치의 값과 전체 스캔의 선폭·최적점을 구분 |
| 하단 조건 탐색 | 같은 변수축의 성능 추세 또는 소수의 비교 패널 | 최적화 목적이 있을 때 표시. 모든 부가 분석을 한 번에 펼치지 않음 |

메인 화면에서 숫자를 입력하고 선택을 확정하면 자동 반영한다. Apply 버튼·새 사이드바·변수 슬라이더는 추가하지 않는다. 계산 범위·표본 수 변경도 입력 확정 후 자동 계산하며 취소·진행 상태를 제공한다.

### 2. Λ: 공명과 코히런스를 읽는 화면

기존 EIT / AT / CPT 모드와 T·Re χ 연결을 유지한다. 모드 선택은 계산 목적과 프리셋을 뜻하며 자동 EIT/ATS 판정 결과로 표시하지 않는다.

| 모드 | 처음 보여줄 비교 | 정밀 단면 | 아래 성능 그래프 | 다른 비교 축 |
|---|---|---|---|---|
| EIT | 광학 이조 × 결합광 세기의 투과율 지도 | T/OD 전환 + Re χ, 같은 이조축 | 대비·FWHM의 결합광 의존성 | Δc, ground coherence relaxation, beam angle |
| AT | 광학 이조 × Ωc/2π 지도 | 두 흡수 피크 표시. T에서는 두 최소점 | 추출 간격과 입력 Ωc/2π 기준 | Δc, 완화율 |
| CPT | 좁은 이광자 이조 δ 단면 + 소수의 결합광 조건 곡선 | T와 Re χ, kHz 축 | 같은 출력축의 대비·FWHM·대비/FWHM 세 작은 패널 | γgg/2π, Δc, beam angle |

- EIT/AT의 지도 y축은 결합광 세기 또는 그 조건에서 계산된 Ωc/2π 중 하나를 선택해 표시한다. 빔 지름·Rabi 기준은 함께 보존하고 축 표시 변경만으로 재계산하지 않는다.
- CPT는 좁은 선의 판독이 우선이므로 첫 화면은 곡선 중심으로 둔다. `Map`에서 δ × 결합광 세기 또는 δ × γgg 지도를 연다.
- 별도 `Detuning map`은 Δp × Δc를 보여주고 이광자 공명선을 표시한다. 두 레이저 이조의 관계를 확인하는 화면으로, 결합 세기 지도와 동시에 크게 펼치지 않는다.
- 대비의 배경·정규화 기준을 먼저 정하고 판독과 내보내기에 남긴다. 대비/FWHM은 신호 품질 지표이며 시계 안정도·Allan deviation으로 부르지 않는다.
- 선폭은 실제 계산 표본의 양쪽 반높이 교차가 있을 때 표시한다. 미분해·스캔 끝에 걸린 경우를 0 폭으로 연결하지 않는다.

근거: [Fleischhauer Fig. 1·7·9](https://journals.aps.org/rmp/abstract/10.1103/RevModPhys.77.633#f9), [Anisimov Fig. 1·2](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.107.163604#f1), [AIP CPT Fig. 4·5](https://doi.org/10.1063/5.0336834). 마지막 논문의 주입비·VCSEL 변조 출력은 GABES의 단일 Λ 제어 변수로 복사하지 않고, 세 성능 그래프의 비교 방식을 참고한다.

### 3. 리드버그: 스펙트럼에서 RF 검출 성능까지

기존 EIT / AT electrometry를 유지하고, AT 안의 `Sensitivity` 분석을 강화한다. 새로운 시간영역 모드를 추가한 것처럼 보이지 않도록 한다.

| 화면 | 처음 보여줄 비교 | 정밀 단면 | 아래 성능 그래프 | 확장 비교 |
|---|---|---|---|---|
| EIT | 광학 이조 × Probe power 투과율 지도 | 선택 출력의 T, 잔류 Zeeman 폭 비교선 선택 | 대비·FWHM vs Probe power | Coupling power, 유효 온도, 잔류 폭 |
| AT | 광학 이조 × ΩRF/2π 투과율 지도 | 선택 RF 조건의 T, 두 투과 최대점과 간격 | 광학 피크 간격 및 입력장·추정장 | RF detuning 지도, 고정 RF별 소수 패널 |
| Sensitivity 분석 | 현재 광학 스캔에서 유한 IF 응답과 감도 | T와 응답 크기/위상. 현재 동작점·스캔 내 최선점 구분 | 같은 출력축의 응답도·PSN/총 잡음 등가 전기장 | IF 주파수, 출력, 유효 온도 |

- EIT의 현재 보상 유무 비교를 없애지 않고 `Compare`의 잔류 폭 항목과 보조선으로 둔다. 주 비교 축은 실험자가 조절하는 Probe power로 확장한다.
- 지도에서 선택한 RF 조건, 스펙트럼의 두 피크, 교정 그래프의 점이 함께 움직인다. RF off·미분해에서는 추정장 값을 비우고 이유를 한 번 표시한다.
- Probe/coupling 중 스캔한 축과 고정 레이저 이조를 명시한다. 장의 RMS/Peak 규약, RF 전이 쌍과 각도 계수는 판독·내보내기와 일치해야 한다.
- 감도는 기존 유한 IF 응답과 잡음 예산을 사용한다. 정적 T 기울기와 유한 IF 응답을 같은 값으로 취급하지 않는다. 감도 축에는 작을수록 좋다는 방향을 표시한다.
- 기존 Probe power·Cell-heating 추가 분석을 메인의 목적별 조건 탐색으로 연결한다. 히터 설정·유효 온도·cold spot을 묶어 같은 온도로 바꾸지 않는다.
- 수치 최적점은 계산한 범위 안의 결과로 표시한다. 논문의 최적 출력·감도 숫자에 맞추기 위해 보정하지 않는다.

근거: [Ju Fig. 2–5](https://arxiv.org/pdf/2606.04354#page=5), [AT 지도와 교정 Fig. 7](https://www.nature.com/articles/s41378-026-01221-4/figures/7), [이중 RF Fig. 2·4](https://journals.aps.org/pra/abstract/10.1103/PhysRevA.108.033712#f2). 마지막 자료는 지도·조건별 패널의 표현을 참고하며 강한 이중 RF Floquet 스펙트럼을 현재 약한 SIG 모델의 결과로 제시하지 않는다.

### 4. Magneto: 편광 반응과 전이 타깃을 구별

사용자 결정대로 Magnetic field 스캔은 회전, Optical detuning 스캔은 투과율을 기본 신호로 유지한다. 아래의 편광각 비교는 별도의 투과율 비교 영역이다.

| 목적 | 권장 구성 | 판독·해석 |
|---|---|---|
| 기본 스캔 | 선택 축의 신호 단면·전체 구간 개요 | Bcommand=0과 Bz=0 기준을 유지. 물리적 바이어스와 검사 커서 구분 |
| QWP 각도 비교 | 현재 0·9·18·27·36·45° 및 사용자 각도의 분리 T 곡선. `Map`에서 자기장/광학 이조 × QWP 각도의 T 지도 | 각도는 QWP 빠른 축과 입사 선편광 사이. 지도와 곡선 모두 원래 T를 판독 |
| D선 비교 | 비교 이름을 `D line`으로 명확히 하고 D1·D2 두 조건 비교 | 두 전체 초미세구조 가지의 비교이며 Fig. 5의 네 전이 비교와 구별 |
| 초미세 전이 타깃 | 같은 동위원소·D선에서 레이저를 Fg→F′ 공명에 맞춘 조건별 곡선/소수 패널 | 원자 데이터의 공명 주파수·ground-F 기준·광학 이조 연결을 검증한 뒤 제공. 다른 초미세 준위를 임의 제거하지 않고 기존 다준위 모델 사용 |
| 셀 비교 | 지원하는 셀 모델을 같은 축·색 척도의 두 패널로 표시 | 기존 모델끼리 비교. 논문의 순수 셀/Ne 50 Torr 셀 정량 재현과 구분 |
| Show shot noise | 켰을 때만 선택 신호의 광자잡음 감도 패널·지표 | 자기장 스캔 회전/광학 스캔 투과 기준 유지. 총 잡음 감도로 표시하지 않음 |

- QWP 비교의 기본 곡선 표현은 현재의 세로 분리를 유지한다. 화면에 공통 T 척도와 오프셋 사용을 명시하고, 겹쳐 보기·지도를 선택할 수 있게 한다.
- 회전은 현재 모델이 지원하는 선형 편광만 표시한다. 0° 기준선과 비선형 편광의 현재 조건을 혼동하지 않게 라벨을 붙인다. 계산 범위 밖인 모든 각도를 표에 반복 나열하지 않고 패널 설명 한 곳으로 모은다.
- `Hyperfine target`은 지원을 검증한 후 노출한다. ⁸⁷Rb D1의 1→1, 1→2, 2→1, 2→2처럼 타깃 공명에 맞춘 레이저 조건의 비교이며, 해당 전이만 고립한 계산으로 부르지 않는다. 주파수 기준을 바꿔도 같은 물리 레이저 주파수를 유지하는지 확인한다.
- 현재 Buffer 모델에는 압력 넓어짐·확산이 포함되지 않는다. 셀 종류 패널의 형태 비교와 논문 재현을 구별한다. 지원하지 않는 순수 셀 모드나 가스 압력 선택기를 UI만 만들어 노출하지 않는다.

근거: [PRA 81, 023416 Fig. 4–6](https://journals.aps.org/pra/abstract/10.1103/PhysRevA.81.023416#f4). Fig. 4는 Ne 셀의 편광각, Fig. 5는 같은 D1의 네 전이, Fig. 6은 순수 셀의 편광각이다.

### 5. 공용 그래프·조작 계약

- 지도 호버는 검사, 클릭·드래그 종료는 선택 확정. 지도 행, 정밀 단면, 오른쪽 표와 성능 그래프의 선택점이 하나의 조건을 공유한다.
- 기존 초록 확대 구간·점선 판독선과 조건 선택을 연결한다. 드래그 중 브라우저 표본 미리보기, 종료 때 한 번 확정. 이미 계산한 지도의 이동·확대는 원자 해를 다시 구하지 않는다.
- 같은 물리량의 패널끼리 축·색 범위를 공유한다. T/OD는 순차 색상, 부호가 있는 분산·차이는 0 중심 발산 색상, 감도는 양수 범위의 로그 척도를 사용한다.
- 선 색은 조건에 고정하여 T·분산·감도 패널 사이에서 유지한다. 세로 분리·배율·정규화는 원래 수치를 변경하지 않으며 표시 방식을 명시한다.
- 곡선별 실제 주파수 격자를 보존한다. 지도에는 공통 물리 좌표로 계산한 행 또는 원래 좌표 기반 셀을 사용한다. 서로 다른 배열 인덱스를 같은 주파수로 취급하지 않는다. 미계산·범위 밖·미분해는 수치 0과 구별한다.
- 판독부는 현재 패널의 물리량을 기본으로, 다른 물리량 전체 표는 접어서 제공한다. 전체 스캔에서 얻은 대표 지표에는 산출 좌표를 붙인다. 모델 설명은 범위가 달라지는 지점에 짧게 표시하고 자세한 조건은 팝오버에 둔다.
- 데스크톱은 지도/단면과 판독부를 나란히, 좁은 화면은 지도→단면→핵심 판독 순서로 배치한다. 소수 조건 비교는 2×2/2×3까지 허용하고 좁은 화면에서는 한 열로 읽는다.
- 기존 DEFAULTS·스킴 왕복 상태·프리셋·단위 입력을 보존한다. 지도 선택과 숫자 입력이 서로 다른 물리값을 가지지 않게 한다.

### 6. 적용 순서와 완료 기준

| 단계 | 패치 범위 | 완료 기준 |
|---|---|---|
| 1 | 공용 지도·단면·조건 선택, 스캔 행 캐시·진행/취소, 공용 판독 필터 | 현재 곡선·지도·표·내보내기 좌표/값 일치. 포인터 이동 중 solve 0회, 조작 종료 한 번 확정. 추가 스캔 범위·표본 수·완료 상태 명시 |
| 2 | Λ EIT/AT 지도, T/OD·분산 연결, CPT 대비/폭, 이조 지도 | 기존 해·판독과 대조. 두 피크/두 반높이 교차 및 미분해 상태 검증. EIT/ATS 자동 판정을 새로 주장하지 않음 |
| 3 | 리드버그 EIT/AT 지도, 출력·온도 분석 이동, 유한 IF 감도 연결 | 입력장/추정장·RMS/Peak·스캔 축 일치. 기존 감도/잡음 배열 재사용. 최적점의 범위·해상도·가정 보존 |
| 4 | Magneto QWP 지도, D line 명칭, 지원 범위별 판독 정리, 전이 타깃·지원 셀 비교 | 자동 Signal 규칙과 선형 회전 범위 유지. 전이 타깃의 공명·기준 변환을 검증한 항목만 표시. 셀 근사 범위와 광자잡음 기준 명시 |
| 5 | 세 스킴의 통합 검수·가이드 | 숫자/지도 왕복, DEFAULTS·스킴 왕복, 확대·드래그·툴팁·키보드, 좁은 화면, 원래 배열의 JSON/CSV와 단위 일치. 공유 그래프 변경의 다른 스킴 영향 검사 |

새 물리 개발과 분리할 항목: 전체 과도 시간 응답, Ramsey/STIRAP, 다중 Λ 시계 안정도, 강한 이중 RF 스펙트럼, Buffer 압력 넓어짐·확산에 기반한 논문 정량 재현, 통계적 EIT/ATS 판별. 현재 모델로 계산 가능한 지도를 먼저 제공하고, 이 기능들의 도입은 별도 범위로 정한다.
