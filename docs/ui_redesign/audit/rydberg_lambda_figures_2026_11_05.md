### 리드버그: 기본 그래프와 비교 축

| 사용 목적 | 권장 그래프 | 읽을 값 | 현재 코드와의 거리 |
|---|---|---|---|
| EIT 조건 선택 | 주파수 단면 + `광학 이조 × Probe power` 투과 지도 | 선택 출력의 T, 대비, FWHM. 보상 유무는 같은 조건의 두 선 또는 두 패널 | 보상 비교·출력별 피크/폭 분석 이미 있음. 지도는 출력별 스펙트럼 저장과 추가 스캔 연결 필요 |
| AT 전기장 측정 | `광학 이조 × ΩRF/2π` 투과 지도 + 선택 행의 AT 스펙트럼 | 두 투과 최대점과 실제 피크 간격. 옆에 입력장·피크 기반 추정장 | 현재 0·1·3.7·7.4 MHz 및 사용자 입력 비교와 장 추정 재사용. 연속 지도에는 더 많은 RF 조건 계산 필요 |
| RF 공명·이조 영향 | `광학 이조 × RF detuning` 지도, 고정 RF 세기별 2–3 패널 | 비대칭·피크 이동·분리 변화 | 기존 단일 RF 이조 파라미터의 반복 계산. 강한 이중 RF Floquet 부구조의 재현은 별도 문제 |
| 약한 RF 검출의 동작점 | 같은 x축의 T, 유한 IF 응답 크기/위상, 잡음 등가 전기장 | 현재 판독선과 스캔 내 최선 지점을 따로 표시 | 유한 IF 응답 좌표·복소 위상자 배열과 감도 배열 이미 있음. 시각화·판독 연결 추가. 단순 정적 dT/dΔ를 유한 IF 응답으로 부르지 않음 |
| 출력 최적화 | 같은 출력축의 대비·FWHM, 응답도, PSN/총 감도 | 가장 높은 피크와 가장 좋은 감도의 위치 차이 | 출력 스윕·감도 판독 재사용. 출력 스윕 전체에 유한 IF/잡음 계산을 연결해야 함 |
| 온도 조건 탐색 | `광학 이조 × 유효 온도` 지도 + 온도별 대비·폭·감도 | 온도 증가에 따른 신호·불투명도·감도의 절충 | 기존 cell-heating 추가 분석 우선 재사용. 히터 설정·유효 온도·cold spot을 분리해 표시 |

**우선순위:** EIT는 Probe power 비교를 주 비교 축으로, 잔류 Zeeman 폭 비교를 선택 가능한 보조 축으로 둔다. AT는 RF 세기 지도를 먼저 제공하고, 감도 분석과 온도 탐색은 목적별로 연다. 논문의 특정 최적 출력·온도·감도를 GABES 결과에 강제하지 않는다.

AT에서 광학 피크 간격과 입력 RF Rabi는 구분한다. 스캔한 레이저, 이조 기준, Doppler에 따른 축 해석, 장의 RMS/Peak 규약을 함께 기록한다. RF off·두 피크 미분해는 0 간격으로 연결하지 않는다.

### Λ: 모드마다 강조할 그래프

| 모드/질문 | 권장 그래프 | 비교 축·표시 | 현재 코드와의 거리 |
|---|---|---|---|
| EIT 창이 어떻게 열리는가 | 같은 x축의 T와 Re χ + `이조 × 결합광 세기` 지도 | Ωc/2π 또는 Pc 중 하나를 지도 축으로 선택. T/OD 표시 전환 | 현재 T·Re χ 및 결합광 조건 비교 재사용. 흡수계수 배열도 이미 반환. 연속 지도는 추가 조건 스캔 |
| 두 레이저가 어긋나면 어떻게 되는가 | `Δp × Δc` 또는 `단일광자 Δ × 이광자 δ` 지도 + 선택 단면 | 이광자 공명선과 선택점. 좌표계는 명시적으로 전환 | 기존 Δc 입력의 반복 계산으로 구성 가능. RMP Fig. 9의 정량 조건을 그대로 재현한다는 뜻은 아님 |
| AT 이중선이 어떻게 갈라지는가 | `Δp × Ωc/2π` 지도 + 두 흡수 최대점의 간격 추세 | T 표시에서는 두 최소점. 미분해 구간을 끊어서 표시 | 기존 AT 피크 검출·입력 Ωc 기준 재사용. Λ의 흡수 피크와 리드버그의 투과 피크를 같은 규칙으로 표시하지 않음 |
| CPT의 신호와 폭을 어떻게 절충하는가 | 좁은 δ 단면 + 같은 Pc축의 대비·FWHM·대비/FWHM 세 작은 패널 | 필요 시 γgg/2π를 비교 조건으로 선택. 단면은 kHz, 폭·대비 정의를 함께 표시 | CPT 폭은 기존 값 재사용. 대비 기준을 먼저 명시하고 품질 지표 판독을 추가해야 함. 시계 안정도나 Allan deviation으로 부르지 않음 |
| 정렬·열운동·코히런스가 미치는 영향 | beam angle 또는 γgg에 따른 단면/폭/대비. 온도는 별도 비교 | 우선 3–5개 선, 연속 탐색이 필요할 때 지도 | 현재 angle·ground relaxation·temperature 파라미터의 반복 계산. 속도군별 기여 지도는 현재 평균 χ 배열만으로 만들 수 없으므로 원래 속도별 응답 노출이 추가로 필요 |

**우선순위:** T·Re χ 두 패널은 유지한다. EIT에서는 결합광 세기와 두 레이저 이조 지도, AT에서는 분리 지도, CPT에서는 대비·폭·대비/폭을 강화한다. 분산 기울기는 표시할 수 있지만 펄스 지연·저장 효율·STIRAP/Ramsey 시간 응답은 현재 정상상태 그래프와 구분해야 한다.

Λ의 δ=Δp−Δc와 리드버그 cascade의 이광자 공명 Δp+Δc=0은 스킴이 선언한다. 공용 UI가 같은 부호로 하드코딩하지 않는다. Anisimov의 Akaike 가중치처럼 보이는 자동 EIT/ATS 판정은 기존 모드 이름이나 두 피크 검출만으로 생성하지 않는다.

### 공통 화면·조작 설계

1. Conditions와 직접 입력은 현재 규칙 유지. 아래에서 **비교할 조건 하나**를 고르고, 이미 계산한 스펙트럼 단면을 먼저 보여준다.
2. 연속 스윕은 넓은 2차원 지도 하나로 보여준다. 지도 위 선택 행·점을 움직이면 아래의 정밀 단면, 판독표, 성능 지표의 선택점이 함께 움직인다. 호버는 검사, 클릭·드래그 종료는 선택 확정이다.
3. 추가 조건은 2×2 또는 2×3 작은 패널로 나누되 x/y축과 색 척도를 공유한다. 3D 표면은 기본으로 쓰지 않는다. 피크 겹침·가림과 정밀 좌표 읽기를 피하기 위함이다.
4. T·OD처럼 한 방향으로 커지는 양은 순차 색상, Re χ·차이 신호는 0 중심 발산 색상, 감도/잡음은 필요할 때 로그 척도. 같은 물리량을 비교하는 패널끼리 색 범위를 맞춘다. 개별 패널 최대값 정규화는 명시적으로 선택할 때만 한다.
5. 실제값을 겹쳐 보는 것이 기본. 선이 많을 때만 세로 분리를 켜며 가산 오프셋·배율 여부를 명시한다. 원래 수치·단위는 툴팁·표·내보내기에 남긴다.
6. 기존 초록 확대 구간과 판독선 조작을 연결한다. 움직이는 동안은 계산된 표본으로 브라우저 미리보기, 놓을 때 선택 확정. 계산하지 않은 조건의 정밀한 곡선을 있는 것처럼 그리지 않는다. 가장 가까운 계산 행을 읽거나 조작 종료 후 필요한 조건만 계산한다.
7. 현재 조건마다 주파수 격자·스캔 폭이 달라진다. 특히 리드버그는 큰 RF에서 범위가 넓어진다. 지도를 위해 동일한 물리 주파수 격자를 따로 계산하거나 원래 좌표 기반 셀을 구성하고, 계산 범위 밖을 비운다. 배열 인덱스를 같은 주파수로 취급하거나 결측을 0으로 채우지 않는다.
8. 출력·조건 스윕은 계산 행 캐시와 취소·완료 상태를 표시한다. 지도 이동 자체는 재계산하지 않는다. 정밀도·표본 수를 조용히 낮추어 인터랙션을 빠르게 만들지 않는다.
