# ⟦AI⟧ 공용 지도·선택 체계 1단계 검증 — 2026-11-05

직접 사용자 요청: “1단계인 공용 지도·선택 체계부터 구현해주세요.”

## 구현 범위

- 기존 spectral comparison 계약에 Map/Curves·Quantity·Selected condition을 공용으로 제공. 지도 행과 숫자 입력, 정밀 단면, 현재 물리량 표, 조건별 판독, 대응하는 네이티브 요약점이 같은 조건을 가리킨다.
- 포인터 조작 중에는 브라우저에서 이미 계산한 배열로 미리 보고, 종료 시 한 번 확정한다. 선택한 조건은 기존 실제 파라미터로 반영한다. 캐시된 해·view를 유지하며 단순 지도 탐색 때문에 물리 해를 다시 계산하지 않는다.
- 각 조건의 실제 비균일 x 좌표를 셀 경계·툴팁·선택에 사용한다. 결측·미계산·범위 밖을 공백으로 유지하고 서로 다른 배열 인덱스를 동일 주파수로 간주하지 않는다. 셀 경계는 기기 픽셀에 맞춰 인공적인 줄무늬를 제거한다. 원래 표본과 내보내기 배열은 변하지 않는다.
- 같은 물리량의 행은 공통 색 범위, 부호량은 0 기준 발산 색, 로그 패널은 양수 로그 색을 사용한다. 숫자·범주형 비교 변수를 지원한다.
- 기존 숫자 비교 변수는 Condition scan에서 범위·균일 표본 수 2–41을 지정하면 자동 계산한다. 스캔 시작의 정확한 현재 조건은 추가 보존되므로 총 행 수가 표본 수보다 하나 많을 수 있다. 네이티브 주파수 격자는 유지한다.
- 세션별 순차 행 계산·LRU 캐시, 진행률, 중단·재개, 실패 시 부분 결과 보존. 중단은 진행 중인 한 행의 계산을 강제 종료하지 않는다. 고정 조건·스킴이 바뀌면 이전 작업의 결과가 새 문맥에 섞이지 않는다.
- JSON/CSV는 원래 배열과 선택/스캔 메타데이터를 보존한다. 내부 raw/view 캐시는 브라우저·내보내기에 포함하지 않는다. 사용자 가이드 원본과 배포 HTML에 사용법을 반영했다.
