## 구현 범위

- EIT/AT는 결합 출력의 네이티브 조건 지도를 기본으로 표시한다. 기본 비교는 P/4–4P 주변의 대수 간격 9조건이며 허용 범위·현재 값·P=0을 보존한다. CPT는 소수 조건의 곡선과 kHz 단면을 기본으로 연다. 기존 물리 프리셋과 각 조건의 601점 격자는 그대로이다.
- 결합 출력↔유효 Ωc/2π 지도 y좌표는 기존 빔 변환을 선언한 표시 축이다. AT 기본은 Rabi 축, EIT 기본은 출력 축. 실제 varied parameter와 입력값은 mW이며 축 전환은 브라우저 표시만 바꾼다.
- Quantity에서 T·OD·Re χ 선택. 정밀 단면의 T/OD는 같은 자리를 사용하고 분산은 별도 패널이다. OD=αL의 원래 값을 사용해 T가 수치적으로 0이 된 곳도 유한 OD를 보존한다. AT 피크 표시는 기존 추출기의 실제 두 흡수 최대점(투과 최소점), 추세는 추출 간격과 입력 Ωc/2π 기준이다.
- CPT는 대비 ΔT, FWHM, ΔT/FWHM을 같은 실제 제어 변수 축의 세 패널로 표시한다. 배경은 각 조건 전체 스캔의 min T, 대비는 T(δ=0)−min T. 기존 표본 괄호 폭을 재사용하되 양쪽 반높이 교차가 없거나 중간에 결측이 있으면 폭·비율을 비운다. 6간격 미만은 resolution-limited로 판독/요약에 남긴다. 품질 비율을 시계 안정도로 부르지 않는다.
- Compare에 Ground relaxation·Beam angle·Detuning map 추가. 동적으로 선택한 물리 입력만 그래프 옆에 내리고 Atom·Advanced 중복을 제거한다. Δp×Δc 지도는 모든 모드에서 광학 MHz 축이며, δ=0 대각선을 표시한다. 일반 CPT의 δ(kHz) 단면과 구별한다.
- 기존 공용 행 캐시·추가 스캔·중단/재개·선택·내보내기 재사용. 요약의 표본 상태도 해당 행과 함께 추출/조립한다. 이전·다음 표본은 합집합 격자에 끼인 다른 조건의 표본을 건너뛰고 선택 조건의 네이티브 격자를 따른다.
- 기본 확대는 공명 주변으로 잡되 데이터는 그대로 유지한다. 밀집 지도 y라벨의 겹침을 피하고, 단위 없는 판독의 문자 1을 숨긴다. 사용자 가이드 원본·배포 HTML 동기화.
