# FWM diagram v3 — 설계·변경 기록

2026-09-07. `fwm_quotient_structure_v3.html`은 같은 폴더의
`squeezing_analytic_reconstruction_v2.tex`와 GABES의 선언된 FWM 범위를
설명하는 정적 해석 지도다. v2 HTML과 물리 엔진은 수정하지 않는다.

## 화면 설계

- 주 화면은 물리 입력 → 원자 응답 → 평균장 / 미시 요동 → 검출의 흐름이다.
- 평균장 복소 진폭을 검출에 전달하는 연결을 복원한다. 공분산 입력 상태와
  검출기의 외부 입력도 표시한다.
- 물리 흐름 / 수식과 가정 / 검증 근거 보기는 같은 데이터와 선택 상태를
  공유한다. 상세는 오른쪽 패널, 좁은 화면에서는 도식 아래에 표시한다.
- 모바일은 도식을 축소하지 않고 순차 카드로 재배치한다. 각 카드의
  ‘받는 곳’은 병렬 의존관계를 텍스트로 보존한다. 카드 순서를 모든 단계의
  선후 관계로 해석하지 않는다.
- 외부 폰트·수학 라이브러리·네트워크 요청 없이 실행한다. 수식은 HTML
  sub/sup와 로컬 수학 글꼴로 표시하며, 긴 수식은 자르지 않는다.
- 화면의 상태 배지는 문서상의 범위다. 현재 시뮬레이터 운전점의 실제
  수렴 여부를 읽거나 계산하지 않는다.

## 물리·수학적 수정

1. 생산 원자 계산은 finite-seed Floquet 경로로, 별도 pump-only 참조는
   trace-constrained steady state와 trace-zero weak response로 구별한다.
2. 미시 주파수 의존 M_q와 D, 검출 응답이 필요한 경계 및 물리적
   S_−(Ω)의 미완성 상태를 주 도식에 표시한다.
3. 응답 잔차 7.32e-17을 생산/참조 차이로 표시하지 않는다. 8 µW finite-seed
   비교 오차 2.503e-3, pump-only gauge parity 8.37e-15와 별도로 표시한다.
4. 검증은 전역 사다리나 정의되지 않은 2-cell이 아니라 주장별 근거다.
5. 평균장 D → 검출 F 연결을 포함하는 D/X/E/F 부분구조는 조건에 따라
   유도 N형을 갖는다. N-free / 전체 SP 단정과 하드코딩된 N 카운터를 제거한다.
6. 규약 환경과 수학적 quotient를 구별한다. 물리 입력과 모델 가정은
   규약으로 숨기지 않는다.
7. flux gain gap의 스칼라 검사, 전체 정준성, Gaussian complete positivity,
   실제 미시 저장고 모델의 타당성은 다른 조건이다.
8. Gaussian channel 합성·잡음의 부분순서·속도 평균과 전파의 비가환성은
   별도의 해설로 둔다. 이것들은 신규 엔진 구현을 뜻하지 않는다.

## 과거 표현의 위치

- ‘레거시 스칼라’ 종착점과 과거 오류 설명을 주 도식에서 제거했다.
- 이득 진단은 물리적으로 의미 있는 flux 검사와 조건부 이상 극한만 남긴다.

  미시 저장고 상세에 남기되 실제 잡음·보편적 하한과 구별한다.

## v3 재개정 방안 — 그룹 내부 도식과 단일 HTML의 설명 완결성

2026-09-07 추가. **설계안이며 아직 HTML에 적용하지 않았다.** v3는 임시
빌드이므로 파일명·표시 버전을 유지한다. 이번 기록은 위 제작 이력에 이어지는
다음 개정의 요구사항이다. 기존 검증 결과는 이 설계안의 구현·렌더링 검증을
뜻하지 않는다.

### 1. 목표와 유지할 범위

다른 AI에게 `fwm_quotient_structure_v3.html` 하나만 전달해도 입력, 원자 해,
응답, 평균장, 원자 잡음, 공분산, 검출의 연결과 각 단계의 성립 조건을 거의
재구성할 수 있게 한다. 사람에게는 전체 흐름과 선택한 그룹의 내부 구조를
서로 다른 배율로 제공한다. 가독성을 위해 정보를 접을 수는 있지만, 필요한
의존관계 자체를 지우거나 외부 TeX를 열어야만 알 수 있게 만들지는 않는다.

- v3의 전체 지도, 평균장 → 검출 연결, 외부 입력 포트, 주장별 검증 근거,
  현재 물리적 스퀴징 예측의 미완성 표시는 유지한다.
- v2의 **그룹 내부 노드·분기·합류·직접 전달 연결**을 복원한다. v2의
  배치와 수식을 통째로 복사하지 않고 현행 TeX 및 생산 코드와 맞춘다.
- 레거시 스칼라 종착점, 옛 점수식, rate/Sylvester 근사, dressed-k 중복
  분산 경로, 과거 최적점과 버전별 오류 이야기는 새 주 지도와 내부 도식에
  복원하지 않는다. 이력은 기존 v2와 원문에 둔다.
- 현재 UI의 `Squeezing indicator`가 평균장 기반 지표라는 사실은 범위
  설명에 남긴다. 이를 물리적 `S_−(Ω_SA)`와 같은 출력으로 연결하거나,
  조건부 이상식을 현행 지표의 일반 계산식이라고 표시하지 않는다.
- 내부 정규화처럼 UI에 숨겨져도 현행 계산에 실제로 쓰이는 요소는 필요한
  만큼 설명한다. ‘UI에 없는 설정’과 ‘폐기된 계산 경로’를 같은 뜻으로
  취급하지 않는다. 예를 들어 현행 결합의 `1/12` 구조 인자와 경험적 잔여
  계수의 역할은 응답의 절대 크기를 이해하는 데 필요하다.

### 3. 화면과 탐색 방식

1. **전체 지도**는 v3의 작은 수의 그룹을 유지한다. 그룹 카드에
   ‘내부 구조 보기’를 제공하고 하위 노드 수와 핵심 분기만 짧게 예고한다.
   기존 ‘물리 흐름 / 수식과 가정 / 검증 근거’는 정보의 관점으로 유지한다.
   별도로 전체/그룹 상세의 깊이를 선택하며 두 기능을 혼동하지 않는다.
2. **그룹 내부 도식**은 지도 아래의 넓은 본문 영역에 표시한다. 현재
   320–390px inspector 안에 v2의 넓은 SVG를 축소해 넣지 않는다. inspector는
   선택한 내부 노드의 정의·수식·조건·출처를 읽는 보조 패널로 사용한다.
   그룹 제목과 상위 지도에서의 위치, 이전/다음 연결을 계속 표시한다.
3. **전체 상세 펼치기**는 모든 그룹의 내부 도식과 텍스트를 문서 순서로
   읽는 모드다. AI 전달, 검색, 복사, 인쇄에 사용한다. 모든 그룹을 펼쳐도
   하나의 거대 SVG로 합치지 않으며, 노드 순서와 실제 의존관계는 구별한다.
4. 각 내부 노드는 짧은 이름과 핵심 출력만 표시하고, 선택하면 정의·차원·
   대표식·가정·검증을 읽게 한다. 긴 식을 생략 부호로 자르지 않는다.
   분기 많은 응답/공분산 그룹은 내부 소그룹으로 나누되 공유 입력을 남긴다.
5. 좁은 화면에서는 내부 도식을 순차 카드로 재배치한다. 카드마다 **입력
   출처와 출력 목적지**, 분기 조건을 텍스트로 표시해 병렬/선택 관계를
   보존한다. 전체 화면을 축소해 글자를 작게 만드는 방식은 사용하지 않는다.
6. 그룹과 내부 노드에 안정된 앵커를 부여하고 URL fragment로 직접 이동하게
   한다. 키보드 선택·접기·복귀를 지원하며, 선택 강조에만 색을 쓰지 않는다.

화살표의 의미도 복원한다. 계산 입력 전달, 같은 문제를 푸는 대안,
특정 가정에서만 가능한 축약, 검증 대상 연결, 수학적 형태의 유사성은 각각
다르다. 선 모양과 짧은 라벨을 함께 쓴다. ‘미완성’은 연결의 구현 상태이며
‘대안’이라는 의미와 같은 점선 하나로 표현하지 않는다. 전체 SP/N-free나
정의되지 않은 2-cell 표기는 되살리지 않는다.

#### 4.1 입력과 규약 — `input`

- 네 준위 `g₁(F=2), g₂(F=3), e₂(F′=2), e₃(F′=3)`와 pump/probe/
  conjugate의 double-Λ 결합을 작은 준위도로 표시한다. `p`는 probe이며
  pump의 약자가 아니다.
- 실험 입력의 각 사용처를 연결한다: 파워·1/e² 강도 반경 → Rabi 구동,
  온도 → 밀도·속도 분포·충돌률, L·교차각·수집 면적 → 전파/모드 정규화.
  열적 transit 재장전과 순수 위상감쇠가 다른 채널임을 B 상세와 연결한다.
- 주파수 관계 `ω_p=ω_pump−ω_HF+δ`, `ω_c=2ω_pump−ω_p`,
  `Ω_beat=ω_HF−δ`와 별도의 RF `Ω_SA`를 내장한다. 식은 rad/s,
  표시값은 `/2π`, Fourier 부호는 `exp(−iΩt)`로 고정한다.
- 광자속 정규화 `P_j=ℏω_j|α_j|²`, 실제 수집 면적, 입력 평균장과
  `V_in`을 구별한다. 밝은 coherent seed와 vacuum conjugate는 하나의
  명시적 입력 상태이며 임의 입력 상태를 뜻하지 않는다.
- η, H_p/H_c, w, 전자 잡음과 SQL 보정은 검출 외부 포트로 보낸다.
  EOM 같은 실험 장치의 상세를 원자 모델 안에 끼워 넣지 않고, 셀에 입사한
  seed와 필요한 기술 잡음 정보의 경계만 표시한다.

#### 4.2 생산 원자 응답 — `atomic`

내부 흐름은 다음과 같이 구성한다.

```text
운전점 + branch + 속도축
  → Hamiltonian / 산일자 / 유한 기준장 조립
  → [probe 기준장만 입사한 Floquet 해 ∥ conjugate 기준장만 입사한 Floquet 해]
  → 각 해의 ρ₀, ρ₊에서 가중 polarization 읽기 / 기준 Rabi로 나누기
  → 4개 복소 reduced-response 성분
  → 생산 1D Maxwell 속도 평균
  → 평균장 전파 그룹
```

- 실제 `chi_matrix_table()`의 두 번의 해를 드러낸다. 두 번째 conjugate
  기준장은 응답 열을 얻는 계산용 입력이며, 실제 운전에서 conjugate를
  함께 주입한다는 뜻이 아니다. 이것을 무한소 Nambu 도함수와 동일시하지 않는다.
- Floquet 식 `(ℒ₀+inΩ_beat)ρ_n+𝒞₊ρ_(n−1)+𝒞₋ρ_(n+1)=0`과
  `Trρ₀=1`, `Trρ_(n≠0)=0`을 넣는다. 연분수/compiled kernel은 생산 계산,
  별도 dense block은 같은 절단 문제의 구현 비교로 표시한다.
- 대표 dipole/CG 가중치가 구동과 polarization 읽기에 들어가는 위치,
  열 재장전 `γ_t(ρ_th Trρ−ρ)`의 `5/12, 7/12`, 충돌 위상감쇠를 보존한다.
  생산 해 앞에 pump-only 16×16 정상상태 해를 필수 단계로 두지 않는다.
- 두 Raman branch를 표시할 때 각각 별도 모드쌍·응답행렬로 유지한다.
  참조의 plus 미지원이 생산 plus 계산 자체의 부재를 뜻하지 않게 한다.
- N_F=3과 2에서 **응답 → 전파까지** 계산한 결과를 검증 노드로 보낸다.
  reduced response, 정준 transfer, gain, wrapped phase, gain 최적점의
  전체 스캔 비교를 통과해야 수렴으로 표기한다. 이는 반복 계산의 검증 관계이며
  검증선을 생산 DAG의 순환으로 만들지 않는다.
- 전달계수의 혼합 허용오차 `1e−10+0.01 max(|T_N|,|T_(N−1)|)`,
  시간 차원 응답의 별도 절대 바닥값, gain 1%, phase 0.5°, 최적점 한
  격자 간격 조건을 상세에 둔다. trace/positivity 합격으로 대체하지 않는다.

#### 4.3 pump-only 참조와 응답의 해석 구조 — `reference`

**B̃ 정상상태**: 공통 원자 모델 → minus pump 정적 프레임 →
`ℒ_pump ρ_ss=0, Trρ_ss=1`의 16×16 구속 해. 여기서 출력을 두 갈래로 보낸다.
한 갈래는 약응답의 원자 상태, 다른 갈래는 seeded frame으로의 gauge 사상과
pump-only Floquet parity 검사다. 유한 seed 생산 응답과의 차이는 별도
seed→0 비교로 두며 같은 상태라는 등호를 붙이지 않는다.

**C̃/C 약응답**은 다음 구조를 복원한다.

```text
ρ_ss + ℒ_pump + probe/conjugate 섭동 + 독립 Ω_SA
  → trace-zero source / stationary-subspace 처리
  → 직접 구속 선형해 ───────────────────────────────┐
    또는 쌍직교 고유기저 → pole와 residue → 응답 재구성 ├→ 2×2 복소 Nambu 응답
    결함 행렬: 고차극 해석 / 직접해·등고선 평가 ──────┘
  → 속도 평균 → 참조 χ′(Ω_SA)
```

- 해석식 `δρ_k=−(ℒ_pump+iω_k)⁻¹_(Tr=0)𝒱_kρ_ss`와
  `χ̄_jk=Σ_m A_m^(jk)/(λ_m+iω_k)`를 내장한다. residue는
  `A_m^(jk)=−⟨w_j|r_m⟩⟨l_m|𝒱_k|ρ_ss⟩`로, drive와 polarization
  readout 양쪽에 의존한다. 극 위치만으로 관측 피크나 대역폭을 정하지 않는다.
- `λ_m=−Γ_m+iω_m`에서 pole 중심은 **resolvent 주파수 축**의
  `−Imλ_m`, HWHM은 `−Reλ_m`이다. minus 참조의
  `ω_k=−ω_HF+δ+Ω_SA`를 함께 표시해 RF 실험 축으로 옮기는 기준을 밝힌다.
- 단순극 표현은 대각화 가능한 경우다. stationary mode의 residue가 0이어도
  `ω_k=0`의 특이 역행렬을 그대로 쓰지 않는다. 여러 정상 모드가 있으면
  전체 stationary subspace를 처리한다. `ω_k=0`과 `Ω_SA=0`도 구별한다.
- 1D 기본 참조와 opt-in 2D `(v_z,v_x)` 평균을 명시적 선택으로 둔다.
  `Δ_eff=Δ−k_pump v_z`,
  `δ_eff=δ+(k_pump−k_p cosθ)v_z−k_p sinθ v_x`를 넣고, lab beat와
  RF 분석 주파수는 속도에 따라 이동시키지 않는다고 적는다. 2D는 생산에
  자동 합류하지 않으며 plus 참조는 unsupported다.
- Faddeeva/Voigt는 **선형 속도 pole 위치·상수 residue인 단일극 극한**의
  별도 축약 가지로 둔다. 일반 응답의 속도 구적 → 최종 평균 응답 직결도
  남겨서 모든 계산이 Voigt를 거쳐야 하는 것처럼 보이지 않게 한다.
  단일극 적분식과 `Im⟨1/(x₀−kv+iΓ_o)⟩=−πV(x₀;kσ_v,Γ_o)`를 넣는다.
- Raman pole의 Lorentzian HWHM, 비공선 Gaussian rms, 검출 스퀴징
  bandwidth는 서로 다른 양이다. 참조 응답은 미래 M_q의 재료를 제공하지만
  실제 구동 상태에서의 미시 M_q·D 연결을 완성하지 않는다고 표시한다.

#### 4.4 평균장 전파와 이득 진단 — `mean`, `gain`

- 평균한 시간 차원 reduced response → 무차원 physical χ 변환을 명시한다.
  `χ=−2Nd²ℓ_norm χ̄/(ε₀ℏ)`의 밀도·dipole·정규화 출처를 연결하고,
  ρ가 이미 담은 ground population을 외부에서 다시 곱하지 않는다.
- physical χ의 네 성분과 bare carrier k, 기하 `Δk_geom`가 **함께**
  Maxwell `M_E`로 들어가게 한다. Part IV의 2×2 행렬 네 성분, mismatch
  대각 부호, `Q=diag(√(2ℏω_p/(ε₀cA_p)),√(2ℏω_c/(ε₀cA_c)))`,
  `M_cl=Q⁻¹M_EQ`를 상세에 모두 넣는다. 분산은 대각 χ에서 한 번만 적용한다.
- `M_cl` → 상수계수 Cayley–Hamilton 전파자 / z 의존 분절 전파의
  조건부 분기를 표시한다. 상수식의 `(s,q)`, `sinh(qL)/q`의 q=0 연속값,
  순서 있는 `T_K⋯T_1`을 설명한다. 일반 z 의존 문제를 평균 M의 지수로
  치환하지 않는다.
- 전파자에서 **복소 평균장·위상 → 검출**, **두 이득 → 진단**이 갈라지게
  한다. 정준 입력 벡터가 `(α_p,α_c*)ᵀ`임을 표시하고, gain의 분모는
  모두 같은 probe-seed 입력 파워 P₀로 둔다.
- `G_p=|T_11|²`, `G_c=(ω_c/ω_p)|T_21|²`,
  `g_c^(Φ)=(ω_p/ω_c)G_c`, `𝒢_flux=G_p−g_c^(Φ)`를 구별한다.
  전체 `TJT†` 검사는 두 gain만으로 계산되는 스칼라 검사보다 강한 조건이다.
- 현재 Ultra의 분절·공간 overlap·근사 pump 예산 제한은 선택적 생산 상세로
  남긴다. 작은 신호 정준 T의 진단과 seed 의존 유효 gain을 구별하며, 제한된
  파워에서 유일한 복소 진폭·위상 또는 물리적 양자 T를 역으로 만들지 않는다.
  매 구간 pump 상태를 다시 푸는 완전한 세 장 고갈 해로 표시하지 않는다.
- X는 `𝒢_flux` 진단과 조건부 이상 비교까지만 둔다. 무손실 정준 두 모드
  증폭기, 밝은 coherent seed, vacuum conjugate, 비가중 차동이라는 조건 아래
  `S_ideal=1/(2G_p−1)`, 대칭 외부 손실에서 `1−η+ηS_ideal`을 제시한다.
  `𝒢_flux=1`만으로 이 모든 가정이 검증됐다는 ‘합격’ 경로를 만들지 않는다.
  실제 공분산 또는 최종 스펙트럼으로 X에서 직결하지 않는다.

#### 4.5 미시 요동·저장고 — `micro`

- Nambu 벡터 `Â=(δâ_p(Ω),δâ_c†(−Ω))ᵀ`, `J=diag(1,−1)`를 첫 노드로
  두고, 구동된 원자 상태/주파수 응답과 저장고의 미시 상관을 입력 포트로 둔다.
- 원자 모델에서 미래의 `M_q(z,Ω)`와 `B(z,Ω), N_res(z,Ω)`를 구성하는
  미완성 경계를 표시한다. `M_q`에서 전파자 T로 가는 길과 저장고가
  분포 잡음 W로 가는 길을 각각 공분산 그룹에 연결한다.
- `K=−(M_qJ+JM_q†)=BJ_FB†`의 채널 분류와
  `D=BN_resB†`의 symmetrized diffusion은 별도 노드로 둔다. K는 D의
  유일한 생성기가 아니며, K의 양/음 고유값은 합격/불합격이 아니다.
- 교환관계 보존 적분식과 국소 조건, 정규화가 바뀌면 K도 바뀐다는 사실을
  보존한다. 독립 속도군의 D는 공분산 기여로 더하며 평균 잡음 진폭의 제곱을
  사용하지 않는다. 평균 응답만으로 속도별 저장고 정보를 복원하지 않는다.
- 독립진공 완성 `B_vac=U|Λ_K|^(1/2)`, `D_vac=B_vac B_vac†/2`는
  ‘대수 시험’ 소도식에 둔다. 이 출력으로 물리적 미완성 배지가 해제되지
  않으며 미시 저장고의 보편적 최소 잡음으로도 표시하지 않는다.

#### 4.6 공분산 전파와 Lyapunov 내부 구조 — `covariance`

```text
M_q ──→ T ──┬─ + V_in → T V_in T† ────────────────────────┐
             └─ + D → W=∫ T(L,z)D(z)T(L,z)† dz ────────────┤
                                                          ↓
                                               2×2 V_out의 합류
                                                          ↓
                     companion block + ±Ω pairing → V_Ξ → 4×4 V_R
```

- 상수 M_q와 D에서 `𝓜[X]=M_qX+XM_q†`,
  `dW/dL=𝓜[W]+D`, `W(0)=0`를 연결한다. 같은 W를 평가하는 세 구조를
  복원한다: 좌표무관 `Lφ₁(L𝓜)[D]`, 조건부 고유기저 전개,
  Van Loan 블록지수. 세 결과를 순차 통과하거나 합산하는 도식은 금지한다.
- `φ₁(x)=(exp(x)−1)/x`, `φ₁(0)=1`, 고유기저의
  `μ_m+μ_n*`와 `D̃=S⁻¹DS^(−†)`,
  `Z=[−M_q,D;0,M_q†]`, `exp(ZL)=[F_11,F_12;0,F_22]`,
  `W=F_22†F_12`를 상세에 내장한다. 고유기저는 해석용이며 대각화·조건수
  확인이 필요하다. 결함/준결함 행렬에서 좌표무관 평가로 돌아가는 경로를 둔다.
- 평균장의 `(s,q)`와 양자 요동의 `(s_q,q_q)`는 형태가 닮았다는 해설선만
  연결한다. `M_q(Ω)=M_cl` 조건 없이 고유쌍을 재사용하는 데이터선은 없다.
  `spec 𝓜={μ_m+μ_n*}`를 그대로 제시하고 서로 다른 값의 수를 고정하지 않는다.
- z 의존 계수는 입구에서 별도로 분기해 실제 국소 `(M_k,D_k)` →
  `(T_k,W_k)` → `V^(k+1)=T_k V^(k)T_k†+W_k`로 누적한다.
  상수계수 최종 결과를 얻은 뒤 추가로 잡음을 한 번 더 넣는 경로가 아니다.
- T가 입력 요동과 분포 잡음 양쪽에 사용되는 직접 연결, 외부 `V_in` 포트,
  companion block을 모두 보존한다. `Ξ=(a_p,a_c,a_p†,a_c†)ᵀ`의 ±Ω
  배치와 원문의 4×4 C를 넣어 `V_R=CV_ΞC†`, `R=(X_p,Y_p,X_c,Y_c)ᵀ`를
  설명한다. 네 성분을 네 독립 carrier로 부르거나 2×2 V에 검출 4×4 행렬을
  곧바로 곱하지 않는다.
- `W=W†`, `W⪰0`(D⪰0일 때), L=0 극한과 Gaussian channel 물리성 조건은
  검증 대상으로 붙인다. 대수 항등식 검증과 실제 원자 D 검증은 별도 상태다.

#### 4.7 외부 손실·검출·최종 스펙트럼 — `detector`, `output`

- 셀 출력 `V_R,out`와 외부 독립 vacuum →
  `V_R,det=K_ηV_R,outK_ηᵀ+K_ℓ(I/2)K_ℓᵀ`를 그린다. K_η와 K_ℓ의
  네 대각 성분을 내장하고, mean 그룹의 복소 carrier는 별도 선으로 받아
  `α_j,det=√η_j α_j,out`으로 감쇠시킨다.
- 검출된 carrier·위상·`H_p(Ω),H_c(Ω),w(Ω)`가 광전류 선형화와
  **같은 조건의 SQL**에 함께 들어가도록 한다. 측정 벡터 m이 외부에서
  갑자기 주어지는 상수가 아니라 이 입력들에서 구성됨을 보여준다.
- `δi_j∝H_j(α_j,det*δa_j,det+α_j,det δa_j,det†)`,
  `δi_−=δi_p−wδi_c`와
  `S_−(Ω)=[m†V_R,det m+S_el]/S_SQL`을 내장한다.
  복소 주파수 가중치를 허용하면 SQL의 제곱은 `|w|²`로 쓰고, `w²` 표기는
  실수 가중치 조건에서만 사용한다. 출력/검출 평균장을 섞어 η를 중복 적용하지 않는다.
- 파워·응답·가중치·RBW/VBW·dark-noise 포함/차감 조건이 SQL과 일치해야
  한다. 셀 내부 흡수를 외부 η로 다시 적용하지 않는다. 외부 기술 잡음은
  물리적 위치와 보정이 확인된 입력으로 두며 임의 상수를 원자 diffusion에
  합쳐 넣지 않는다.
- 최종 RF 스펙트럼의 dB 정의는 `10 log10 S_−`와 함께 표시한다. 미시
  M_q·D 및 필요한 검출 입력이 없는 현재 상태에서는 숫자 곡선이나 대역폭을
  완성 결과처럼 제시하지 않는다. 평균장 δ 스캔과 RF Ω_SA 스캔도 구별한다.

**F의 손실 통계 소도식**은 현행 TeX의 추가 논리를 압축한다.

```text
이상 vacuum-input TMSV → 공유 pair number N → 두 팔의 thermal marginal
  → 각 팔의 독립 순수 손실 K_j|N ~ Binomial(N,η_j)
  → 평균·분산·공분산 → 가중 차동과 해당 SQL
```

- `VarK=η²VarN+η(1−η)⟨N⟩`,
  `Cov(K_p,K_c)=η_pη_c n̄(n̄+1)`에서 공통 pair fluctuation과 분할 잡음을
  구별한다. 대칭 손실의 이상 TMSV에서는 `NRF=1−η`, 비대칭이면 공통
  열적 요동이 raw difference에 남는다는 분기를 보인다.
- thermal marginal, vacuum 손실 포트, 실제 thermal 환경, 밝은 seeded
  displaced-thermal 상태를 구별한다. 순수 손실이 포아송 광자 집단을
  주입한다거나 밝은 seeded 빔에 항상 `g²=2`라고 표시하지 않는다.
- 이 소도식은 검출 통계의 이상 시험이다. 진공 입력 TMSV의 정확한 광자수
  통계를 밝은 carrier 광전류 선형화에 그대로 넣지 않는다. 여기서 얻는
  NRF와 X의 bright-seed 이상식을 같은 초기 상태의 식으로 합치지 않는다.
  일반 GABES 산일 셀의 covariance를 대신하는 우회 경로도 만들지 않는다.

### 5. HTML 하나로 이해할 수 있게 하는 정보 계약

- 모든 내부 노드에 **의미, 입력/출력, 차원·기저·주파수 인자, 계산식,

### 6. 검증 근거의 연결과 구현 순서

기존 검증 표는 유지하면서 해당 내부 노드로 연결한다. 특히 참조 방정식
잔차 `7.32e−17`, pump-state gauge parity `8.37e−15`, 8 µW finite-seed
응답 차이 `2.503e−3`은 서로 다른 비교량으로 남긴다. 2D rms·grid·cutoff,
대수 항등식, 전체 스캔 절단 수렴, 절대 gain 불일치, 미완성 스펙트럼도
하나의 오차나 인증 배지로 합치지 않는다.

다음 HTML 개정의 실행 순서는 다음과 같다.

1. v2의 `INT.n/e`를 위 그룹 대응에 따라 목록화하고, 각 항목을 복원·분리·
   재배선·제외로 표시한다. 위 출처 키를 현행 TeX에서 확인한다. 물리 흐름은
   TeX를 기준으로 하되 현재 실행 여부는 구현에서 확인한다.
2. 모든 그룹의 정적 본문·수식·포트·연결 데이터를 먼저 채운다. 이 단계에서
   HTML만 읽어 계산 경로와 미완성 경계를 재구성할 수 있어야 한다.
3. 넓은 내부 도식, 노드 inspector, 앵커 이동, 전체 펼치기, 세 정보 보기의
   공유 선택 상태를 연결한다. 레이아웃 때문에 필수 배선을 삭제하지 않는다.
4. 정적 검사와 실제 렌더링 검사를 구별해 수행한다. 허용된 브라우저 접근이
   차단되면 그 제한을 기록하며 정적 검사를 시각 검증으로 보고하지 않는다.
5. 결과와 검증 범위를 이 notes에 이어 기록하고 **v3 그대로** 개정한다.
   물리 엔진 변경이나 새로운 양자 solver 구현은 이 HTML 개정 범위가 아니다.

- **소스 추적**: TeX 검색 키와 관련 구현 이름이 존재하며, HTML에 서술된
  식·단위·조건을 대조한다. 주장별 보고값에는 원문 표와 검사 범위를 남긴다.
- **사용성**: 데스크톱·태블릿·모바일, 키보드, 긴 수식, 전체 펼침·인쇄에서
  글자 겹침·잘림·모호한 연결·포커스 유실을 실제 렌더링으로 확인한다.
- **검토 질문**: HTML만 받은 독자가 ‘왜 gain만으로 S_−를 알 수 없는가’,
  ‘일반 응답은 왜 항상 Voigt가 아닌가’, ‘K를 알아도 왜 D가 남는가’,
  ‘평균장과 V는 검출에서 어떻게 합류하는가’, ‘무엇이 구현됐고 무엇이
  아직 필요한가’에 도식의 노드와 식을 근거로 답할 수 있어야 한다.
