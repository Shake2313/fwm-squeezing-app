# FWM 동작 변수 점검 — mean-field gain과 gain-referred 진단

자동 생성 — `analysis/squeezing/variable_audit/scan_variable_audit.py`

판독 규약은 v6 gain-referred diagnostic tolerance 절과 동일: hardened Ultra, η = 0.8694, δ 격자 5 MHz, gap gate [0.5, 1.5]. 기준점은 레퍼런스 DB의 gold reference (Sim 2025: Δ=+0.9 GHz, T=121 °C, δ=−8 MHz, 600 mW, w 530/330 µm, L=12.5 mm, θ=0.32°).

**Claim gate — `MEAN_FIELD_DIAGNOSTIC`.** 엔진의 절대 이득은 예측값이 아니며, 아래 dB 값은 mean-field gain에 ideal twin-beam law를 결합한 `gain_referred_noise_dB` 진단이다. GABES에는 microscopic Langevin diffusion/covariance와 동일 조건의 측정 SQL이 없으므로, 아래 결과는 물리적 squeezing·대역폭·SQL 상하를 예측하지 않는다. 읽을 것은 이 가정 아래의 민감도와 순서뿐이다. `S_dB`와 `xi_*`는 호환용 구 키다.

### 10개 연구실이 실제로 얼마나 좁게 수렴했나 — v6 gain-referred 진단 창과 대조

엔진과 무관한 독립 교차검증이다. **검출량(detuning)은 영점이 물리적이라 비율/CV가 무의미**하므로(TPD는 0을 가로지른다) v6의 +0.5 dB 허용 창과 직접 비교한다:

| 변수 | n | DB 전체 산포 | v6 진단 +0.5 dB 창 | 산포/창 |
|---|---:|---:|---|---:|
| TPD delta [MHz] | 8 | 13.7 | -9.6 / +4.2 MHz | 0.99 |
| OPD Delta [GHz] | 8 | 0.45 | -32 / +155 MHz | 2.41 |
| temperature [C] | 10 | 29 | -3.3 / +12.0 C | 1.90 |

**TPD가 가장 좁다**: 8편이 독립적으로 고른 δ가 전부 14 MHz 폭 안에 들어 있고, 그 폭이 v6가 1D 스캔으로 계산한 gain-referred +0.5 dB 진단 창 (−9.6/+4.2 MHz, 폭 13.8 MHz)과 사실상 같다. 서로 다른 셀·온도·파워를 쓴 연구실들이 이 한 변수에서만 한 점으로 수렴했다는 뜻이다. 이는 **진단 창과 문헌 동작점 산포의 정성적 일치**이지, 물리적 squeezing 창의 검증은 아니다. OPD와 온도는 창의 2배 정도 흩어져 있는데, 이는 각 실험이 자기 조건에서 다시 최적화했기 때문으로 읽힌다.

두 기하 모두 지수가 **n ≈ 1.5**로 나온다. 이것이 dressing이라는 직접적인 증거다: n = 2는 섭동적 light shift Ω²/4Δ, n = 1은 강한 dressing 극한(일반화 라비 √(Δ²+Ω²) → Ω)이고, 이 동작점은 Ω/Δ ≈ 0.2–1.6이라 정확히 그 **교차 영역**에 있다. 위 표에서 Ω²/4Δ는 고출력에서 과대평가, dressed 공식은 저출력에서 과소평가하는데, 실측 δ*가 그 사이에 있는 것도 같은 이야기다.

δ* ∝ Ω^n ∝ P^(n/2) 이므로 파워를 x배 하면 δ*는 x^{n/2} ≈ x^0.75배가 된다. 동작점에서 실제로 얼마나 움직이는지:

| 기하 | 동작 P [mW] | 그때 δ* [MHz] | 파워 −50% | 파워 +10% | 파워 ×2 |
|---|---:|---:|---:|---:|---:|
| gold | 600 | +35.8 | -14.4 | +2.6 | +24.3 |
| Jain | 135 | +53.0 | -21.4 | +3.9 | +35.8 |

비교 대상: v6 gain-referred 진단표의 TPD +0.5 dB 창은 **−9.6 / +4.2 MHz** — 모든 변수 중 절대 창이 가장 좁다. gold 동작점에서 펌프를 절반으로 줄이면 δ*가 −14.5 MHz 움직여 창(−9.6)을 벗어나고, 2배로 올리면 +24 MHz로 창(+4.2)을 6배 넘긴다. **파워를 10%만 건드려도 청(+)측 창의 절반을 쓴다.** 실무적으로 펌프 파워(또는 허리)를 바꾼 뒤 δ 재스캔을 우선 점검할 근거다. 다만 이 계산만으로 관측된 squeezing 저하의 물리적 원인을 δ 불일치로 확정할 수는 없다.

**지렛대 비교** (기준점 ±15% 국소 미분): dlnG/dlnP = 0.69, dlnG/dln(겹침) = 5.84 → 겹침이 파워보다 **8.5배** 강하다.

이 비율은 엔진의 절대 이득과 무관한 양이다. `mode_overlap_penalty`는 결합상수에 곱해지므로 q ∝ 겹침이 **정확히** 성립하고, 연쇄법칙으로

```
  dlnG/dln(겹침) ÷ dlnG/dlnP = 1 / (dln q / dln P)
```

즉 dlnG/dlnq가 그대로 약분된다. 측정된 dln q/dln P = 0.118 — 앞선 저출력 분석에서 나온 포화 지수와 같은 크기다. 겹침은 이득 지수 qL에 선형으로 들어가 exp에 바로 앉는 반면, 파워는 √I → 이미 포화된 Ω를 거쳐 들어가기 때문이다. **'FWM이 안 보이면 펌프보다 겹침을 먼저 보라'는 모델이 그대로 재현한다.**

정리하면:
- **이 fixture에서 DC 기댓값 자체는 진단 손실이 아니다.** 재균형으로 지워도 ideal-law 진단은 거의 같다.

그러니 체감의 물리는 맞고 표현만 옮기면 된다: 'IDS 기댓값이 0이 안 된다'가 아니라 **'한쪽 팔에만 상관 없는 광자가 더해진다'**. 그리고 그 순간 이 항은 시드 문제가 아니라 §8의 '외부 빔 유입'과 같은 범주가 된다. 다만 coherent/thermal 유입의 실제 SQL 상하는 microscopic covariance와 동일 조건의 측정 SQL 없이 이 스크립트가 판정할 수 없다.

표의 `셀내 최소겹침` 열을 보면 0.32°에서도 0.997, 1.0°에서도 0.97로 **겹침은 거의 손실이 없다**. 그런데 이득은 급격히 떨어진다 — 범인은 겹침이 아니라 위상정합 Δk_z다. v2 §Classical coupled-mode equation의 Δk_geom = 2k_pump,z − k_p,z − k_c,z 가 exp(qL) 안에 직접 들어간다.

**단, 여기엔 모델의 구조적 편향이 있다.** Option A 규약(v2 「No double counting of dispersion」)에서 분산은 Re χ_pp/χ_cc가 전부 담당하고 Δk에는 진공 파수만 들어간다. 에너지 보존 ω_p + ω_c = 2ω_pump이 정확하므로 **θ=0에서 Δk_geom은 항등적으로 0**이고, 엔진은 언제나 0°를 최적으로 고를 수밖에 없다. 즉 이 모델은 '유한 각이 최적일 수 있는가'라는 질문에 답할 자격이 없다 — v6 「해석」 4항이 low-angle ridge를 *geometry calibration 범위 밖*이라고 못 박은 것과 같은 이유다. 저각 수치를 설계 근거로 쓰지 말 것.

실무적으로 각을 정하는 것은 **분리 거리**다. 마지막 열이 셀 출구에서 프로브/conjugate가 3 허리만큼 벌어지는 데 필요한 자유전파 거리다 (가우시안 발산 포함). 레퍼런스 DB의 실제 사용 각은 0.3–1° (중앙값 0.4°)로 좁게 모여 있는데, 이 표를 보면 그 범위가 '분리 거리는 감당 가능하면서 Δk_z 대가는 아직 작은' 구간과 정확히 겹친다. 체감하신 타협이 바로 이것이다.

## 8. 외부 빔 유입 — conditional ideal-covariance fixture

> Within the assumed ideal covariance, S(eta) = eta*S_ideal + (1-eta) with 0 <= S_ideal <= 1 gives S <= 1 for eta in [0,1]. This algebraic unity reference is not a measured SQL and does not establish the physical cell covariance.

아래 unity=1은 이 fixture의 정규화 기준일 뿐, 동일 조건에서 측정한 SQL이 아니다. 따라서 표의 unity 상하는 물리적 above/below-SQL 판정이 아니다.

| 0.8694 | 0.1628 | -7.88 |

### 조건부 점검 순서 (mean-field/ideal-law 진단)

이 순서는 실험 진단 후보의 우선순위이며, physical squeezing noise-budget의 first-principles 순위가 아니다.
1. **Loss / 검출 효율** — ideal-law 진단과 점근선을 직접 움직인다.
2. **외부 빔 유입 / 미광** — 별도 microscopic covariance와 동일 조건 SQL 측정으로 확인해야 한다.
3. **빔 겹침** — 이득이 안 나올 때 펌프 파워보다 먼저 볼 것 (지렛대 8배).
4. **TPD 재스캔** — 특히 펌프 파워를 건드린 직후. δ* ∝ Ω^1.5 ∝ P^0.75로 이동하고, 파워 10% 변화가 허용 창의 절반을 쓴다.
5. **OPD** — TPD와 쌍으로 함께 재스캔.
6. **온도** — 저온측이 절벽이니 명목값보다 1–2 °C 높게.
7. **시드 파워** — 마지막. 검출기 포화만 피하면 된다.
